# 宝石品质升级曲线（2026-09-09）

用户确认普通到不朽保留原设计，并进一步明确：不朽之后逐级递减的是品质升级倍率，范围采用×2到×1.25。五次升级的倍率均匀递减。宝石数量正常累加，同品质同属性四颗的收益等于单颗的四倍。

攻防值每阶先用上一阶整数乘升级倍率，再向上取整：`V(q)=ceil(V(q−1)×倍率(q))`。品质阶q=6～10时，`倍率(q)=2−0.1875×(q−6)`；整数取整后的实际相对提升约为100%、81.25%、63.79%、44.21%、25.55%。属性总值始终上升，相对增幅逐级放缓。此前“每阶新增点数递减”及×1.95到×1.75的方案均已撤回，以本版为准。

生命沿用此前批准总表的攻防值5倍，在攻防档位取整后乘5；旧代码的10倍是本次同步修正的已记录差异。至宝4攻／4防／4生命从2026-09-04设计的 `+80攻击、+80防御、+400生命` 调整为 `+128攻击、+128防御、+640生命`。总表01中的设计最终属性只增加48攻击、48防御、240生命，装备和裸身预算不变；原值保留作历史对照。这些是设计配装值，不能冒充现有装备基础曲线已经全部实现。

实现顺序是先写本文与装备总表，再修改 `FGameXXKGemRules::GetStatBonus`。总表保留“设计值／当前代码值／状态”三列，实施后重新核对。旧存档只保存宝石类型与品质，新品质值由统一规则重算；数量、合成配方、孔数和拆装规则不变。属性投影、换装比较、宝石提示、详细属性页都读取统一结果。

验证需覆盖十档三种属性、无效输入、高五档升级倍率递减而属性总值增长、同品质多颗累加及现有存档往返；不得保留按镶嵌颗数降权的实现。
