## 1. 目标与已确定的边界

玩家的主线依次是：使用一次装备 → 看见自动成长 → 开箱获得机会 → 主动挑战 → 加入伙伴 → 接任务、认识月白 → 调整卡组与套装 → 理解不同职业 → 选择收益地点 → 挑战高难与讨伐。加工工具从1-1起穿插在这条主线中：掉出什么、现在需要解决什么，就介绍对应的一种工具。

保留的核心乐趣是构筑与开箱。任务提供大量金币和宝箱，教学负责把这些收获接到一个具体用途上。

- 挂机条负责自动游历；局内负责路线选择、卡牌战斗和本局构筑，两者分别演算。
- 普通挑战期间暂停挂机，覆盖路线、战斗、事件、行商及奖励选择，返回后按既有规则恢复；不补算这段暂停时间。
- 普通挑战胜利、剧情专属战斗胜利、借用教学战斗胜利分别记账。剧情战或课程不替代普通关卡首通。
- 新档1-1只有主角；实际通关1-1后进入1-2，开放伙伴槽天赋；实际通关1-2后进入1-3，开放主线。
- 主线S00-02“获得卷轴”认识月白后开放NPC槽天赋；月白首次入队。沿用 `Npc.YueBai`，当前游戏文本称“幽白”。
- 两个出战槽天赋各200金币，已有功能不重复收费。解锁后可卸下伙伴/NPC，保留个人资产；合法携带牌份额为8/13/11/16。
- 未开放槽位用锁图标；购买后自动高亮编队图标。不能让玩家自己猜下一处入口。
- 设置、静音、退出和跳过教学一直可达。旧存档保留已有功能，不倒退到新手阶段。

开场即在 1-1 正常游历，开箱和提示不主动暂停。裸装可过普通波次，在精英处战败后优先引导逐件穿齐六件基础装备，再重新出发。基础装备基础属性乘 2，穿齐后应打过精英和 Boss；游历与局内挑战分开验证，不能混用结论。最新证据见[装备门槛记录](../production/2026-09-16-starter-equipment-gate.md)。

## 2. 每段教学的统一合同

### 2.1 一段最多两次操作

一次点击、一次右键、一次拖放分别计一次操作。“打开页面、选材料、投入、确认”必须拆段；“填九件材料”也不能伪装成一步。

各表行的操作以相关对象已经可见为前提。需要用户切页时，先插入独立的“点高亮入口”导航段；需要选难度、选关卡时分别插入选择段。观察自动出现的结算不计额外点击。不能用一句“使用卡牌”隐藏选牌、选目标两次操作，也不能靠自动替玩家选目标或付款来凑步数。

每段写清五件事：**为什么现在需要它、操作目标、操作方式、成功证据、下一步去哪里。**

例如伙伴解锁：

| 小段 | 玩家操作 | 完成后发生什么 |
|---|---|---|
| 解锁 | 点天赋 → 支付200金币 | 槽位真实开放，钱包真实扣款 |
| 找入口 | 点编队图标 | 打开编队，随后结束这一段 |
| 使用 | 选一位伙伴 → 编入队伍 | 挂机/下次局内采用新编队 |
| 体验 | 在后续战斗使用一张伙伴牌 | 看到该伙伴的实际作用 |

界面不显示整个长流程的“第1/80步”。只显示本段1/1或1/2，完成后给出简短反馈。

### 2.2 “学过”与“会用”分开

课程记录分成：已介绍、已成功操作、已在没有高亮提示时再次使用。第三项作为熟练信号，不宣称能够读取玩家是否真正理解。

- 点“知道了”不算完成穿戴、付款、配卡或战斗机制。
- 自然完成相同操作也算学习，不要求拆掉重装、重复付钱或重打一遍。
- 普通成长不强制等待每一门课熟练；下一次同类基础操作先给玩家自己尝试的机会。
- 选自动出牌的玩家照常推进关卡；系统不把自动出牌记录成玩家已独立掌握手动操作。
- 全部内容都有可到达的课程。未选择的职业和NPC不用在前期逐个强制毕业。

### 2.3 同时只给一个当前目标

点击后需要连续完成的短链自动衔接，例如购买后指向编队。一次穿戴、一次开箱、一次战斗兑现效果后，先留出正常游玩的空间，再介绍无关新系统。

同时满足多个条件时，优先处理：必须完成的结算/溢出处理 → 当前已开始的操作 → 当前剧情 → 本阶段主要新功能 → 可选进阶课。正在选目标、弃牌、调查选择、洗炼保留/替换时不插入别的课程。

### 2.4 开放功能、提醒学习分别控制

下表的后续关卡只是**建议最早教学窗口**，不代表已经批准或写入新的硬门槛。实际触发还必须检查玩家已具备相关物品、金币和前置操作经验。

五种工具从1-1即可使用，不新增关卡锁或工具解锁费。当前“百工开物”开启的是工具经验与金币加成分支，不能把它误当成操作工具的必购前置。实际操作仍检查合法目标、材料、金币、背包空间和交易状态；离线收益继续使用它自己的既有资格。

如果前置天赋还没买，每个前置都单独做成“选节点→支付”的小段，不在一次操作里暗购整条路径。实际流程自动到账的奖励直接显示已到账明细，不为了教学虚构一个领取按钮。

主动查看说明、提前获得物品、关闭引导都不删除资产。不把已经拥有的物品藏到玩家无法取回的地方。

## 4. 1-1：先完成最小成长循环

### 推荐开场处理

新档只持有第一教学箱，推荐承载起始武器与装备课程；其余阶段箱尚未发放。开场先处于短暂出发准备状态，突出主角和第一箱；武器由玩家亲自装备，避免空装时后台连续被打倒。玩家可暂缓教学并正常游玩，回来继续当前课。

这是拟新增的首次出发规则，不能误写成现行行为，也不改变正常挑战期间暂停挂机的合同。

| ID | 触发与用途 | 本段操作（最多2次） | 成功证据与衔接 |
|---|---|---|---|
| A01 | 新档已持有第1教学箱 | 点第一教学箱 | 固定物品成功入账后自动进入装备课，不另要求找教程目录 |
| A02 | 第一箱武器已交付 | 点背包入口 → 右键该武器装备 | 主角武器槽真实占用；入口已打开则跳过导航，只讲本次真实属性变化 |
| A03 | 已装备武器或玩家主动跳过 | 点出发/游历 | 正常挂机开始；指向攻击、生命和当前遭遇，不讲回合气力 |
| A04 | 第一场挂机遭遇成功结算 | 无需额外点击，短暂标出收入 | 金币/经验真实增加；不把点提示算作收益 |
| A05 | 首次另外取得普通随机宝箱 | 点普通宝箱 | 展示本次真实随机收获，区别于固定教学箱；不占用教学箱顺序 |
| A06 | 普通收获中有可用防具 | 点查看获得物品 → 右键穿戴 | 对应槽位真实改变；没有适用装备则说明用途并保留，不阻断教学箱流程 |
| A07 | 已体验一次成长，准备主动推进 | 点历练图标 → 点普通1-1挑战 | 明确这会进入局内；挂机停止，普通挑战身份不变 |
| A08 | 第一个可选路线节点出现 | 点一个可到达节点 | 打开正式战斗；不一次解释全图节点种类 |

第1箱在新档创建时发放，推荐从原起始装备重分配武器；后续阶段箱通过上一课完成记录逐个发放，提供固定教具。第6箱另外一次性发8个配套材料子箱，最终共9件合成装备。具体物品、材料和费用逐箱对账，普通与高级随机箱保持原有概率。

第1箱不依赖战斗、收益、出发或通关；第2～6箱只按前课真实完成顺序发放，不新增关卡限制。开箱、入账和学会分别记录，读档不重发；玩家不必学完全部工具课才能正常挑战，合成课尤其允许直接关闭。

### 首次局内分段

| ID | 触发与用途 | 本段操作 | 成功证据与衔接 |
|---|---|---|---|
| B01 | 首次拿到可打手牌 | 查看一张当前可用攻击牌 | 先说这张牌做什么、能对谁用；费用不足的牌不选作首次示范 |

| B04 | 玩家准备把行动交给敌人 | 查看一个敌方意图 → 点结束回合 | 敌人按实际规则行动；提示将要受到的影响 |
| B05 | 首次有防护需求且手里有合法牌 | 点一张合适防护牌 → 点目标（若需要） | 实际产生护甲/反应；不要求此时理解全部状态 |

| B08 | 回到路线图 | 点下一可达节点 | 让玩家自行重用前面学过的操作，减少高亮 |

| B10 | 普通1-1整关完成 | 领取/确认该次结算（如现有界面需要） | 真实首通登记、1-2可挑战、新游历目标按原规则恢复 |
| B11 | 失败或主动退出 | 点返回 → 进入一个可执行的提升入口 | 仍能装备、继续游历或重试；不会重复给首通奖励 |

使用现有合法主角8张携带牌，不恢复被撤回的“三张新手牌”方案。教学适配当前手牌和目标；缺少示例牌时等待合法机会或提供自愿借用练习，不能卡住回合。

首节点单敌是降低观察负担的优先候选，整关编制与数值须通过真实战斗定表。关卡强度按内容定义，不能根据玩家临时卸下角色动态降低、仍给同等奖励。

**1-1验收门槛：**正常新档资源、无需开发指令、无需读说明书，能够完成穿戴、取得收获、进入与离开局内；装备后挂机与完整单人挑战都须验证可玩性。未通过此项就先修开场，不继续堆后续课程。

| D11 | 首次剧情专属战斗准备完毕 | 点进入剧情战斗 | 白话说明这是当前任务战；不要求寻找已经移除的剧情问号入口 |
| D12 | 剧情战胜利且战后对白结束 | 点领取该任务奖励 | 获得任务定义的大批资源；不冒充普通1-3首通 |
| D13 | 大批箱子到账且已会单开 | 点一个同类箱的批量开启入口 → 确认本批（若有确认） | 看清本批实际收获；没有完整批次展示时先补展示能力 |

1-3的主要新增学习是“认识任务、理解收益、认识月白、会带NPC”。领取大批奖励后先看收获，有具体工具需求再提示对应一课；不把一批材料转成五门连续必修课。

## 7. 局外成长：工具从1-1起按需学习

以下每个ID是一段，不把表内多行自动连成强制长教程。建议窗口可因玩家资源情况后移；基本存储、离线说明等安全功能可以按实际需要提前。

### 7.1 五工具的首次触发

| 工具 | 1-1起即可触发的条件 | 第一次只教什么 |
|---|---|---|
| 镶嵌 | 点击镶嵌教学箱；其他宝石用途可主动补课 | 用固定宝石与合法孔完成一次镶嵌 |
| 强化 | 点击强化教学箱 | 用配套目标、材料与费用预算强化一次 |
| 分解 | 打开对应普通宝箱 | 了解分解用途与位置后关闭；是否分解由玩家决定 |
| 合成 | 点击第6教学箱，配套8箱也已发放 | 指引玩家点“自动填入”、看9格与概率预览；不代点最终合成，提示可关闭 |
| 洗炼 | 点击洗炼教学箱 | 用可洗目标和配套材料生成一次结果，自主保留或替换 |

固定教学箱是默认课程触发器，不是工具使用许可证。箱内配齐课程所需实物；玩家也能直接使用其他合法物品。普通掉落满足多个补课条件时，不抢当前箱子的课程。正常工具操作不足材料时保留页面与物品，不新增关卡条件。

镶嵌教学箱的固定短链：**点击箱子并看固定收获 → 高亮工具入口〔1步〕→ 选镶嵌模式〔1步〕→ 选装备、放入〔2步〕→ 选宝石、放入〔2步〕→ 选孔、确认〔最多2步〕→ 看实际结果。** 导航已经熟悉的步骤自动跳过介绍；业务上的选择和确认仍由玩家操作。

教学箱配套资源必须保证默认演示目标可用，包含合法孔位、词缀与配方，不能把缺教具留给玩家自行刷取。玩家改用自己的其他物品而不满足条件时，说明缺项并允许返回配套目标；若目标已被移动、锁定或消耗，按实际状态恢复，不重复发箱。1-1实物测试必须验证这些组合。

右键对阶段教学箱最多处理当前已发的一只，当前课未完成就没有下一阶段箱可开。第6箱发出的8个材料子箱允许另外一次主动右键批开，按真实背包空格逐箱交付，满包保留余箱；它们不再启动8门课。合成提示关闭后不因开子箱反复弹出，所有物品与箱子保留。见[教学箱右键处理](2026-09-15-starting-teaching-chests.md#4-顺序右键与暂缓)。

某些节点在1-1就可能遇到，其最小必需操作必须就地可学，不能等到3-1才允许过节点。这里推迟的是复杂解释和进阶购买，不是把早期合法路线堵住。

## 9. 所有职业与NPC的课程覆盖

复用现有 `GameXXKAcademyCatalog.cpp` 的13门课程、证据判定与借用战斗。在课程内部拆小段，不重造一套战斗规则。首次选用某角色时先教第一种机制，剩余课在继续使用或主动进入教程时开放。

| 弓手 / Academy.Hunter | 获得蓄力 | 重箭消耗、追加效果、持续状态与连射 |
| 法师 / Academy.Sorcerer | 主动使用符合要求的不同牌 | 任务完成、重放顺序、首牌阵赏分别观察；火/冰等目录中已有课分别练习 |

陌生角色可借用体验，正式拥有、正式出战资格和教学临时阵容明确分开。现行桌面商店目录不含伙伴包，不能把旧商品接口当成当前新手招募入口。

## 11. 保障资源和失败路径

| 问题 | 处理要求 |
|---|---|
| 默认教学需要的资源 | 开局教学箱提供固定配套资源；在发放表中验证可完成一次课程，不等待随机掉落 |
| 1-1普通箱掉落宝石/材料 | 按真实来源保存；主动使用可补课，不抢当前固定教学箱课程，已会操作不重复教 |
| 大批任务奖励导致背包满 | 优先已有仓库/待领取机制；必要时提前教一次存放。不得以“先分解”强迫损失资产 |
| 钱或材料不足 | 付款失败不记完成；返回已经学过的合法积累/领奖入口，不复制发钱 |
| 教学目标已被自然完成 | 校验业务状态后回补记录，跳到下一个未掌握环节 |
| 玩家在菜单选了不同对象 | 以当前合法对象继续，或恢复到选择步骤；不偷偷换回推荐配置 |
| 玩家主动关闭 | 当前小段可稍后继续；同一会话不反复弹同一提醒，不把关闭记成已学会 |
| 操作成功，教学记录保存失败 | 以真实业务状态恢复；不重复收费、发奖或强制再做一次不可逆操作 |
| 读档在拖放、洗炼待决、战斗选择中 | 优先恢复必须处理的实际状态，再决定是否继续引导 |
| 玩家反复失败 | 返回当前可执行的成长建议/借用练习；不因失利连续开放更多复杂功能 |

## 12. 怎样判断“所有内容都有引导”

维护一份课程覆盖清单，每项至少对应：入口、当前用途、一次合法操作、一次实际反馈、失败/取消说明、稍后重看位置。

覆盖范围：挂机与地点选择、单开/批开与奖励去向、装备六部位/品质/词缀/套装、背包仓库/锁定/整理、编队/卸下/角色查看、个人配卡、四类天赋、主线/调查/剧情战/领奖/回看、正式路线和所有实际节点、气力内力/目标/意图/主动牌/反应/状态/地势/任务机制、五种工具与两种合成、桌面商店与行旅钱、六伙伴职业和六NPC、教程复习、离线、高难、两种讨伐、设置与安全退出。

设置只在用户需要时指向缩放、语言、声音、置顶、退出等已实现选项；其他说明/图鉴入口按当前真实可用状态登记。未实现的邮件等占位入口不算已有内容，不编造每日任务、抽卡、转生、多人玩法的课程。3D城镇与旧NPC交互不进入默认桌面新手路线。

### 12.1 目录级覆盖

除上面的操作课程，还需遍历当前卡牌、敌人意图、地势、状态、装备套装/词缀、宝石和物品目录，逐项登记“真实说明、作用场景、来源、关联机制课”。所有条目都能查到，但不为每一张牌和每一颗宝石再弹一个强制教程。

首次接触同类新机制时只提示一项；已会的同类条目沿用解释。一次获得多个新词条时先展示收获，剩余解释供主动查看。说明/图鉴入口不存在或内容缺失的条目记为待制作，不能在覆盖清单中提前勾选完成。

## 13. 制作与验收顺序

1. **P0a开场定表：**冻结6个阶段箱逐个发放、第6箱1件装备＋8个材料箱的例外、固定课程和资源预算，验证单人强度。
2. **P0b最小短课框架：**补导航衔接、右键/拖放与实际状态判定、恢复/关闭/优先级，复用现有引导表面。
3. **P0c早期工具：**把固定短课接到对应教学箱开箱成功事件，验证资源能完成课程；普通掉落按需补课，无额外关卡或解锁费。
4. **P0d开场闭环：**整合A/B课程与早期工具分支。1-1可玩性不合格时停在这里修。
5. **P1完整1-2/1-3：**整合已完成C/D课程，补伙伴/NPC实际使用、调查、剧情战与批次收获的连续验收。
6. **P2构筑与定向购买：**实现E与H01～H03，用已学工具服务于套装、换牌与具体目标；不在此时才开放工具基础。
7. **P3战斗机制与全角色：**按I和13门课程目录补覆盖；借用练习独立验收，不修改玩家正式阵容。
8. **P4离线与长线：**完成J及回归登录、领收益、门票预算与高难链条。离线课程可按首次离开/重登时机提前。
9. **P5全程新档验收：**完全新档、不跳进度，记录“当前目标—实际操作数—收获—下一入口”。另测老玩家跳过、纯自动出牌、不同伙伴、卸下任一成员、满包、磁盘保存失败等适用路径。

“68项旧检查通过”仅证明上一批范围。完整新手流程完成必须另有上述新档连续证据、课程覆盖清单和各条异常路径结果。制作任务详见[实施拆分](../superpowers/plans/2026-09-15-full-onboarding-rollout.md)。
