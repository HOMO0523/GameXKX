名称与边框同档对应；纸面底色淡染，不能用饱和色淹没装备图。普通名称无描边、无流光。字内使用稳定的浅色，流光只作用于描边与边框。

最新裁决：最后两档取消金色虹彩镭射，改为铂金银白。以深银边缘衬托局部明亮反光，不做整字或整页白闪；第十档使用边长一致的小等边三角切面，并以少量切面高光区分于第九档。保留品质文字，避免只凭颜色辨认。色板是视觉方向预览，尚未代表 UE 材质接入完成。

后续细化：用户希望镭射感更明显。保留铂金银白作为基底，在描边、边框及局部表面反光中增强青蓝、紫粉、暖白的干涉色；字内仍为稳定浅色。第十档以规则三角切面分割反光，避免整体满色或整字变色。该细化替代“完全取消虹彩”的强度理解，但不回到金色主底。

## 装备背光与卡底设计

用户要求从至宝（第6档）起，装备图后方逐渐增加光效。背景承担品质分色，背光承担高阶强调，字内保持稳定浅色，描边与边框继续独立流光。

层级从后到前：带纹理的分档卡底 → 局部装备柔光 → 装备图 → 名称、品质文字与边框。光限制在卡面以内，不遮住装备形状和名称。

| 档位 | 卡底方向 | 装备背光（预览峰值/扩散） |
|---|---|---|
| 1 普通 | 暖灰纸面，边缘略深 | 无 |
| 2 稀有 | 灰绿，中心浅、边缘绿灰 | 无 |
| 3 珍稀 | 雾蓝，蓝灰边缘 | 无 |
| 4 传奇 | 蓝紫灰，保持纸纹 | 无 |
| 5 不朽 | 香槟金，避免纯黄铺底 | 无 |
| 6 至宝 | 杏金橙 | 暖金橙柔光；0.24 / 4px |
| 7 超凡 | 朱金与赤陶底色 | 金红柔光；0.32 / 7px |
| 8 天界 | 玫瑰金灰 | 金红粉柔光；0.40 / 10px |
| 9 登神 | 冷铂金、银灰边缘 | 冷银白光；0.50 / 12px |
| 10 宇宙 | 珍珠铂金、规则三角切面 | 铂金白光；0.62 / 15px，加少量切面高光 |

数值用于同屏比较，不是已确认的 UE 参数。扩散以104px装备图预览为基准。缓慢呼吸只在峰值的82%～100%之间变化，周期5秒；高级感通过边缘对比与局部反光体现，不通过全卡白闪体现。

卡底不再是同一米色纸面上的微弱色差：采用各档浅色中心与略深边缘，保留纸纹与明亮标题区。色板提供“装备柔光”开关，先关光看底色能否区分，再开光比较6～10档的增强节奏。50%时优先检查装备轮廓、普通/高阶区分及铂金两档的切面差异。

Tooltip 分为名称/等级品质、基础属性、词缀加成、镶嵌、套装效果。全部使用统一江湖体，栏目用间距和细分隔区分，保留术语 pill 样式。词缀直接显示实际条件与属性，例如“乘隙 +3.93%”改为“对破绽目标的伤害 +3.93%”。

镶嵌行：已装宝石为图标＋实际加成，空孔显示空装备格。属性读取实际装备实例与宝石，不使用商品包描述。商店等级按工具等级，未解锁默认为1级。
