# 挂机游戏存档完整性设计与审计

状态：用户已要求纳入当前 goal 并实现；以下为源码审计后的设计与验收要求，尚未宣称实现或通过。

## 玩家应获得的行为

继续游戏恢复最近一次可靠进度。挂机期间定期自动保存；领取收益、开箱、商店购买、强化/洗炼/镶嵌/合成、天赋、编队卡组、剧情奖励、课程奖励和讨伐结算在成功反馈前保存。正常退出先保存，失败时说明原因并允许重试。自动档与现有5个手动槽位分开；手动档显示时间、等级和所处关卡，覆盖与删除有明确确认。

中断三章讨伐后恢复章节、路线、卡组、遗物及其限次账本、未完成选牌、血量、剩余门票和结算回执，不免费重开补满血，也不因失败误扣票。普通挂机恢复战斗游标、各队员血量、冷却和累积未领收益。

## 当前实现与具体缺口

| 项目 | 当前证据 | 需补齐 |
|---|---|---|
| 5个手动槽 | MVPSubsystem SaveCurrentGame / LoadGameFromSlot；MainMenu槽预览 | 桌面可达入口、时间/状态、同档自动续玩关联 |
| 存档语义 | SaveMigration当前v41，丰富运行态校验 | 新增讨伐与自动存档元数据的迁移与往返 |
| 升级备份 | 迁移前写PreV备份、序列化等价回读、失败回滚 | 常规保存也要写入完整性、轮换备份与损坏恢复 |
| 当前写盘 | WriteSaveGameToSlot直接调用SaveGameToSlot | 写临时文件、回读验证、可靠替换；失败保留旧有效档 |
| 恢复点 | 部分通关、购买、主线、课程事务写固定桌面恢复点 | 全部关键资产交易、持续自动保存、档案隔离 |
| 离线读档 | ApplyOfflineTravelSinceLastUpdate；当前版本仅尝试写恢复点且忽略失败 | 保存新结算时间及待领奖励后才接受加载；不能反复计算同一区间 |
| 离线限制 | 新讨伐入口用天赋上限；普通读档仍调用纯规则旧入口 | 普通/讨伐统一解锁条件、收益倍率、分类时长上限 |
| 时间回拨 | SafeNow<=LastUpdated会把基准写成更早的当前时间 | 基准单调不退；长离线只算上限且消费整个观察区间，防重复读档补算 |
| 游历运行态 | 存档主体是RuntimeState；TrainingTravelRuntime为独立成员 | 核查保存当前敌我生命、阶段、计时器与游标；明确定点恢复 |
| 故障提示 | 多处通用迁移失败或忽略恢复点写失败 | 中英区分写失败、无权限/空间不足、损坏恢复、未来版本不兼容 |
| 开发隔离 | 教学WriteGuard、DevWritesSuppressed、自动化slot delegate | 所有新增保存入口遵守；测试绝不写正式存档 |

## 数据与可靠写入

- 角色持久数据：金币/元宝、经验等级、天赋、角色伙伴NPC、装备实例/词缀/孔位、宝石材料、背包与仓库槽位/锁定、卡组/编队、关卡首通、任务课程奖励集合。
- 局内数据：根随机种子与章节种子、节点选择、怪物配置与战斗队列、卡牌资源、遗物及限次证据、待选奖励、一次性回执、退战恢复点。
- 挂机数据：关卡、战斗游标、实存运行快照、时间基准、收益待领取账本、宝箱来源/种子、冷却、讨伐票预留与待消费债务。
- 独立设置：只支持中文/英文；江湖字体、HUD缩放、音量等设置跨档共享，不因读档重置。
- 存储元数据：档案身份、单调提交序号、UTC保存时间、内容校验、版本。恢复只选择同一档案的有效候选，不能把另一个槽位或新角色进度混入。
- 写入顺序：候选语义校验→内存序列化→临时文件→回读校验→保留上一有效备份→替换主文件。任何失败不得假报已保存；备份只从已验证的完整文件形成。
- 损坏主档：保留损坏文件供排查，验证同档备份并告知恢复时间。未来版本拒绝覆盖；不得静默新建角色吞掉旧档。

## 挂机时间与事务

自动保存采用脏标记与节流（初定30秒），关键交易立即保存；无变更不重复写盘。退出、切换档位、进入后台等正常生命周期触发保存。崩溃最大损失受自动保存间隔约束，关键已反馈交易必须已落盘。

离线区间以最近已消费时间基准到当前UTC计算；时间回拨不给收益且不降低基准。长离线按已解锁天赋各类上限支付，时间基准推进到观察结束，不让反复读档逐次领取超额部分。完成离线候选后把基准、收益、票库存和运行态一同落盘，再显示离线收益。领取从待领账本转入库存和金币经验同一次保存，重复点击/恢复回调只执行一次。

讨伐消费只发生在完整21场历练结束或完整三章挑战成功；同一候选事务扣1令、增1讨伐箱、记1次完整收益和回执。失败/退出保留票。离线不得消耗超过真实库存，不得收费却丢箱，最后一票完成后停止。

本次本地单机范围不引入账号、云同步或服务器校时。设计保证正常故障和重复回调的一致性；本地文件被用户主动整体回滚不等同于异常恢复。

## 验收矩阵

1. 全数据真实SaveGame往返：背包/仓库、装备宝石、角色卡组、天赋、课程剧情、讨伐票与宝箱来源、三章中断、遗物限次和待选动作。
2. 正常保存、自动保存、退出后重启、选择正确档位；语言/缩放保持；新游戏不偷载旧恢复点。
3. 临时写失败、替换失败、磁盘错误、主档截断/校验失败、备份损坏、未来版本：原有效档与内存状态按约定保持，提示准确。
4. 离线0秒、时间倒退、正常时长、超过上限、连续加载同档、退出后再次加载；普通和讨伐均遵守天赋限制。
5. 离线结算写失败不提交收益/扣票；领奖写失败不清待领；重复领取不会增发；开箱保存失败不耗箱且保持种子。
6. 一票/两票/零票、挂机中途退出、最后一票完成、战败、胜利待确认与已确认重载；保持扣票/箱/金币/经验严格一致。
7. 教学/开发快照/自动化不得污染正式档；保存最新用户试玩21文件快照作为保护证据，不用早期基线覆盖。
