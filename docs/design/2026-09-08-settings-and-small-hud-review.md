# 设置与 50% HUD 可读性分析

## 结论

设置应成为一个独立、可读的纸面窗口，而不是跟随 HUD 再缩小的小气泡。先解决显示和阅读，再整合已有声音、挂机、通知开关。新增功能需明确区分，不能把设计建议当成已实现。

## 现状依据

- 当前设置窗 220×184；标题 17、缩放标签 14、档位 12、旧引导按钮 14。源码：`BuildHudSettingsPanel`。
- HUD 提供 50/75/100 三档，设置窗位于同一个缩放树内；50% 时容器等效只有 110×92。
- 背包内部还使用一次 ScaleToFit：1450×849 放入 945×533，系数约 0.628；再乘 50%，总系数约 0.314。
- 因此 24 号背包卡名等效约 7.5，19 号说明约 6.0。这里指设计字号按布局比例折算，不是对所有显示器实际字形像素的断言。
- 挂机进度采用 11 号字，宝箱计数 14，角色候选的“等级”12、“已选/出战”13–14，均是小尺寸风险。
- 全屏战斗使用独立布局，不能简单套用桌面 HUD 的 50% 系数。
- `重置战斗引导` 的代码入口仍存在；用户的“没有这个功能了”可能指已取消或入口失效，已单独询问，暂不改其功能。

## 推荐设置结构

| 分组 | 设置项 | 当前能力 | 建议 |
|---|---|---|---|
| 界面与阅读 | HUD 大小 | 已有 50/75/100 | 保留，并提供尺寸预览 |
| 界面与阅读 | 文字大小：标准/大字 | 需新增 | 与 HUD 大小分开，不把所有文字机械缩小 |
| 界面与阅读 | 悬停详情阅读大小 | 需新增 | 桌面 tooltip 独立浮层，保持可读字号和宽度上限 |
| 界面与阅读 | 窗口置顶 | 已有快捷开关 | 设置与图钉共用同一状态 |
| 界面与阅读 | 恢复窗口位置 | 需新增入口 | 只恢复显示位置，不影响游戏进度 |
| 声音 | 静音 | 已有快捷开关 | 与喇叭同步，状态一眼可见 |
| 声音 | 总音量、音乐、音效 | 需新增/核对音频分组 | 先总音量，再按真实音频分组接音乐/音效 |
| 声音 | 后台静音 | 需新增 | 适合桌面挂机；与后台继续运行分开 |
| 挂机与战斗 | 失败后自动重试 | 已有规则和开关 | 统一入口，说明适用于游历 |
| 挂机与战斗 | 自动战斗 | 战斗界面已有 | 设置默认偏好前明确“当前战斗/后续战斗”的范围 |
| 挂机与战斗 | 战斗演出速度 | 需新增正式选项 | 只改展示速度，保持伤害、触发和结算顺序 |
| 挂机与战斗 | 前台/后台帧率 | 需新增 | 第二阶段做；先验证不会影响挂机推进和 UI 响应 |
| 通知 | 通知分类 | 已有 11 类 | 合并呈现为宝箱、战斗结果、角色成长、装备操作、系统 |
| 通知 | 日常记录密度 | 已有单条/5条/18条模式 | 统一为易理解名称；保留展开历史，不堆满日常界面 |
| 其他 | 界面语言 | 尚需完整本地化支持 | 中英文就绪后接入；不显示没有完成翻译的选项 |
| 其他 | 版本、反馈 | 建议 | 放页尾，不占主要设置空间 |

首版不增加怪物属性、配装、加道具等 Dev 项；F10 开发台保持独立。普通“恢复默认设置”绝不能重置存档。

## 排版与交互

- 设置窗挂在桌面独立浮层，HUD 50% 时仍保持可读；建议初始宽度约 560 屏幕像素，按工作区尺寸限制，不铺满屏幕。
- 使用项目统一九宫格纸底。标题、分组和内容左对齐，开关/档位固定在右侧；每行只讲一件事。
- 一级只保留“界面与阅读、声音、挂机与战斗、通知”。少量其他信息置于底部，避免嵌套菜单。
- 常用设置即时生效并保存，给明确选中状态；无需同时出现“应用、确认、保存”。关闭/再次点齿轮/Esc 返回之前界面。
- 恢复默认按分组处理，有简短确认。保留用户卡组草稿、背包选择和编队上下文。
- 图标不替代复杂说明：开关旁仍有清楚的短标签，补充解释放悬停或一行辅助说明。

## 50% 界面的整改优先级

| 优先级 | 部位 | 问题 | 处理方向 |
|---|---|---|---|
| P0 | 设置窗 | 容器和文字一起缩小 | 独立尺度，不再使用 220×184 小气泡 |
| P0 | 背包卡组/详情 | 二次缩放，文字压到约 31% | 提供小尺寸布局；卡组优先完整区域选牌，而非窄栏塞四列 |
| P0 | 桌面 tooltip | 说明随背包缩小 | 独立阅读层，保留纸底和 pill，不再叠乘缩放 |
| P1 | 挂机进度 | 11 号字，长关卡信息拥挤 | 放大关键进度，短显示名，次要信息移到悬停 |
| P1 | 角色候选 | 12 号“等级”、13–14 号状态 | 保留大等级数字，用少量状态标记替代重复小字 |
| P1 | 数量和主按钮 | 小数字、细描边 | 按最终显示尺寸设置下限；主动作短词、足够点击区域 |
| P2 | 页脚和解释 | 重复长句挤占空间 | 精简或移至悬停，避免所有辅助字都硬放大 |

不要全局统一放大所有字体：会让按钮溢出、卡片变高、文本遮住立绘。需在 50% 的可用空间下重新分配信息。
