# 本地化接入边界

当前基础：`GameXXKLocalization` 从 `Content/Localization/GameXXK/strings.json` 读取双语条目，用 `FTextLocalizationResource` 仅更新游戏文本，不改变编辑器语言。已有FText/Format历史的中英切换及独立偏好文件测试通过；当前只260个identity，不是完整覆盖。

## 保持语义再翻译表现

- 卡牌原有 `GameXXKCardText` 按中文做分支筛选和简述处理。**原始计算与过滤继续接收原始中文**；翻译放在最终显示层，不能全局把所有TEXT字面量替成英文。
- 固定句子使用稳定Key。现有NSLOCTEXT按精确namespace/key/nativeSource注册译文，保留FText格式化历史。
- FString::Printf等旧动态文本，在显示边界使用**整句模板匹配**：原中文模板单独保存为nativePattern，中文显示模板与英文译文都用编号参数。完整匹配后提取参数，再用FText::Format按各自语序生成；数值不得重新计算。
- 模板匹配不是逐词替换。类型和参数数量需校验；文本参数可递归解析名字/短语，设置深度与缓存上限；未匹配项保留中文并进入审计，不能悄悄冒充已翻译。
- 同一中文词有不同上下文（例如品质“普通”与难度“普通”）必须在调用点用明确Key，不能依赖Source映射的第一项。

## Tooltip与Pill

- 先用原始文本完成规则分支/详述筛选，再把最终整句翻译为目标语言。
- 展示用Pill词库支持中英，并将显示名映射回稳定的规范术语；颜色和分类使用规范术语。旧DescribeHelp等语义扫描仍使用中文词库，避免切英文后漏掉机制。
- 英文关键词匹配需词边界，不能把Mark误识别进Market等单词。合并的“蓄力／重箭”保留合并术语身份。
- CardTooltip保存原始compact/expanded/pill内容；语言revision变化时重建当前阅读层，保留Shift/Ctrl模式与配置上下文。
- 名称设置为目标语言后重新应用CardName/EquipmentQuality样式或更新TextAspect，依赖实际FontMeasure；不改字体资产。
- 换行按实际测量并保持英文词边界；检查长标题、最大数值、屏幕边缘、50/75/100%及旧阅读缓存。
