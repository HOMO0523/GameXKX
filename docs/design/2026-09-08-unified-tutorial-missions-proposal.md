# 统一教学任务方案：基础、六职业、六 NPC

状态：设计提案，未创建新关卡、未修改引导存档、未发放金币。

用户已确认：**每个独立教学任务首次通关奖励 100000 局外金币，重复通关不重复领取。**

## 一、任务结构

建议 13 个主任务：基础 1 个、职业 6 个、NPC 6 个。每个主任务一个首通奖励，共 1300000 局外金币。主任务内部的教学段、分支练习和综合考核不重复发奖。

主角基础操作放在基础任务；主角六方向与伙伴的差异放在对应职业任务的小节中，不额外拆成一批奖励任务。若后续明确要独立主角进阶任务，再另立任务 ID 和奖励预算。

入口建议为「演武教学」，从设置中的「教学」或角色/卡组页面的「学习玩法」进入。目录分「基础」「职业」「同行 NPC」，显示核心机制、预计时长、学习进度、首通奖励状态。新玩家首次轻提示，不要求先做完全部任务才允许正常游玩。

统一流程：借用教学阵容与合法牌组 → 简短示范 → 分段实操 → 无强制点选的综合挑战 → 完成机制目标并获胜 → 首通结算 → 返回原界面。

普通任务目标约 4–6 分钟，法师等复杂任务可 6–8 分钟，按段保存。完整系列并非一次强制完成的长教程。

## 二、13 个主任务

### 00 初入江湖：基础教学

教学内容：

1. 认识三人队伍、共享气力、各自内力、气血与护甲；区别局内资源与局外金币。
2. 读取敌方意图和目标编号，出指向牌、取消选目标、打出无需手选的群体牌。
3. 结束回合、观察受击和一次状态结算；了解抽牌、弃牌、内力不足时为何不能出牌。
4. 使用悬停说明、简述/详述；认识呼吸灯表示当前联动机会，而不是必须点击的命令。
5. 路线内走一个短教学链，认识商店、事件、篝火、遗物和首领结算；只使用当前有效设计。
6. 返回桌面，打开编队、选择伙伴、进入共用卡组编辑，明确“查看角色”和“编入队伍”不同。
7. 认识背包与仓库、穿戴装备、卡组需达到合法张数；教学物品不写入真实背包。

考核：玩家亲自完成一次合法出牌、一项防护决策、一次回合结束和短战斗胜利；角色/卡组操作在教学草稿里完成，不破坏真实配置。

### 01 刀客：首尾成招

- 核心段：主动首牌的冲锋效果 → 中间其他角色接牌 → 用有收招效果的牌结束自己的主动出牌序列 → 结束回合验证收招。
- 必须说明：这里不是机械“第 1/2/3 张刀客牌”。要按当前运行时的队伍主动牌首尾与具体牌说明判断；自动重放不冒充一次新的主动操作。
- 分支练习：流血及触发、气势/破绽爆发、反击借势、归鞘蓄势。每段换一套固定合法教学牌组。
- 主角对照：识别主角同系牌提供的首尾协作效果与伙伴专属规则的区别。
- 通关目标：真正触发一次冲锋连动和一次收招，在综合战中完成规定连动后获胜。

### 02 守卫：护友反制

- 核心段：获得护甲、判断敌方意图、保护被集火友方、让敌人攻击后观察反应。
- 明确区别：护甲是防护资源；格挡/反击是具体反应及次数，不能把“有护甲”讲成“已有格挡次数”。
- 分支练习：叠甲、援护/转移目标、护甲转伤、消耗护甲与保甲取舍。
- 主角对照：同系防护牌给谁使用、反应来源归属。
- 通关目标：一次真实援护或格挡反应，一次基于护甲的伤害结算，并保护指定友方赢下战斗。

### 03 药师：药理相生

- 核心段：首次主动出牌开启本场药方 → 查看药方图标与提示 → 在真实条件下触发药方 → 观察药效变化。
- 治疗段：给受伤友方治疗、清除状态，区别名义治疗量与实际恢复量；满血目标不能用于虚假完成“治疗成功”。
- 进攻段：识别牌的敌我目标语义，利用药效反向伤害、叠加中毒/流血/灼烧与毒爆。
- 分支段：低血量、治疗次数、净化、群体生命变化等代表性药方。其余药方可在任务内自由练习，不另发主任务奖励。
- 通关目标：开启并实际触发指定药方，完成一次有效救治和一次正确的进攻联动后获胜。

### 04 弓手：蓄势穿杨

- 核心段：积累蓄力 → 选择时机打出重箭 → 观察蓄力消耗和追加效果。
- 分支练习：流血连射、重箭追加、毒箭/毒爆、灵动与反应配合。
- 强调目标仍存活、触发前后快照与资源来源；不能只看牌上一个伤害数字。
- 主角对照：同系重箭如何借助已有蓄力，按具体牌的来源与锁定时点解释。
- 通关目标：一次正蓄力消耗的真实重箭联动，完成指定分支策略后获胜。

### 05 法师：五法成阵

- 核心段：选择首张牌 → 锁定本次任务与阵赏 → 主动打出携带的五张不同法师牌 → 按首次出牌顺序重放 → 结算首牌阵赏。
- 进度必须对应固定卡位；未完成置灰，完成后点亮并显示实际顺序。悬停看缺哪张牌。
- 火/冰/雷/通用各做一个短场景：灼烧触发、内力/护甲转换、标记逐层落雷、通用牌的编序收益。保留简单落雷，不启用已暂停的 057 全屏效果。
- 加入抽弃牌练习：把一张任务牌弃掉后，使用合法检索找回并完成任务，说明弃牌不等于永久少带牌。
- 解释主动出牌与免费重放的区别，遵守该角色实际的任务完成次数限制。
- 主角对照：主角法术任务与伙伴五牌任务分别讲清，不能统一写成五张。
- 通关目标：亲自完成一轮五牌任务，验证重放次序和阵赏；综合挑战自行选择首牌并获胜。

### 06 阵师：因地布阵

- 核心段：读取当前地势 → 真正切换地势 → 触发地势收益 → 观察对应目标与数值。
- 比较攻击型和防护/恢复型地势，按当前规则选用。其他地势放入可复习的任务内练习页。
- 分支段：增加收益次数、提前布置下一次收益、配合同伴攻防与治疗。
- 同一地势再选一次若运行时无实际换场，不算完成“切换地势”；重复触发地势收益也不算出牌重放。
- 通关目标：一次真实换场，一次增益后的地势结算，按场上局势自主选择后获胜。

### 07 土司首领：护友合击

- 以当前四选三卡池教学，重点是刀客式首尾协作与守卫式护甲/格挡，而不是让 NPC 单独刷伤害。
- 用「寨主号令」辨认最高攻击友方及代为攻击；用「石门守势」或「土司军令」完成护友/反应；再演示「盟寨誓约」的队伍合击。
- 两个短段覆盖四张牌，保持每场仍是合法三张 NPC 牌。
- 通关目标：由正确友方执行一次联动攻击、一次护友反应或协同收招，再获胜。

### 08 宋金宝：借势连招

- 「赏钱鼓舞」的资源支援与友方攻击；反击/首尾协作；检索把三张不同 NPC 牌串起来。
- 亲手完成一次三牌任务，观察三次基础重放与首牌奖励。说明它不是法师伙伴的五牌任务。
- 演示「一诺千金」的减费窗口，区分临时免费与永久零费。
- 通关目标：一次正确支援/借招，三张不同牌任务完成并结算正确阵赏后获胜。

### 09 月白：残卷成阵

- 以**最新四张牌基础均为 1 气**教学，避免旧零气文案。
- 「残卷批注」抽牌与地势收益、「山河残图」护甲/回内、点灯触发灼烧，三张不同牌完成任务。
- 第二短段替换一张，演示「月白照夜」首牌奖励中的标记和逐层落雷。
- 核心是预算共享气力、选择首牌阵赏，并分清地势重复结算与任务重放。
- 通关目标：预算足够的主动气力、完成三牌任务并看到一种阵赏，另一段验证落雷奖励。重放免费，主动出牌按实际减费后扣费。

### 10 周光祖：药地相济

- 「异草辨识」的敌我目标与药效、「黄山敷治」的群体生命变化；「地志摹图」触发地势；「岩粉封脉」的状态与毒爆。
- 通过两段三牌配置覆盖四张牌，教会按队伍血线选择支援还是进攻。
- 通关目标：实际完成治疗/净化、地势收益和一次有效进攻联动后获胜。

### 11 金贵：蓄势周旋

- 「市井耳目」「杂役筹备」给最高攻击友方蓄力，并按牌的锁定时点结算重箭；「巧言周旋」保护最高护甲友方。
- 明确 NPC 的蓄力来源可以是其他角色，不能把蓄力都画在金贵自己身上。
- 「后巷脱身」按当前真实支持范围说明，不能把尚未完成的旧行为写成必过目标。
- 通关目标：正确资源来源的一次重箭、一次保护/反应配合后获胜。

### 12 琼梅儿：蛊箭济人

- 追踪/蓄力协作与「蛊雾迷踪」的流血、中毒、毒爆；「银铃镇心」净化/治疗与「山歌唤灵」群体支援。
- 两段三牌配置覆盖四张牌。设置明确的受伤友方和带状态敌人，避免对空气操作。
- 通关目标：一次有效毒爆、一次实际净化或治疗、一次蓄力协作后获胜。

## 三、统一交互要求

- 同一个纸面目录与 BattleBoard，纯 2D 桌面主地图，不为教程切回 3D 旧流程。
- 一次只强调一个目标，短句描述“做什么、为什么”。正文按实际阅读尺度显示，不跟随 50% HUD 再次缩小。
- 使用现有状态图标、pill、意图卡与呼吸灯；不用内部枚举、CardId、Standard/Training 等词当玩家说明。
- 示范阶段可限制明显无关操作，但始终能暂停、退出、重试；目标丢失或界面关闭必须释放输入锁，尤其覆盖 F10/设置/切窗口恢复。
- 综合挑战解除逐按钮强制提示。跳过说明后仍可自己通关领奖；仅跳过步骤不能被算作机制完成。
- 自动战斗不代替玩家完成首次教学动作；通关后可在自由练习中体验自动策略。
- 错误操作给具体反馈，如“这次没有消耗蓄力”“护甲有了，但还没获得格挡次数”，允许重试当前段，不扣真实资源。
- NPC 教学覆盖四张可选牌，但每次三张的规则保持；不为了教程允许违法少带牌或多带牌。
- 首版建议教学时暂停真实游历推进，保存并恢复原进度；教学战斗用独立借用阵容，杜绝真实单位被教学伤害、耗药或覆盖装备。若以后要求同时挂机，需独立状态隔离后再开放。

## 四、首通奖励与存档

1. 每个主任务固定奖励 100000 局外金币，不能发到行旅钱/局内货币。
2. 机制目标全部达成且教学挑战获胜才算通关；失败、退出、仅点击说明不发奖。
3. 首通完成、金币增加、已领奖记录应作为同一笔持久化提交；重复回调、重进结算或正常读档重试不能多发。
4. 以稳定任务 ID 记录奖励资格，教案版本更新、重置提示偏好、重玩教程都不清空领奖标记。
5. 每个存档独立记录；本地存档的手工回滚不应被宣称为可以绝对防止。
6. 设置中的旧“重置战斗引导”建议升级为“打开演武教学/重新练习”，不提供会误清领奖资格的重置。
7. Dev 自动化测试使用隔离存档验证到账，不把测试奖励写进玩家原档。

## 五、现有系统复用与缺口

可复用：GuideAsset 数据、GuideRules 步骤状态机、GuideCoordinator 输入锁/取消、GuideTargetRegistry、现有气泡/高亮；BattleBoard 实战、卡牌定义、状态与伤害结果、已有临时战斗构造能力。

当前缺少：统一任务目录、13 个可玩的教学场景、分段进度、真实机制目标判定、每任务首通奖励账本、教学状态隔离、退出恢复和专门的教学结算页。现有 GuideProgress 主要保存活动引导和完成步骤，没有每任务奖励记录，不能简单复用一个“看过教程”布尔值发钱。

旧内容必须同步检查：九份基础 Guide JSON、旧 Tutorial01 专用绑定、商店/事件/篝火/宝箱/首领/结算的旧文案。已发现篝火 JSON 仍写“恢复30%最大气血”，与当前已批准的遗物方案不一致。

职业技能和展示从当前卡牌、怪物、装备定义读取；不在教程文案里再维护一套独立伤害公式。任务判定按实际结果归因：主动/重放、伤害来源、资源真实消耗、真实治疗量、真实地势变化。

## 六、实现顺序和验收

1. 先做统一目录、独立教学会话、奖励账本和基础任务，验证退出不丢进度。
2. 刀客/守卫/弓手，建立首尾牌、反应、资源消耗的可复用目标。
3. 药师/阵师/法师，补药方、地势、首次顺序与重放目标。
4. 六 NPC，复用机制目标并覆盖每人四选三组合。
5. 最后统一清理旧引导入口与过时文案，做真实手动通关和存档回归。

每个任务必须有：固定种子正常通关、错误操作可恢复、提示跳过后仍需完成挑战、失败/退出不领奖、首次只加100000、重复领奖不增加、读档恢复、重玩保留领奖状态、50%HUD可读、关闭/F10/设置切换无残留锁。NPC 四种缺牌组合需单独做规则覆盖，不等于另发四份奖励。

本轮只完成方案，不把“编写了说明文案”当作 13 个任务已经实现。
