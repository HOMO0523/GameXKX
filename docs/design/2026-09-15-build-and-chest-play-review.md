# 《霞客行》整体设计与首轮试玩分析

日期：2026-09-15。项目：main，HEAD `edf280cbfb274655e381c9223b98d61904875e41`。

后续讨论：用户认可渐进开放方向，并进一步纠正“挂机条是挂机条，局内是局内”。原渐进解锁单线草稿已停止作为执行依据，当前理解见[玩法边界纠偏](2026-09-15-idle-inrun-boundary-correction.md)。本报告保留原始试玩事实与当时分析，不代表新手流程已经验证。

## 结论

用户确认的留存核心是“构筑与开箱爽感”，任务集中发放金币和宝箱为此服务。本次自然新档的实际过程支持这一设计意图：前三个任务提供30万金币，定向购买与挂机开箱共同让刀客形成破军2件＋青囊2件，破军额外抽牌在首场剧情战斗中真实触发，队伍在第一回合的敌方阶段获胜。

优先改善方向是让玩家清楚感知奖励及其构筑用途。不能仅凭10万金币这个绝对数字判定奖励过量，也不能把一场初期胜利推导为全游戏平衡完成。

### 战斗中兑现的构筑

1. 首牌回锋架势，建立刀客冲锋。
2. 土司首领的寨主号令接续：由最高攻击的主角攻击黄鼬，给予相应防护；回锋生成一张0气/0内临时复制牌。
3. 破军2件触发一次额外抽牌。快照明确记录`Set.PoJun.2`本回合触发数为1，手牌出现复制牌和额外抽到的封喉。
4. 使用复制的寨主号令再次攻击；风身步提供灵动并抽牌弃牌，满血时弃掉归元术。
5. 青锋一式击杀残血黄鼬，为其他角色的下一张牌减费。
6. 用减费疾雨连斩攻击公鸡。进入敌方阶段前，公鸡剩20HP并有流血；队伍已有格挡、防护。
7. 结束回合后获胜，剧情状态记录`bBattleWon=true`并返回桌面。

这条链证明共享气力、卡牌来源、跨角色衔接和套装收益可以一起生效。青囊2件本场未验证触发：所打出的疾雨连斩经过减费，不能把“装备已激活”写成“本场已触发”。

## 综合分析

### 1. 大额任务奖励的设计意图得到支持

前三任务30万金币实际对应两件定向装备与一颗宝石，购买力有清楚尺度。后续7个自然挂机箱把角色身上的组合补完整。评价应围绕“获得机会—整理选择—形成组合—战斗验证”的转化，而非金币位数。

本轮样本还表明，定向购买并不保证立刻成型：两件破军都出了武器，但可分给不同队员；随后宝箱出的头部才补齐刀客两件套。这种随机等待能产生期待，前提是玩家能看懂自己距离组合还差什么。

### 2. 战斗已经能给构筑提供回报

本次最明确的成功点是：穿上套装后，正确的出牌顺序真的多了一张牌、一个免费动作，并与另一名角色的技能接上。玩家的思考空间来自来源角色、出牌顺序、气力/内力、目标、敌人意图与反应；这些规则有形成不同打法的基础。

后续若要评价六职业是否同样有趣，应保持关卡、等级和装备预算可比，分别实际体验。当前不建议基于单场4级剧情战就改动全局职业强弱。

### 3. 开箱的“收获展示”目前偏弱

实际商店购买后有独立“获得物品”展示。挂机箱单开与右键批开则直接入背包，主要反馈为顶部一行通知；批量结束时最后一条物品信息占据通知区。通知历史入口存在，本次未展开验证。

建议优先设计轻量、可跳过或折叠的批次收获摘要：展示数量、最高品质、新部位，以及可能凑成的套装。保留快速连开，不用强制长动画拖慢操作。这里直接服务于用户确认的核心乐趣。

### 4. 构筑信息需要帮助玩家形成行动

玩家目前能读完整卡文和套装条款，但仍需自己跨角色、跨界面核对哪些东西可以一起用。初始六件基础装备也在背包内，23步入门主要教浏览，未要求实际穿上装备。

可优先考虑：当前角色套装件数、已生效档位、缺少部位、适合当前队伍的物品提示；教程加入一次真实穿戴或一次两件套验证。建议不自动替用户换装或修改卡组。

### 5. 挂机与主动构筑存在明确作用边界

`GameXXKTrainingRules.cpp`的游历步骤直接使用队员攻击扣怪物HP，敌方反击直接扣队员HP；`BuildTrainingTravelParty`投影HP和攻击。卡组顺序、治疗牌、格挡与地势组合不会像主动战斗一样逐步运行。

因此局内构筑推动开箱的主要路径之一是挑战解锁更好的挂机地点；同一地点的挂机效率则主要受属性与相关天赋影响。这个设计可以成立，需要向玩家说明哪些收益用于主动战斗、哪些用于游历，避免防御/治疗构筑玩家期待挂机执行相同机制。

### 6. 两个口径问题与一个待复核表现

- **剧情入口文案仍有旧流程描述。** S00-04启程实际显示“进入1-1，在剧情问号处击退拦路兽群”，按钮则直接进入剧情战斗。应随已确认的直达流程统一文案。
- **宝石包数据描述与购买实现不同。** `GameXXKMetaShopRules.cpp`桌面商品描述写采用高级箱宝石品质，购买分支固定`Rare`。本次实际购得稀有雷击宝石；单次产物不能统计证明固定概率，但源码已明确固定值。需要确定应保留哪种规则并统一；本次未改。
- **战后对白展开待复核。** 胜利后返回挂机，快照记录剧情已胜利并停在战后Dialogue第0句，但停止前的桌面画面未自动展开对白。用户随后要求停止，未继续重试；另有窗口前后台变化，暂不直接判为稳定缺陷。

另一个仅源码核对到的中后期边界：桌面商店装备和购买宝箱的等级取工具等级，而工具等级上限10；合成产物等级区间另由制作等级计算。商店中后期的定位应结合真实玩法再审，不能沿用旧总纲假定所有来源等级一致。

## 后续优先顺序（建议，未实施）

1. 开箱批次收获展示与可快速返回构筑的入口。
2. 当前套装进度、激活档位和新物品用途提示。
3. 修正文案/实现口径，并复核战后对白接续。
4. 补玩普通完整路线、五种工具、六职业与讨伐，再讨论掉率、金币和长期平衡调整。
