# 天赋升级交互修订

用户授权在 `codex/ui-visual-optimization` 分支完成本次修复。

- 升级按钮固定为 64 逻辑像素高，文字改为 24 号江湖体；沿用已批准的纸质按钮。价格、状态与按钮各自占位，升级和失败时按钮位置保持稳定。
- 天赋拖动区域改为不透明的中性深灰，节点名称和等级改为浅色，以保留对比度。
- 天赋面板持续打开时，金币到账或在别处消费会更新按钮可用状态。战斗与桌面之间切换也同步刷新；不再需要重新选节点或关闭面板。
- 正常显示当前等级；金币不足、前置未满足或购买被运行时拒绝时显示原因。升级仍由原有权威购买函数执行，每次点击只升一级。
- 保留所选节点、拖动位置和升级按钮对象。金币变化只更新原有控件；成功购买后仍按原机制在下一帧刷新图中节点。

校准后的天赋价格与效果不变。本次仅修改天赋 UI 和聚焦回归检查，不涉及怪物、宝石或装备定价。
