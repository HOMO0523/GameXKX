# 第一章：项目定位与 MVP

GameXXK 是共享手牌、共享气力的队伍构筑回合制卡牌 RPG。主角、永久伙伴和任务 NPC 的牌在同一局内牌组里接续，但每张牌保留来源角色和职业，使任务、套装与职业机制能准确归属。

体验目标是“强度接近、玩法不同”：刀客编排首尾，守卫经营护甲，药师经营生命变化与药效，弓手积蓄蓄力释放重箭，法师按顺序完成任务，阵师只凭出生获得的两种换场组织全地势收益。条件不成立时卡牌仍有基础效果，构筑失败不能表现为指向失效或卡在手中。

当前 MVP 主链为：`L_Main` 主菜单 → 新游戏 → `/Game/GameXXK/Maps/L_QingshanInn` → 城镇 UI → F 接任务 → 手动保存任务接受与玩家位置（任务 NPC 固定不跟随）→ 城镇按钮进入路线图 → 节点进入战斗。该骨架状态为“已实现”；完整职业重做、套装重做、六地势美术和新平衡仍分别标状态。

规范冲突（待用户裁决）：仓库 `AGENTS.md` 仍保留“接任务后跟随者激活且 NPC 位置可保存”的旧 MVP 验收；当前生产代码 `AcceptTownQuest` 明确把 `bFollowerJoined`、`bHasQuestNpcLocation` 设为 `false`。当前真实 PIE 验收结论为“任务已接受 + 玩家位置持久化，NPC 固定不跟随”。本规划按代码与真实 PIE 标当前实现，不把旧验收误报为已实现；是否恢复跟随必须由用户另行裁决。

# 第二章：主菜单与存档入口

主菜单负责新游戏、继续/读取指定存档、删除槽位、设置与退出。新游戏不读取旧槽；继续严格打开玩家选择的槽；删除只影响明确槽并二次确认。项目有五个手动槽，接任务、进路线和购买不隐式覆盖手动存档。

主菜单布局保持当前确认状态，只修数据接线、禁用态和错误文案。保存失败必须保留旧槽。状态为“已实现”，多版本迁移和异常磁盘路径持续回归。

# 第三章：城镇、任务与角色准备

青山客栈是局外准备中心：与任务 NPC 交互、接取/推进任务、管理队伍和装备、进入商店与路线。F 接任务改变运行状态；玩家明确手动保存后持久化任务接受与玩家位置。当前任务 NPC 保持关卡固定位置，不加入跟随，也不写任务 NPC 位置标志。

背包/角色页继续使用当前布局，展示主角 8 张、伙伴 5 张和 NPC 3 张三个独立配置来源。装备六槽、库存和角色信息留在既有模板，不因新机制重排。

天赋与称号当前只确定“沿用背包视觉模板、不改变已确认布局”。页面是页签还是独立页、数据作用域、数值和入口均未批准，状态为“待单独评审”；批准前不创建假页签或臆造节点。

# 第四章：三章节路线与局内外循环

三章沿用同结构路线，首领依次为金钱鼠、黑熊、老虎。每章四种普通怪、两种精英和一个首领，合计 12 普通、6 精英、3 首领。普通节点两只普通怪置于 1P/3P；精英在 2P、两侧普通；首领在 2P、两侧精英。

进入路线时快照玩家等级：普通同级，精英 +1，首领 +2，均封顶 20；路线中途升级不改当前快照。路线包含普通战、精英战、事件、商店和首领。路线金币、运行牌、遗物和商店库存与永久资源分离。

路线初始金币 60；普通/精英/首领奖励 20/35/50。路线牌可进入本次牌组，运行上限 30；不能改写永久伙伴出生六牌。三章骨架和目录为“已实现”，完整章节差异与目标平衡为“部分实现”。

# 第六章：战斗回合、资源、目标与胜负

玩家共享气力和手牌，角色保留独立生命、内力、攻击、防御、护甲、状态和来源。主动出牌按“当前费用与目标预览 → 原子支付/移牌 → 基础效果 → 条件效果 → 自动队列 → 弃置/消耗”结算。非法目标或资源不足不扣费、不移牌。

目标模式固定为无目标、自身、单敌、单友、另一友方、敌群、友群、其他友群、随机敌人、最低生命友方、最低生命其他友方、任意存活单位。玩家指向和效果落点分离；法术优先敌群，对自身的效果固定落来源自身；阵师跨地势不改变目标模式。

普通直接伤害先计算攻击百分比/固定值/气势，再受虚弱、防御、破绽和标记影响，随后由护甲吸收。DoT、反向治疗和非致死自损使用各自管线。双方在同一结算链同时死亡时按玩家胜利。

自动重放、协战、反击、格挡、DoT 和任务回放不算主动出牌，不改变刀客首牌/末牌、不推进法术任务、不增加追风套出牌计数。

# 第八章：六职业体系

## 刀客

每张刀客牌有独特冲锋和收招。冲锋要求本回合首张主动牌，并强化下一张任意角色牌；收招要求结束回合前末张主动牌是刀客牌，且收招不直接伤害。目标 18 张为裂风斩、回锋架势两核心，加血刃、断势、游刃、藏锋各4。血势按目标实时流血每层 +10 个百分点；乘势按自身气势每层 +10 个百分点。完整表已确认，代码待落地。

## 守卫

主要守护牌同时登记格挡。只保留两种护甲转换：不耗甲的 `100%攻击+当前护甲`；仅群体攻击可耗尽全部护甲，倍率每甲 +20 个百分点。取消部分耗甲。玄甲允许保留50%护甲，但套装阶位与另两档待单独评审。守卫逐卡18表待单独评审。

## 药师

两条主线是药效/治疗反转与 DoT/毒爆。单体基础治疗不超12，群体不超6，主要依赖药效；主动扣友方生命最低留1。治疗牌用于敌方时按治疗值令其直接失去生命，除非已批准的卡明确改为中毒/灼烧与毒爆。每张药方首打加1气并激活独特全局监听；监听终端不递归。完整18表待单独评审，药方底层待落地。

## 弓手

方向为固定流血多段、蓄力重箭、灵动和气力过牌。所有攻击基础效果可独立使用，之后耗尽蓄力按本牌逐层收益。连珠箭确认施加流血8、中毒6并在结算后蓄力1，重箭每层追加50%攻击；锐意感知抽2、回1气、灵动2、蓄力3；毒矢中毒6并毒爆，重箭逐层再毒爆；回环箭逐层抽牌。完整18表待单独评审。

## 法师

牌以0气为主、最多1气，基础中等、任务奖强。主角8张、伙伴5张、NPC3张各自全部主动一次后，按首次顺序重放基础，只执行启动牌奖励。炎法靠灼烧与次序；寒冰基础回内/叠甲、溢出内力100%转甲、当前内力25%参与卡牌护甲，任务奖耗甲按每甲20%群攻；雷法群体标记，任务奖按锁定标记层数落雷。主角任务已实现；伙伴/NPC任务和伙伴18表待落地或评审。

## 阵师

目标18张为六换场和十二全地势收益。出生只获两张换场，另四张按3主流派+1全池随机收益生成，终身不再解锁。六地势固定收益：平原敌灼烧2；山崖敌破绽2/标记1；森林全队治疗4；水岸/渡口全队内力3；村寨抽1/全队甲4；洞穴全队甲8/格挡1。错误地势保留基础效果，匹配地势强效果，目标模式固定。整体待落地。

# 第十一章：敌人意图、仇恨与难度

敌人意图显示目标范围、伤害段数、状态、蓄力和特殊行为。敌方每执行一张牌/意图触发自身灼烧一次，不按多段重复。群体意图忽略仇恨改向；单体先处理守护/强制改向，再按我方标记层数与意图规则选目标。敌人蓄力是独立待释放意图字段，普通净化不能清除。

## 总体验收结论

项目达到本规划的“优化落地完美”标准，必须同时满足：

1. 玩家不借助开发快捷入口走通菜单、城镇、任务、三章路线和战斗。
2. 198张当前/替换后目录数量、ID、文本、目标和效果一致；主角8、伙伴5、NPC3来源分明。

4. 六职业和六名NPC各自最小循环可用，跨职业组合提高上限但不强制唯一答案。
5. 六套装没有旧新规则混用，全队唯一和每穿戴者次数准确。
6. 新模拟能使用铺垫牌，成长档分别落入目标区间，无配置在全部节点0%或100%。
7. UI布局无非授权变更；Task11 短 Tooltip 精确测试通过；天赋/称号无未批准实现。
8. 六地势背景低饱和、易区分、与角色怪物同一水墨造型语言。
9. 旧存档安全迁移，未批准的伙伴收藏不被静默重抽。
10. 单元、目录、组合、Board、冷编译和完整PIE证据全部留档。
