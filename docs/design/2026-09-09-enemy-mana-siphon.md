# 怪物内力吸取

用户要求给部分怪物加入吸收角色内力的能力，实际限制出牌。用户随后明确数值：金钱鼠三难度均8点、巨蟾三难度均6点。现有怪物没有内力池，本轮将吸取实现为目标当前内力的扣除；不改变其最大内力。它是资源效果，伤害宝石、暴击、防御和法抗不放大或减免吸取点数。

|怪物|招式|普通/困难/地狱|目标与触发|
|---|---|---|---|
|金钱鼠|贪印、闭门聚财、重利封锁（分别为三个阶段）|8/8/8点|当前内力最高的存活角色；同值按稳定站位；保留意图预测与实际对象的一致性|
|巨蟾|卷舌|6/6/6点|仅在前段攻击命中后，对实际受击者吸取一次；闪避不吸取，援护时跟随实际承伤角色|

吸取量为min(当前内力, 名义量)，不能扣成负数；目标已倒地或来源已倒地时不继续吸取。巨蟾原有回血仍按原公式，吸取不额外转化为回血或护甲。保持各阶段牌数与原动作序列，新增能力写入原招式效果列表。

界面：怪物意图/tooltip写明吸取点数和对象；内力条使用权威新值，后续出牌检查立即按剩余内力执行；战报显示实际吸取量。不给资源损失伪造生命伤害包。

验证：每个难度、零/少量内力、最高内力择人同值顺序、合法意图预测、援护与闪避、一次攻击只吸取一次、吸取后出牌受限、保存后恢复同一意图、原伤害/回血/牌数保持。怪物总表写入上述范围与实际效果。
