## 4. 卡牌数据模板

每张最终卡至少包含：

| 字段 | 规则 |
|---|---|
| CardId | 稳定、唯一、可迁移；显示名可改但 ID 不静默复用 |
| 显示名 | 与关键词词典一致；不把内部枚举名暴露给玩家 |
| 来源 | 主角 / 伙伴职业 / 任务 NPC / 路线 |
| 稀有度 | 普通 / 稀有 / 珍稀；影响奖励与合并，不隐式改规则 |
| 费用 | 基础气力、基础内力；当前费用在预览和确认时使用同一解析器 |
| 目标模式 | 固定枚举；条件只改变效果，不在确认后突然改目标 |
| 基础效果 | 条件不满足时仍可结算的最低价值 |
| 条件/关键词段 | 冲锋、收招、重箭、地势、任务奖励等，写明触发点 |
| 消耗/临时 | 是否进入消耗区，临时复制的到期与不可再复制规则 |
| 所有者/施放者 | 用于职业、任务、套装、药效和反应来源判定 |
| 自动重放安全 | 原目标失效策略、是否只重放基础、禁止递归标记 |

## 5. 数值口径

### 5.1 费用

- 0 气牌必须受消耗、弃牌、内力、任务需求或低基础价值约束；不能无条件净抽与回气形成无限循环。
- 法师以 0 气为主、最多 1 气；1 气牌常承担检索任务牌。
- NPC 强牌以 0–1 气为主，2 气用于全队或完整爆发；其三张组合必须自洽。
- 药方牌第一次打出在基础气力上 +1，之后恢复基础费用。
- 内力不应只是装饰：高倍率、多次重放、群体和完整循环牌应有可感知内力成本；火法和雷法相对低内耗，寒冰把内力当护甲引擎。

### 5.2 攻击倍率

- `100% 攻击`表示 `floor(攻击力 × 1.0)` 进入直接伤害管线。
- 气势全局每层固定 +1；卡牌写乘势/血势时，每层额外增加 10 个百分点倍率。
- 标记每层直接伤害 +15%、每个命中段减 1；破绽每层 +10%、命中后全耗。
- 守卫格挡为 `100% 攻击 + 当前护甲`，不耗甲。
- 守卫群攻全耗甲为 `基础倍率 + 20% × 实际消耗护甲`。
- 寒冰任务全耗甲按每点护甲一段 20% 群体攻击，读取快照后清空。
- 《剑意贯虹》固定为 `攻击力×(260%+20%×N)+N`，耗尽气势。

### 5.3 治疗与生命变化

- 药师单体治疗基础值不超过 12，群体不超过 6；药效每层 +1。
- 群体治疗只耗一次药效快照，但每个目标获得完整增量。
- 对敌反向治疗直接失去同数值生命，不经过防御和护甲，不算普通攻击。
- 友方主动自损最低保留 1 生命；DoT 和敌方伤害不受此保护。

### 5.4 DoT 层数

- 流血可给较大层数，因为只在直接受击后触发且每次减 1，回合结束不减。
- 中毒层数通常低，稳定在所有者回合结束结算并减 1。
- 灼烧层数位于二者之间，按每次出牌/意图触发并减 1，结束再衰减 1。
- 药师单张群体上毒每个敌人最多 1 层；单体毒矢可施加 6 层并立刻毒爆。
- DoT 无玩法硬上限，显示和计算使用安全整数限制。

### 5.5 抽牌与气力

- 抽牌、回气与“本回合已主动出牌数”构成弓手与追风套循环。
- 自动重放、协战、反击、格挡、DoT、药方终端效果不计主动出牌数。
- “计为两张”只改变明确写出的出牌数与套装阈值，不复制卡牌效果和每张牌监听。
- 返费在正常支付和高费用判定后结算；免费牌在支付前改当前费用，二者不可混用。

## 6. 目标与卡手检查清单

逐卡自动化至少检查：

1. 卡面预览目标模式与确认时相同。
2. 不匹配地势、没有状态、没有蓄力或不在指定顺序时，基础效果仍合法。
3. 仅增强段需要的目标不参与基础出牌校验。
4. 群体效果不要求玩家额外点选每个单位。
5. 对自身效果固定落到来源自身；敌方群体法术不出现友敌二次选择。
6. 任意单位牌不因某个条件分支把 `SingleAlly` 动态变成 `AllAllies`。
7. 资源不足时不扣资源、不移牌；目标失效时不产生半结算。
8. 临时复制和任务检索不能生成未携带的伙伴/NPC牌。

## 7. 卡文规范

卡面只写“基础效果 + 本卡差异”；公共流程进入关键词短 Tooltip。建议顺序为：

```text
[费用] [目标]
基础：……
关键词：本牌独有差异……
消耗/每局一次：仅在存在时显示
```

反击与格挡不得混称；灼烧不得写燃烧；玩家可见状态统一写“破绽”，内部英文枚举 `Vulnerability` 不得露出；药效不得显示药材；剑意不得绘制成可叠层状态。

## 8. 目录变更纪律

1. 新目标表通过书面复核后，以 CardId 为单位替换当前定义并更新同日全卡目录。
2. 每次替换需同时更新自动化期望、Tooltip 短文本、存档迁移和实现状态矩阵。
3. 数量校验必须持续满足 198；若新增卡，必须明确它替换哪张或经用户批准扩大总量。
4. 旧定义只保留在变更记录或迁移映射，不与新定义并列成两个现行卡文。
5. A 版全集中的完整 198 行是 2026-08-11 当前实现快照；目标重做是否落地由本专题状态表判断。
