# 专题十：实现状态、测试验收、术语与变更记录

## 1. 状态定义

本文档只使用四种实现状态：

| 状态 | 含义 |
|---|---|
| 已实现 | 当前代码/资产已存在，并有与风险相称的验证证据 |
| 部分实现 | 骨架或部分路径存在，但仍有已知缺口、旧文案或未覆盖分支 |
| 待落地 | 规则已经确认，当前代码/资产尚未实现或仍是被替代版本 |
| 待单独评审 | 关键产品/数值/迁移选择尚未由用户批准，禁止自行落地 |

“有枚举”“有描述符”“有旧牌”不自动等于新设计已实现。

## 2. 规则真源顺序

冲突时按以下优先级裁决：

1. 截至 2026-08-11 当前会话中用户最新明确确认。
2. 2026-08-08、08-10、08-11 的专项设计规格。
3. 当前代码、自动化和当前 198 张目录，用于确认实现状态。
4. 更早的规格和生产记录，只用于未被替代的项目骨架与历史。

被取代规则只出现在本专题变更记录，不在现行章节并列展示。

7. 存档：出牌前与安全结算点恢复结果一致。
8. 文本：卡文与实际结果一致，关键词短句不重复公共规则。

## 8. 完整 PIE 验收脚本

最终人工/自动协同走一次无开发快捷键的玩家路径：

2026-08-12 已用真实输入完整执行一次下列连续路径，并由上述 `ok=true` 报告留档；清单仍作为后续版本的重复验收模板，而不是未执行待办。

1. 启动 `L_Main`，新游戏进入青山客栈。
2. 与任务 NPC 交互并按 F 接任务；打开背包确认主角 8、伙伴 5、NPC 3。
3. 确认任务 NPC 已激活跟随并记录位置；手动保存到指定槽，退出并读取，核对任务、follower=true、玩家/NPC位置、装备和卡组。
4. 进入路线，记录节点与 NPC 4 选 3；进商店购买/刷新并再次保存读取。
5. 进入普通、精英和首领样本战，逐类使用主角、伙伴、NPC 牌。
6. 覆盖流血、中毒、灼烧、蚀伤、毒爆、药效、反击、格挡、灵动、蓄力、任务与地势。
7. 验证阵师错误地势基础效果和匹配地势强效果都能打出。
8. 验证敌方意图、仇恨、守护、多段反应、同死玩家胜与结算奖励。
9. 快速切换六地势背景，核对低饱和辨识、角色/怪物贴合和 UI 可读。
10. 返回城镇，验证路线和永久数据作用域没有串写。

## 10. 关键公式索引

| 公式 | 现行值 |
|---|---|
| 气势 | 每个普通攻击段固定 `+N`，不自动消耗 |
| 标记 | 每层直接伤害 `+15%`，每命中段 -1，上限 5 |
| 破绽 | 每层直接伤害 `+10%`，命中后全耗，上限 5 |
| 虚弱 | 普通直接伤害 ×50%，向下取整且最低 1 |

| 格挡 | `100%攻击力+触发时当前护甲`，不耗甲 |
| 反击 | `100%攻击力`，不耗甲 |
| 守卫全耗甲群攻 | `基础倍率+20%×实际消耗护甲` |
| 寒冰任务 | 消耗全甲，对敌群造成`100%+20%×实际消耗护甲`攻击伤害 |
| 药效 | 每层使本次治疗/反向治疗每目标 +1，行动后全耗 |
| 灵动 | 25%耗1完美闪避；失败且至少2层则耗2闪避 |
| 现代装备强化 | `floor(基础×(1+10%×等级))`，再加每级生命+2、内力/攻击/防御/Speed各+1的可见保底；最高+10，旧装备走槽位固定值兼容 |

## 11. 变更与冲突裁决

| 被替代方案 | 现行裁决 | 原因/影响 |
|---|---|---|
| 气势会自动消耗或有上限 | 气势不自动消耗、无玩法上限，除非明确清除 | 支持长期构筑与按层倍率；怪物可清除 |
| 剑意是独立状态、每层 +20% | 没有剑意状态；只由《剑意贯虹》读取气势 | 防止重复加伤和无来源状态 |
