# 专题八：角色、怪物、地势与局内战斗背景美术

## 1. 美术方向

项目目标不是写实厚涂或高细节国风插画，而是低饱和水墨、概括形体、清晰剪影和少量有控制的色彩。角色、怪物与背景必须属于同一种造型语言：

- 大形先行，轮廓清楚；避免碎石、叶脉、瓦片、纹理噪点堆满画面。
- 墨色边缘有自然干湿变化，但不能把每个物体都勾成细密线稿。
- 颜色只做地势识别、景深和视觉重点；整体饱和度低，不使用大面积高纯度色。
- 前景角色/怪物比背景更清楚，背景主动降低对比和细节，不能抢血条、意图和手牌。
- Q 版或简化角色的体块、头身、笔触粗细要与怪物一致；背景物体比例和透视不能把它们衬成来自另一套游戏的贴图。

当前生成背景只获得“先这样”的阶段性接受，不等于六张背景家族已经最终验收。整体与角色、怪物画风贴合仍为“待落地”。

## 2. 资产范围

本专题的“地势背景”专指项目局内战斗画面的背景图，不是城镇概念图、路线图插画、卡图或独立风景壁纸。六类背景覆盖：平原、山崖、森林、水岸/渡口、村寨、洞穴。

水岸和渡口共享玩法收益，但可以由同一母版导出两种轻微场景变体；在规则和 UI 中仍归为同一颜色家族。背景不改变战斗碰撞或单位站位，只提供可见地势、气氛和层级。

## 3. 六地势视觉语言

颜色差异要明确，但只提高一点点彩度。每张以一种主色倾向、一个大轮廓符号和一组次要墨形识别：

| 地势 | 主色倾向 | 大形识别 | 应减少的细节 |
|---|---|---|---|
| 平原 | 温灰、淡赭与少量枯金 | 横向开阔地平线、远山与低草带 | 密集草叶、花点、碎石 |
| 山崖 | 冷灰、淡紫褐 | 一至两块斜切崖壁与明显高差 | 细碎裂纹、满屏飞石、密集云丝 |
| 森林 | 灰绿、墨青 | 成组树冠大块与纵向树干节奏 | 每片叶子、复杂枝杈、荧光绿 |
| 水岸/渡口 | 灰蓝、淡青 | 大面积水平水面、岸线或简化渡桥/舟影 | 高频水纹、反光碎点、复杂船具 |
| 村寨 | 暖灰、淡土红 | 屋顶/寨门的几何块面与道路透视 | 屋瓦逐片描绘、灯笼高饱和、杂物堆 |
| 洞穴 | 青黑、灰褐与微弱冷光 | 包围式洞口、岩柱和顶部压迫形 | 晶体高饱和、满壁纹理、碎石噪声 |

六张放在一起时，即使缩到战斗窗口大小也能通过主色和大形一眼区分；单张放在角色后方时又不能让色块淹没单位轮廓。

## 4. 构图模板

所有地势使用同一战斗构图骨架：

1. 最后层：低对比远景与纸纹，建立空气感。
2. 中景：一到三个大墨形说明地势，不穿过主要角色头部和血条。
3. 战斗地面：平稳、低细节、可承载我方与敌方脚点；避免极端透视。
4. 近景遮挡：只在边角使用，不能覆盖手牌、单位、意图和目标高亮。
5. UI 安全区：上方状态/意图、中部单位轮廓、下方手牌和资源保持清晰。

六图共用地平线高度、镜头尺度、墨色密度和边缘虚实，因此切换地势不会像切换另一款游戏。地势差异来自主色、大形和少量标志物，不通过改变画面细节量制造。

## 5. 角色与怪物贴合标准

- 先从项目实际战斗角色与怪物截图提取轮廓复杂度、平均线宽、暗部面积和色彩范围，再制作背景，而不是只参考独立水墨风景图。
- 背景最硬的边缘不得比角色主要轮廓更硬；背景最高局部对比应低于角色脸部/武器/怪物头部。
- 角色脚底接触区使用简化墨影或淡色接地，不加写实投影破坏纸本感。
- 怪物体量差异通过站位与留白体现；背景建筑、树木和石块不能给出矛盾尺度。
- 同一批角色、怪物和背景采用一致的黑色倾向、纸张底色和轻微颗粒；不在背景单独使用高频照片纹理。

## 6. 制作流程

1. 收集项目现用我方角色、六章代表怪物和当前战斗 UI 的无损截图，建立风格板。
2. 先画六张黑白大形缩略图；在 25% 尺寸验证辨识和 UI 安全区。
3. 使用同一低饱和色板给六地势轻着色；并排检查区分度。
4. 在实际战斗构图中叠加角色、怪物、血条、意图与手牌，降低冲突区域的细节和对比。
5. 导出符合项目尺寸、色彩空间和命名规则的源图与运行时图。
6. 只在用户确认同一轮六图风格和颜色后替换项目资产；不得覆盖用户手调的角色精灵、PaperZD、关卡、镜头或 HD2D 平面参数。

纯美术工作不使用 TDD；采用尺寸、透明边缘、哈希、清单、导入报告和可视复核验证。若背景接入涉及运行时代码或地势切换行为，该部分仍按代码测试规则执行。

## 7. 文件与导入约束

- 源文件和导出文件使用稳定地势 ID，不用“最终版2”等临时命名。
- 所有六图尺寸、像素格式、色彩空间、压缩和纹理组一致。
- 背景若不需要透明通道，应导出不含无意义 alpha；需要分层时明确远/中/近层清单。
- 导入前记录原资产路径和哈希；生成图先进入候选目录，确认后再替换运行时引用。
- 不改变现有关卡中角色、相机、Paper2D/PaperZD 或 HD2D 平面的手调位置。
- 局内地势 ID 与背景映射使用数据表/目录，水岸和渡口明确共享或选择变体，不硬编码在 UI。

## 8. 视觉验收矩阵

| 验收项 | 方法 | 通过条件 |
|---|---|---|
| 六地势可辨 | 六图同尺寸并排和缩略图盲测 | 只看主色与大形可正确区分 |
| 低饱和 | 直方图与人工复核 | 无大面积高纯度色，关键色仍可辨 |
| 细节克制 | 25%、50%、100% 查看 | 缩小时不成噪点，放大时无无意义碎描 |
| 风格贴合 | 叠加实际角色/怪物 | 线宽、墨色、体块和纸感属于同一语言 |
| UI 可读 | PIE 截图叠血条、意图、手牌 | 文字和图标对比充分，无背景干扰 |
| 构图一致 | 六图快速切换录像 | 地平线、单位脚点和镜头尺度不跳 |
| 技术一致 | 自动清单 | 尺寸、格式、压缩、命名、哈希齐全 |
| 资产安全 | 变更清单 | 只新增/替换已批准背景，不触及手调资产 |
