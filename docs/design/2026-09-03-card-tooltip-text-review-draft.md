# 卡牌pill与悬停文本：最终格式及全量审阅入口

状态：显示格式已按最新讨论统一；逐卡文案仍待审阅。完整稿见[173张卡牌文本表](2026-09-03-all-card-text-review/README.md)，含419个合法品质版本、36条通用阵赏品质分支和共享提示。

## 已确认的表达

| 效果／示例条件 | 简述 | 详述 |
|---|---|---|
| 攻击100、稀有倍率120% | 造成120点伤害。 | 造成120%的攻击伤害。 |
| 百级稀有，流血基础6 | 施加36点流血。 | 6点流血，600%增幅倍率。 |
| 百级稀有，治疗基础25、药效0 | 150点治疗。 | 25点治疗，600%增幅倍率。 |
| 百级稀有，治疗基础25、药效5 | 180点治疗，耗尽药效。 | 25点治疗，600%增幅倍率；消耗全部药效，等量增加基础治疗。 |
| 防御100、基础80%护甲系数、稀有 | 获得96点护甲。 | 获得80%防御的护甲，120%增幅倍率。 |
| 百级稀有、本次溢出4内力 | 溢出获得24点护甲。 | 溢出内力转为护甲，600%增幅倍率。 |

“增幅倍率”表示总乘数，600%即6倍。适用的等级和品质加成统一合入增幅倍率；攻击的品质加成合入攻击倍率。不再列“等级5倍、品质+20%”的参数清单，不再重复乘品质。

所有治疗数值都作为基础系数。用户最新纠正稀有25在百级应为150，已替代此前“25已含品质，所以125”的口径；药效先加进基础值再一起放大。计算保持精确，最后向上取整一次。确需近似显示的倍率标“约”，计算不使用显示时的舍入数。

## 三个展示位置

- 卡面／简述显示按当前属性计算的效果数字；攻击也显示数字。
- 悬停卡牌并切到详述时，使用上表的效果句。攻击不注明额外出手对象，不列当前攻击属性或算式；受益目标、群体范围、次数和必要条件仍保留。
- 鼠标移到怪物后的tooltip解释该目标的防御、状态修正、等级差、护甲吸收和最终生命损失。卡牌产出与目标最终损血不要求相等。

实际取值对象仍由效果数据决定，例如借用友方攻击；它保留在内部计算和文案核对字段，不追加到攻击详述。

## 对象描述

简述和详述开头用独立一行加粗显示对象名称，只突出这几个字，不加“对象：”前缀，不在这一行混入说明。不能藏在阅读页的核对折叠栏中。

| 对象 | 详述例子 |
|---|---|
| 单体敌方 | **单体敌方**<br>造成120%的攻击伤害。 |
| 单体友方 | **单体友方**<br>25点治疗，600%增幅倍率。 |
| 单体友方/敌方 | **单体友方/敌方**<br>25点治疗或治疗反转，600%增幅倍率。 |
| 全体敌方 | **全体敌方**<br>各施加6点流血，600%增幅倍率。 |
| 全体友方 | **全体友方**<br>各获得25点治疗，600%增幅倍率。 |

限定自身的牌仍以“单体友方”为对象行，“仅自身”及自动选目标等限制放在正文。回春露、药王归元同时说明“选择单体友方/敌方”与“效果作用于所选一方全体”。消耗一名友方护甲再群攻、六合自身回内并群体得甲等混合效果分别列对象。对象描述说明效果给谁，不添加攻击来源、属性值或怪物结算过程。

纯抽牌／共享资源不强行标成单位目标；地势与额外重放按其真实作用范围或条件说明。此修订只补文案，不修改取目标规则、费用、倍率或数值。

## Tooltip交互与pill说明

| 操作 | 显示内容 |
|---|---|
| 默认悬停 | 简述 |
| 按住Shift | 详述；松开后回到当前模式 |
| 单击鼠标右键 | 开启本卡pill说明，松开鼠标仍保持；再次右键关闭 |
| 移出卡牌／窗口失焦 | 收起本卡说明，清除临时状态 |

右键说明只介绍当前卡牌、当前品质具有的pill，按出现顺序去重；通用阵赏已锁定时只包含该分支。每条保留触发时机、效果与必要限制，用一两句短文说明，不重复牌面数值推导。对象行属于目标范围，不加入效果pill列表。右键说明不附在Shift详述末尾。

本轮进一步按玩家决策整理：气力、内力改为普通文字，基础介绍放资源栏；蓄力与重箭同时出现时合并解释，持续伤害共性仅补一次。自动入手的触发条件和次数回到四张通用法师的正文；普通重箭在详述明确使用打出前的蓄力，NPC保留先获得再消耗的顺序。满手等情况改为临场提示，不塞进每条释义。不以统一字数上限作为合格标准。

中毒采用用户确认的最终说明：“任意一方回合结束时，失去等同中毒值的生命。”这同时是结算时机修订，双方中毒在每个阵营回合末各结算一次；其余状态的时机不因此改变。

完整右键文案见[逐卡pill说明表](2026-09-03-all-card-text-review/11-card-pill-descriptions.md)。阅读页保留对照文本，每个品质的“交互预览”可试用上述规则；这不代表游戏tooltip已接入。
