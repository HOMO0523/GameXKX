# 挂机条、局外成长与局内挑战：设计边界纠偏

日期：2026-09-15。依据：用户明确纠正“挂机条是挂机条，局内是局内”。  
本轮重新核对现行源码与流程文档，修正前述设计推导；仅文档变更。

**后续已确认人数规则：**新档只有主角，伙伴和NPC槽逐步解锁；解锁后可以卸下任一可选成员并按实际编队进入局内，支持主角单人、主角＋伙伴、主角＋NPC、三人。完整梳理见[三层流程v2](2026-09-15-three-layer-player-flow-v2.md)。下文固定三人描述属于实施前现状，不是新规则。

**用户最新明确决定：挑战期间暂停挂机。** 该决定取代前面的“游历继续”表述，撤回并行运行方案，与当前`StartChallenge`暂停游历的方向一致；具体衔接见三层流程v2第2.1节。

## 1. 本次撤回的错误推导

此前把“单人挂机、开箱换装”与“单人三牌练习、手动首领、伙伴加入”写成一条必经流程，并据此提出试锋/守势/重击、120HP首领及整套新手奖励表。它混合了两套玩法的规则与进度，不能作为执行依据。

`2026-09-15-first-boss-cards-and-rewards.md`整稿撤回。`2026-09-15-player-flow-and-progressive-unlocks.md`原单线顺序停止作为执行依据；其中降低开局信息量、奖励有用途、渐进介绍等原则可以保留，具体流程须按本边界重新组织。

## 2. 当前游戏的三层结构

| 层次 | 玩家行为 | 使用的主要规则 | 作用 |
|---|---|---|---|
| 挂机条／游历 | 选择可游历关卡，自动前进与攻击，处理失败重试 | 独立TravelRunner；队伍生命/攻击、遭遇顺序、收益、冷却 | 持续产金币、经验和宝箱 |
| 局外工作台 | 任务领奖、开箱、换装、编队、选牌、天赋、工具与商店 | 永久角色、物品、成长、进度和配置 | 把资源转为队伍成长与构筑 |
| 局内挑战 | 选路线、战斗出牌、选择临时奖励/遗物、处理事件与行商 | 现有路线与CardBattle；共享手牌/气力、独立内力、职业机制等 | 检验构筑并完成关卡推进 |

“两套玩法”不表示两套互不相干的角色和存档。当前编队、角色等级、装备和永久天赋等由共享状态提供；卡组及完整职业触发用于局内。挂机和局内各自维护其运行过程。

## 3. 已从当前代码核对的衔接

### 挂机循环

**已通关地点 → 自动走动与遭遇 → 自动普通攻击 → 遭遇/整轮收益 → 继续游历。**

普通游历每轮包含普通、精英与首领遭遇；其中的首领仍由挂机演算处理。看到挂机条上的首领，不能推导为玩家此时要切入卡牌界面。

玩家可以在桌面操作背包、开箱等局外功能。挂机持续积累资源，局外调整通过共享属性影响后续演算。

### 普通挑战循环

**桌面选择关卡并点“挑战” → 现有路线图 → 玩家选节点 → 全屏卡牌战斗 → 战后选择与后续路线 → 整关结算 → 返回桌面游历。**

- `StartTrainingChallenge`先生成已有路线图。
- `StartChallenge`使游历停止推进，与用户最新的“挑战期间暂停挂机”决定一致。
- 局内“自动战斗”自动执行合法卡牌动作；它不等于挂机条，也不负责一路选择路线、事件和奖励。
- `CompleteChallenge`登记通关，并将成功关卡设为新的游历目标。
- 取消挑战按现有规则返回可用的游历地点；讨伐存在门票等额外边界。

### 剧情与教程

- 剧情可以提供大量永久金币和箱子；剧情专属战斗按最新规则由对白按钮直达，胜利接战后剧情，独立于普通历练清关。
- 角色课程是独立的借用教学战斗。不能把课程的牌组与数值直接当作挂机条或正式挑战的新规则。

## 4. 两个体验循环通过局外成长相连

### 挂机与开箱

**自动积累 → 打开箱子 → 看懂获得的装备 → 穿戴或处理 → 感受成长 → 继续积累。**

这一侧的新手重点是看懂挂机、开箱和物品用途。单人/单怪的渐进呈现、背包与工具何时开放，应先在这一侧讨论。

### 构筑与挑战

**局外形成目标与配置 → 主动进入挑战 → 使用既有卡牌组合 → 根据战斗结果调整 → 通关取得奖励与更高关卡的游历资格。**

这一侧的新手重点是既有牌组、费用、角色配合与战斗选择的首次接触。它需要独立设计入口和教学时机，不能从挂机条简单化直接推导出新增三张牌、缩小永久卡组或替换正式首领。

连接两者的成长回路为：

**任务／挂机提供资源 → 局外开箱与构筑 → 挑战突破 → 更好的游历目标与后续奖励 → 再次成长。**

这是高层关系，不是要求每开一个箱子就立即进入局内，也不是将两个演算系统串成同一场战斗。

## 5. 下一次分析应分别回答的问题

1. **挂机开局：**第一眼看到多少角色和敌人，何时得首箱，第一次穿戴如何反馈，后续遭遇和人数如何增加。
2. **局外开放：**背包、编队、天赋、商店、工具、任务树分别在什么需求下出现；任务奖励如何支撑当时能使用的构筑途径。
3. **首次局内：**玩家何时愿意点挑战，带着什么已有队伍/牌组进入，怎样逐步理解现有机制，失败后回到什么成长目标。
4. **共享队伍：**若提出1→2→3出战位，明确其对挂机与局内的共同约束。当前有效编队要求三人，任何改变都需单独定规则；不能默认创建两套不同队伍，也不能未经说明修改成熟8＋5＋3卡组。
5. **进度身份：**挂机一轮结束、普通挑战通关、剧情完成、课程完成分别记录。功能解锁绑定哪个进度必须明确，不能统称“打完首领”。

现阶段没有据此新增卡牌、修改怪物、调整掉率或更改保存数据。
