# 任务战返回与奖励表现实施计划

状态：本批已实现，动效获用户验收。见[验收与覆盖](../production/2026-09-16-story-return-reward-presentation.md)。

## 目标

任务“进入1-1”的过时问号节点描述改为“进入战斗，击败兽群”。任务战后自动恢复对应战后对白/结果页。任务报酬与战斗结算使用现有大尺寸金币、普通/高级/悬赏宝箱图标与真实数量，领取/确认成功后播放向对应桌面入口收拢的动效。

## 实施顺序

1. 依据保存的任务战后状态修正Workbench重新打开行为；覆盖重进与读档，已领完任务不强拉回。
2. 同步运行时任务数据和相关本地化文案，移除S00-04的问号节点操作说明。
3. 实现共用奖励图标行及只负责表现的飞行层，复用现有金币/宝箱资源。
4. 任务详情/结果显示更大图标、数量；成功领取时从对应奖励图案发出粒子。
5. 结算页正确列出所有实际宝箱类型；确认返回桌面时表现已发放奖励，不再发奖。
6. 冷UBT、定向运行时/领取幂等检查、独立PIE目视与坐标检查；保存用户原进度，保留手调资产。

## 关键约束

- 游戏状态决定真实收益。领取失败和重复领取不产生表现事件；动画不承担奖励事务。
- 金币目标优先现有金币图标，折叠时回落到背包Tab；宝箱按普通/高级/悬赏分别寻找当前可见入口。
- 飞行层挂在持久桌面外层，绘制仅用本地坐标；布局重建重新解析目标。
- 全屏结算返回桌面后，跨窗口旧来源若在可视范围之外，从可视边界内收拢，避免只在终点突然出现。
- 不改普通挑战与专用任务战的奖励归属，不重复发宝箱，不改变游历/挑战暂停规则。
