# 新手引导的自然触发与保底方案

> 最新规则：开局1-1已算挑战通关，1-2立即可挑战但不可游历。游历1-1通关是推荐去1-2的提示时点；首次实际战斗可能直接发生在1-2。下文关于1-1必须再挑战通关的旧前置由[当前规则与验证](../production/2026-09-16-travel-to12-guidance.md)覆盖。

状态：根据用户本次反馈整理的接入方案，尚未实现。本轮核对代码、定义规则，不宣称下列保底已生效。

## 1. 已确认的现状

- `NeedsStarterRecovery` 要求游历失败次数大于0、出战进度为0且仍在1-1。没有失败不会触发；实际挑战1-1通关后又会失去这个资格。
- 首箱装备成功会继续原箱子流程，但没有独立的“穿戴后查看角色属性”自然短课。
- 手动界面总览包含卡组入口、展开和查看卡牌，没有完整的实际选牌并应用教学。
- 伙伴/主线自动提示要求NewPlayer偏好；默认Unset和未接通的选择入口会阻断提示。F10重置还缺伙伴/主线会话去重记录的清理。
- 主角卡组已有待应用草稿和“应用卡组”按钮。主角合法携带8张；伙伴、NPC分别遵循自己的5/3张规则。真实首Boss快照为3级、32张已解锁主角牌、8张携带牌，已经可以教学编辑。

## 2. 两种1-1通关承担不同作用

| 里程碑 | 接入职责 |
|---|---|
| 游历1-1首次完整一轮成功 | 补查装备基础、角色属性、挑战入口。没有失败也能到这里 |
| 普通挑战1-1首次结算确认，回到桌面 | 接1-2伙伴天赋→编队→伙伴入队 |

游历完成必须读取真实整轮完成事实。不能用初始化时已包含1-1的 `ClearedStageIds` 判断首次游历成功。

**首次战斗入口已明确：**第一次普通挑战中，成功点击怪物节点、进入真实战斗并具备操作条件时开始基础战斗引导。详见[首次普通挑战战斗方案](2026-09-16-first-normal-challenge-battle-guide.md)。

首通不是把1-1全部课程重新播放一遍。仅检查尚未满足的学习目标；6个固定箱仍在玩家点击对应箱时触发，箱子发放与右键规则保持已确认口径。

## 3. 学习目标与触发方式

每项至少区分：是否介绍过、真实操作证据、是否暂缓、下次合适的补提示时机。实际成功操作可以在没有引导时回补证据。

- 已穿戴的槽位跳过穿戴动作；不要卸下再穿，也不强制换成更差的基础装备。
- 角色属性页、装备悬停详情、结算成长页是不同入口，不能互相冒充完成。
- 看过卡组不是编辑过卡组；选择并应用合法配置才产生编辑操作证据。
- 已购买槽位直接去编队，已入队直接跳过招募操作；不要重复付费或选人。
- 自动打开页面只是准备，不计为玩家完成了购买、查看或应用。
- 过了关卡不删除未完成的基础目标；满足条件时在后来相应场景补上。

### 三种接入方式

1. **原位高亮**：正在穿装备时提示属性入口，正在看牌时提示当前牌的作用。不中断连续操作。
2. **自动打开并定位**：首通结算已经确认、玩家回到桌面后，打开天赋并定位伙伴槽。这是明确的新阶段目标。
3. **先等待合适时点**：玩家正在战斗、对话、选目标、拖拽物品或编辑草稿时保留待提示目标，在相应操作结束后接续。

## 4. 触发与保底表

| 目标 | 首选自然时点 | 漏掉后的保底 | 已满足/无法练习时 |
|---|---|---|---|
| 装备基础 | 首箱拿到武器；首次打开背包且有可穿装备 | 首次游历战败或首次完整一轮1-1成功；首次准备挑战1-1前再核对一次 | 仅处理有合法物品的空槽，已穿槽跳过；不强迫先穿齐才能继续游戏 |
| 查看角色属性 | 首次穿戴操作告一段落，或第一次穿齐装备 | 首次游历1-1完成后的空闲点；下次打开背包；首次挑战前尚未看过时轻提示 | 玩家已主动查看则不重播；只突出攻击/气血等当前发生变化的少量属性 |
| 进入正式挑战 | 第一次游历1-1完整成功，已体验变强 | 仍未挑战时，在后续一轮游历完成或主动打开历练页提醒一次 | 只想挂机且关闭提示可继续挂机 |
| 正式路线/出牌基础 | 首次路线可选节点、首次发牌动画结束、当前合法手牌出现 | 下次同类节点、手牌/资源满足时继续未完成目标 | 不依赖旧主线任务；缺牌/资源时允许正常回合，不锁住玩家等待示例牌 |
| 伙伴槽天赋 | 普通1-1首次结算确认后返回桌面 | 首次准备挑战已解锁的1-2、后续回桌面或重登时复核 | 缺200金币不推进到付款成功；提示实际收益来源，金币够后在空闲时续接 |
| 伙伴入队 | 伙伴天赋购买成功 | 槽已开但无人出战时，首次准备1-2或打开编队 | 跳过购买，直接高亮编队；已入队不重复选择 |
| 卡组入口 | 体验过一次正式挑战后回到桌面，或主动查看卡组 | 首通1-1之后，准备下一次挑战前，排在伙伴入队短链之后 | 不要求编辑默认卡组才能第一次开打 |
| 卡组编辑 | 解锁新可选牌并回到桌面，或首次主动打开有替换候选的卡组 | 具备候选时，首通1-1后首次准备1-2前；暂缓后在下一次卡组访问/新卡解锁/出发准备补提示 | 无合法替换候选时只介绍入口，保留编辑目标；不发假牌或强迫替换最优配置 |
| 伙伴首次实际作用 | 首次带伙伴入局，抽到该伙伴可用牌 | 下一次满足手牌、费用和目标条件时 | 一次只教一种效果；自动出牌不记成玩家手动掌握 |
| 主线入口 | 普通1-2结算确认后，进入1-3阶段 | 首次准备1-3、后续桌面空闲或重登 | 已开始任务就接当前节点，已完成就接领奖，不重接已做任务 |
| 月白/NPC槽 | S00-02任务奖励实际领取后 | 离开任务页、准备后续挑战、打开编队时复核 | 已买槽未入队直接去编队；第一次NPC仍为月白 |
| 月白首次用牌 | 首次随队入局且有可用牌 | 后续合法手牌出现时 | 不在第一张牌时灌输全部地势/三牌任务机制 |
| 五工具基础 | 玩家打开对应固定箱 | 玩家主动重开该工具/教程时恢复未完成步骤 | 分解、合成按既定可关闭规则处理，不在首通时强补整套、不增发教学资源 |
| 属性/套装/词缀选择 | 实际获得可替换装备或接近套装条件 | 玩家比较装备、准备挑战或因强度失败返回时 | 已会基础工具就只讲本次选择原因，不重播工具操作 |
| 仓库与锁定 | 收藏重要物品、背包接近满、主动存放 | 容量首次影响正常开箱/领取之前 | 不以分解作为强制腾空间条件 |
| 离线与长线入口 | 实际离开/重登、获得高难资格或讨伐令 | 第一次操作对应入口时 | 每种用途只解释当下需要的部分，不在1-1提前弹出 |

这里的“挑战前保底”是可暂缓的轻提示，不是新增通关许可。明确选择继续挑战后应立即进入，不轮流拦截补完全部课程。

## 5. 装备后的属性短链

1. 玩家连续穿戴时不自动切页；等待鼠标未携带物品、没有拖拽和待决交易，当前操作告一段落。
2. 高亮已有「属性」页签，让玩家点击。
3. 在已有面板里指出当前攻击、气血等实际变化，玩家查看后结束这一段。没有之前的可靠数值快照，就只展示当前数值，不编造差值。
4. 后来穿更多装备只更新反馈，不反复播完整教程。

示例文案：“装备已经穿上了，点这里看看角色的攻击和气血。”

此目标不增加下一只箱子的领取门槛。玩家点击另一只已获得箱子时，优先尊重当前开箱操作；属性目标等待下次合适时点。强化箱仍使用原装备悬停详情教学，不另加比较页面。

## 6. 卡组编辑短链

| 小段 | 玩家实际操作 | 完成依据 |
|---|---|---|
| 找入口 | 点卡组→展开 | 已进入对应角色编辑界面 |
| 选牌 | 取消一张携带牌→选择一张合法候选 | 用户产生实际选牌操作，保持角色自己的数量规则 |
| 应用 | 点「应用卡组」 | 业务提交成功、配置合法；不是只点开页面 |
| 验证效果 | 后续实际挑战里用到相关牌时观察 | 反馈与所选牌相符，不强求立即抽到 |

主角先只教8张携带牌的编辑，不同时要求编辑伙伴和NPC。未应用的草稿不算已完成；实际携带配置继续遵循当前编辑器的应用规则，不由引导代选、代点应用。玩家愿意保留原构筑可以暂缓。

示例文案：“这里决定进挑战时携带哪些牌。可以先调整一张，也可以保留现在的配置。”

## 7. 1-2的明确接力

普通1-1结算确认→桌面就绪→自动打开天赋、定位「结伴同行」→玩家点节点并支付200金币→高亮编队图标→玩家点击→选伙伴并入队。

到入队为止结束这一段，让玩家先看见伙伴出现在游历中。卡组编辑放在之后主动准备挑战或打开卡组时，不在刚入队的同一瞬间继续塞课。

首通确认时若还有更早的装备/属性缺口，先记录待补。伙伴是本次通关的新奖励目标，优先承接；旧缺口在下一次背包/出发准备时补，不把结算出口变成补课队列。

## 8. 关闭、错过和优先级

- 没显示成功、被对话或另一操作挡住：保留待提示资格，不记录为已经提示。
- 暂时关闭：同一场景不再弹。下一次真实的新事件——回到桌面、打开对应页面、获得所需资源、准备下一次挑战——才允许一次轻提醒。
- 分解/合成等“了解即可”的介绍，关闭按原合同处理；不因没有实际消耗而追着玩家补课。
- 明确关闭功能提示：停止自动保底，保留手动教程入口。战斗提示和局外功能提示分开控制；新档Unset不能被当成玩家明确拒绝全部提示。
- 已经自行完成：按业务事实跳过相关动作，不要求拆装、重复付费或重复用掉材料。
- F10重置：持久学习状态与本次会话的提示去重同时清理。

调度优先级：必须处理的结算/强制选择 → 玩家当前进行中的操作 → 当前任务/刚解锁的新能力 → 本场景可补的基础目标 → 可选进阶。

任一时刻只显示一个当前目标。后台记待补，玩家不看见“漏课”“还差几课”“完成本课才发箱”等内部术语。

## 9. 实施顺序与验收

1. **触发基础**：区分默认/主动关闭；保存待提示目标；修复F10会话去重。影响GuideProgress、GuidePreference、Workbench调度。
2. **装备与属性**：独立于战败的基础目标，接首次装备/整轮游历/挑战准备事件。保留已有败退重试和六箱规则。
3. **伙伴/主线**：复用现有Progression短链，补默认新档触发与付款后导航；已解锁状态从正确步骤续接。
4. **实际卡组编辑**：复用InventoryWindow的待应用选牌和Apply流程，记录真实编辑证据；不与默认卡组合法性混为一谈。
5. **正式局内短课**：脱离旧任务门槛，按手牌、目标、意图、奖励与节点的实际就绪事件触发。
6. **连续体验验收**：无Dev推进，完整走1-1→伙伴→1-2→主线→月白；分别覆盖自动出牌、暂缓及重复登录。

必须覆盖：

- 游历战败与完全不战败两条路径。
- 已穿齐/部分穿戴/裸装直接通关；已看属性不重教。
- 直接进挑战绕过游历整轮；过了1-1仍保留未完成基础目标。
- 默认Unset、只关闭战斗提示、主动关闭功能提示三种偏好。
- 首通后自动定位天赋；缺钱、已买未入队、已入队三种续接。
- 有候选/无候选、真实应用/只打开/未应用草稿三种配卡状态。
- 当前没有伙伴牌、费用不足、自动出牌时不锁住战斗。
- 教学箱和新里程碑同时到达时只显示一个目标，保持游历正常进行。
- 关闭后同一场景不重复、下一个保底点可恢复；分解/合成不变成必做。
- 存盘失败、读档及F10重置后，不重复付款、发箱、发奖或漏掉后续导航。

文档替代旧开场计划中“装备后才开始游历”的口径；不改变1-1主角、1-2伙伴、1-3主线与月白的既定节奏。
