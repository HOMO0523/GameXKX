# 宝石类型扩展建议

当前运行时代码只有攻击、防御、最大生命3种固定数值宝石。用户已确定总共12种：固定3种、对应百分比3种，以及直接伤害、护甲获得量、治疗效果、反击伤害、火焰伤害、持续伤害6种机制宝石。新9种尚未实装；不包含速度和内力恢复。每类仅一张图标，所有品质复用，品质通过装备名称/道具底/tooltip Shader及镶嵌文字颜色区分。先审核12张定型图，不制作其余9档品质图。

| 类别 | 设计边界 | 当前代码接入情况 |
|---|---|---|
| 攻击、防御、生命固定值 | 品质值1/2/4/8/16/32/58/95/137/172；生命5倍 | 已有宝石规则和装备投影；新版品质数值已写入代码 |
| 对应三种百分比 | 建议0.25/0.5/1/2/4/8/14.5/23.75/34.25/43%；每种分别合计为S，再用75S/(75+S)，不额外折半 | 新类型尚未实现；用户确认对裸身＋装备＋固定宝石生效，之后再算永久天赋 |
| 护甲获得量 | 提高本人本来会产生的护甲；复制或衍生产甲不得重复放大 | 已有按SourceUnitId匹配的ResolveGeneratedArmorAmount与共享75%词缀公式；宝石来源尚待新增 |
| 治疗效果 | 优先限本人产生的主动治疗；固定套装回血、复活、路线恢复及吸血需分别定边界 | 已有带SourceUnitId的治疗结果和主动治疗增幅入口；装备Healing词缀仍未消费 |
| 反击伤害 | 只强化已有的反击/格挡追击，不赋予额外反击触发 | 已有反应伤害与玄甲格挡追加入口；通用CounterDamage词缀尚未消费 |
| 直接伤害 | 提高本人牌本体的直接伤害，主动与正常重放采用相同被动数值；反击、持续伤害及其他衍生伤害不混入本类 | 已有明确伤害类型、来源角色和ResolutionOrigin；DirectDamage词缀仍未消费，需新增来源清楚的宝石投影 |
| 火焰伤害 | 本人火系直接伤害及本人施加的灼烧伤害；不增加触发次数，排除中毒和流血 | 新增机制，需补齐火系标识及灼烧归属；不能只接直接伤害后把整类标完成 |
| 持续伤害 | 用户选择的第12类，覆盖毒/血/灼烧及对应引爆伤害；只放大伤害，不增加层数/次数/持续时间 | 需要补齐状态来源与自然跳伤/毒爆/引燃的统一边界 |

局内机制的后续专精候选是冰爆伤害和雷击伤害。冰爆只提高消耗护甲后实际生成的伤害，不改变耗甲/返甲/回内；雷击只提高单次伤害，不增加标记或雷击次数。代码已有DamageAllPercentAttackPerConsumedArmor、ResolveSorcererRewardIceDamage以及LightningPerTargetStatusSnapshot等明确入口，但仍须统一普通牌与阵赏路径。通用与专精增伤应进入同一次伤害的统一边际池，避免每类各取75%后连乘。

直接伤害宝石与攻击百分比不能照抄同档强度：前者收益范围更窄，应以伤害优势补偿不提高攻击面板及其他按攻击换算的收益。确切数值待类型方案确认后试算。

暴击率和暴击伤害留待第二批评估：当前天赋暴击率最多20%，暴击伤害额外最多50%（基础150%，最终200%），而且是战斗级天赋字段。增加个人宝石前须建立个人投影并重新安排总上限，避免满天赋后宝石无效，或一人装备全队受益。

持续伤害已入选第12类，但其前置问题仍需解决：当前FGameXXKCardStatusStack只存状态和层数，没有逐来源归属。个人持续伤害宝石不能直接放大全部中毒/流血/灼烧；需要先确定叠层归属、自然跳伤与毒爆边界。火焰与持续伤害共同影响同一灼烧包时，只进入一次75%边际池，不各自折算后相乘。

不建议首批制作抽牌、回气、减费、虚拟连击计数宝石。它们改变出牌资源与触发循环，不能直接套一个75%百分比上限。低血保护、阵型、相邻增益等未定义效果也应先补设计，再考虑宝石化。

主要核对入口：`GameXXKCardRules.cpp`的产甲、直接攻击/暴击、主动治疗和ResolveEquipmentReactionDamage；`GameXXKCardTypes.h`的FGameXXKCardStatusStack；`GameXXKAffixCatalog.cpp`的对应效果目录。以上为源码审查与候选设计，不是新增效果的运行时验收。
