# 物理、法术与抗性：已确认方案

用户于本轮回复“ok”，接受本抗性方案，并要求追加火焰、冰霜、雷击三类抗性宝石图标；战斗减伤与抗性配置尚待接入。用户已确认“直接伤害”改称物理伤害、受防御；法术独立受抗性。用户已确认护甲（临时护盾）仍吸收法术直击，法术只跳过防御属性。

## 当前代码与影响

当前防御为逐伤害包固定相减：`max(1, 原始伤害 - 有效防御)`，见 `Source/GameXXK/Private/GameXXKCardRules.cpp::ComputeDamageAfterDefense`。因此把雷击从防御改为百分比抗性，会显著改善低倍率多段攻击，不能只换显示标签。

## 推荐口径

1. 物理伤害走防御；火焰、冰霜、雷击法术分别走火抗、冰抗、雷抗。三抗互相独立，没有再乘一次的第四条通用法抗；“全抗”奖励仅表示同时增加三条。
2. 抗性用百分比。20%抵消20%对应法术，-10%表示承受110%。初版建议最终上限75%、下限-25%，常规角色5～25%，特色怪可到40%，不配置元素免疫。
3. 已确认：法术直击经抗性后仍消耗临时护甲，再扣生命。
4. 灼烧的自然跳伤和主动引燃均吃火抗；先按来源加成，再按目标火抗，只应用一次。保持其现有持续伤害护甲规则。流血、中毒、蚀伤先保留当前结算，不把它们硬塞进冰火雷。
5. 现有拳头图标改称物理伤害宝石；物理与元素加成分开。反击若带相应伤害属性，同一包适用的物理/反击或元素/反击名义增幅仍只合池一次，75%宝石增幅上限与抗性上限是两个独立步骤。
6. 角色与怪物基础三抗建议不随等级或难度自动上涨；现有生命、攻击、难度系数仍承担成长。初版用明确强项/弱项保留配队价值，再根据真实战斗校准法术倍率。

## 抗性加成的边际提案

表内R0是直接生效的基础抗性。S为以后装备、天赋等提供的正向名义抗性总和，P为减抗百分点：

`R_pos = R0 + (75 - R0) * S / (75 - R0 + S)`

`最终抗性R = clamp(R_pos - P, -25, 75)`

`法术减伤后伤害 = 原始法术伤害 * (1 - R / 100)`

按结算顺序最终取整；无实际伤害的效果不凭空产生1点。R0=20%、S=20个百分点时，最终34.67%；再减抗15个百分点，最终19.67%。没有新抗性装备时S=0，下面的基础表直接生效。此边际与上下限作为已确认设计基准，代码接入仍须完成战斗验证。
