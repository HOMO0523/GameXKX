# 场景、人物立绘与营火插图核对

本次依据当前纯 2D 主流程实际使用的资源：从 UE 导出平原、森林、村寨背景及挂机条背景，核对导入来源；重新拍摄 BattleBoard；查看主角 idle 原帧及 13 名角色的卡面立绘。没有用历史 3D 城镇作为风格基准，也没有修改人物、动画、地图或镜头。

## 现有画风

- 人物：深棕近黑的墨线、略有粗细变化，眉眼与发髻轮廓明确；头身比例偏卡通，衣服以成块灰蓝、棕、墨绿设色。细节集中在脸、武器和职业特征，衣褶主要交代体块。
- 战斗场景：低对比远山，中景使用树冠、崖壁、屋顶的大形，中央地面留空。灰绿、淡赭与暖纸色衬托角色，不应照搬背景纹理密度到人物身上。
- 挂机条：横向山形、稀疏植被及黄土地带，呈现更硬的像素边缘。这是小尺寸运动场景的独立表现，不宜把锯齿作为营火插图的笔触。
- 当前资源仍有不一致：部分背景纸纹铺得较密，角色源帧边缘可见少量旧抠图色边。它们属于现有素材问题，不作为新图必须复制的特征；本轮保留用户手调素材。

## 营火图的修订依据

第一稿的问题是细碎皴染、草叶、碎石和衣纹密度过高，人物和地面同时争抢注意力。第二稿虽减少细节，却使用对称端坐、整齐水平山线和均匀粗轮廓，造成僵硬感。

第三稿保留主角身份与服装，改成一膝抬起、另一腿自然伸出的松弛姿势；发带、衣摆、少量烟线形成曲线呼应。背景只留疏密错落的淡墨远山，纸面大量留白，边缘自然淡出。飘逸感来自笔势与构图，不靠添加碎装饰。

输出为 2172×724 的 3:1 长条，接入时等比显示，完整保留主角、营火与行囊。候选原图和生成提示保存在 `SourceArt/UI/RouteCamp/`；不覆盖旧图。
