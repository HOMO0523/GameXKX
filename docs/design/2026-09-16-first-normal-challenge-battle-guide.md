# 第一次普通挑战的怪物战引导

状态：本批首战发牌与基础教学已实现；[验证记录](../production/2026-09-16-first-battle-guidance.md)区分自动化与实机覆盖。下文其他系统衔接仍是设计范围，不代表本批全部完成。

## 1. 入口固定在第一次真实怪物战

首次进入普通挑战地图，只介绍当前可以选择的节点。玩家成功选择怪物节点（战斗/精英/Boss）后，记录战斗基础引导待显示；进入真实战斗，玩家回合、发牌演出、必要强制选择以及目标控件就绪后显示第一小段。

- 点击挑战按钮、游历条遭遇怪物、进入商店/事件节点，不算首战教学已触发。
- 节点点击失败、取消、不可达、场景载入失败，不消耗首次资格。
- 首场可以是1-1，也可以直接是已开放的1-2。开局1-1通关资格不代表玩家已进行战斗教学；依据独立的实际战斗与学习记录判断。错过后保留未完成目标，不绑定关卡编号。
- 不依赖旧主线 `Step.Main.XuXiake.CombatTutorial`；1-3才开启主线，不可反过来作为首次1-1教学前置。
- 不把战斗界面刚创建的 `Event.Battle.Opened` 等同于已经能看见并操作手牌。
- 首战教学显示在BattleBoard自己的引导层。进入挑战后桌面Workbench已关闭，不能把可见教学继续挂在隐藏桌面上。

## 2. 当前确认的首战节奏

| 顺序 | 出现条件 | 玩家操作 | 认可依据 |
|---|---|---|---|
| 攻击牌 | 第一次普通挑战成功进入怪物节点，实际手牌就绪 | 悬停青锋一式看效果，随后点牌、点敌人 | 实际攻击结算；其他攻击牌也认可 |
| 气力 | 攻击已结算，演出结束 | 查看当前气力并确认阅读 | 已查看资源提示（原控件鼠标穿透，不要求悬停事件） |
| 结束回合 | 气力已介绍 | 玩家点击结束回合 | 实际进入敌方阶段；提前主动结束也认可 |
| 治疗 | 敌人行动后，下一玩家回合且有存活队员受伤 | 归元术 → 受伤角色 | 实际回血大于零；其他牌和效果也认可 |
| 护甲 | 治疗已发生；满血时治疗暂缓 | 横剑守势 → 友方 | 实际产甲大于零；其他牌和效果也认可 |
| 护甲状态 | 已产甲且仍有可见护甲 | 悬停真实护甲图标 | 已查看状态提示，不以另一个空白示意图代替 |
| 自动 | 前面当前可完成的步骤已介绍 | 了解自动按钮，可以关闭或自行开启 | 介绍完成；玩家此前自行开启也跳过 |

每次只指向一个当前控件。攻击、治疗、护甲按结果跳过；不校验必须用了指定卡名，不代点任何牌、回合结束或自动按钮。若一张牌同时完成回血和产甲，两个动作都认可，直接看护甲图标。

## 3. 仅教学战控制发牌

此规则取代初稿“完全不调整抽牌顺序”的建议。

- 教学启用时，青锋一式首回合上手率 100%。首回合主角直接治疗/产甲牌暂缓，额外普通抽牌同样遵守。
- 敌人实际行动后的下一次玩家手牌补充，保证归元术、横剑守势在手，先引导治疗再引导护甲。
- 用户已确认：自定义永久卡组缺少示例牌时，只向本场战斗牌堆补齐；原有八张选择和永久解锁池不变，离开战斗随战斗牌堆清除。
- 不改变怪物生命、伤害、奖励、挑战身份或胜负判定。首回合快速击杀照常胜利，剩余体验延后。
- 极端自定义卡组若几乎全是治疗/护甲，首回合可能少于五张，避免为凑五张重复复制攻击牌。
- 教学明确停用、已完成、老玩家偏好、已有旧档、独立剧情战及 F10 指定战斗探针不启用这套发牌。关闭一条小提示不会停用整场教学。
- 新档启用；v47 保存本场发牌阶段和已发生的教学目标，v46 及以前迁移不突然加入新教程。F10 重置走新档初始化。

## 4. 结果、时机与恢复

攻击依据已结算的敌方受击/失血，治疗依据实际回血，护甲依据实际产甲。不存在点击指定按钮就冒充操作成功的记录。气力、图标、自动分别是介绍目标，不冒充战斗结果。

提示等发牌、出牌、敌方行动演出和必须处理的选择结束，控件有有效位置后再显示。提示挂在 BattleBoard 内；切去路线、奖励或桌面时不留下悬空高亮。

- 玩家不用指定牌也能推进；已经完成的结果不重复要求。
- 满血时不强迫打无效治疗，治疗留待实际受伤后补上；不造伤害。
- 缺费用、目标或当前示例牌时，允许继续正常出牌/结束回合，之后再接。
- 关闭操作提示只收起当前这一段，不停用本场教学、不取消第二回合的配套发牌。实际结果变化、进入目标选择或回合交接后自然接下一段；不会在原地立即重弹。信息提示读完再关闭即认可该段介绍，悬停类仍须先实际查看。
- 自动出牌尊重玩家选择，进行期间不叠加手动操作提示。自动造成的真实效果也按用户“只跟随结果”要求认可。
- 读档保持原手牌和教学发牌阶段，不重新洗一副起手。

## 5. 教学不能拖住正常战斗

- 首张牌秒杀敌人：正常胜利、正常奖励；未体验的防护/敌方回合留到下一场。
- 玩家能直接结束战斗：不要求为了上课故意吃伤害或结束回合。
- 真实战败/主动退出：走原有败退或退出流程；保留已学目标，回桌面接装备/属性等合适的提升建议。
- 多敌：只围绕一个当前合法目标讲第一次操作，不同时解释全部敌人意图。
- 中途触发弃牌、检索、选择或其他必须处理的界面：先处理当前实际选择，再恢复基础教学。
- 教学目标控件短暂缺失、分辨率改变或演出尚未就绪：等待重新定位，不当成已学，也不让教学错误改变战斗胜负。
- 不把旧独立教学战的15秒等待超时、胜利拦截或“必须开启自动战斗”作为正式挑战规则。

## 6. 第一场胜利与整关通关分别衔接

第一场普通怪胜利：先完成该场的正常奖励，再轻提示回到路线选择下一节点。按实际奖励类型说明归属；不能统称全部奖励临时或全部永久，更不能说它自动修改了局外8张携带牌。

首次遇商店、事件、宝箱或营地时，才介绍对应当前选择。无钱的商店可以直接离开，不要求购买才能完成教学。

Boss整关胜利：正常生成结算，玩家确认后回桌面；开局1-1已算挑战通关，1-2已经可挑战。游历1-1后推荐伙伴准备与挑战1-2；挑战通关1-2开放其游历及1-3。第一只普通怪的胜利仍不等于整条路线通关。

## 7. 1-2、1-3只增加新知识

- 伙伴第一次随队入局：用一张实际可用的伙伴牌，说明属于谁、扣谁的内力，以及一种该伙伴特点。已会的选牌/目标/结束回合不重播。
- 月白第一次随队入局：先用一张牌；地势和三牌任务在相应实际机制出现时再分段介绍。
- 首战基础若未完成，优先接当前能够自然完成的一小段，不与新角色提示同时叠加。
- 学院练习中已有的真实基本操作证据可以复用，但课程胜利不能替代普通挑战首通。

## 8. 保底、关闭与恢复

| 情况 | 续接规则 |
|---|---|
| 第一次挑战先选了非战斗节点 | 保留首战资格，到第一次真实怪物战就绪时启动 |
| 首战已进场，但尚未发完牌 | 记待显示，等实际可操作时再出提示 |
| 第一场很快获胜 | 只补未完成项，到下场有对应操作机会时继续 |
| 玩家已自行完成伤害、治疗、产甲/结束回合 | 记录真实证据，跳过对应动作 |
| 收起一条提示 | 当前步骤不原地重弹；下一操作或回合在同一场战斗续接。第二回合优先治疗、护甲，不因为旧结束回合标记缺失再催结束回合 |
| 明确关闭战斗提示 | 保留手动入口，不在每场/每次读档强拉回来；不关闭伙伴/任务功能提示 |
| 玩家选择自动出牌 | 保留其选择，收起当前手动动作提示，真实效果仍可完成对应结果目标 |
| 保存/退出时还没学完 | 保存学习目标；下次进入合法战斗时重新解析实际手牌与目标 |
| 读档后已在战斗中 | 不必再次点击地图；界面与玩家操作就绪时恢复未完成目标 |
| 首战条件曾漏掉，已到后续关卡 | 依据学习目标继续，不依赖1-1当前关卡编号 |
| F10重置 | 首战记录、学习证据和本场提示去重一并复位 |

以真实结算结果记录攻击、治疗与护甲；失败的点击不算。记录效果已经发生，不将自动或反应标成手动操作熟练度。

## 9. 实现涉及的接入点

1. RouteMap：成功选怪节点时登记首战请求；取消/失败不消费资格，切场释放路线短课输入锁。
2. BattleBoard：以真实普通挑战身份、玩家回合、演出队列空闲、强制选择已处理和有效目标几何判断就绪；在自身引导层显示。
3. GuideTargetRegistry：复用已有手牌、合法目标、气力、内力、意图、结束回合目标；补缺失的通用查看/防护目标，不以固定卡名约束整条流程。
4. Progress：持久记录学习目标与延后状态，不保存UI指针或手牌位置；恢复时重新校验实际牌实例与目标。
5. 事件：选牌、目标选择、卡牌提交、演出结束、结束回合、下一玩家回合分别使用真实事实。就绪事件不能被一次性的界面创建事件替代。
6. 结束：引导只释放自身高亮和输入限制；普通奖励、Boss结算、关卡解锁仍由既有业务流程处理，不安装旧0-1的胜利/退出拦截器。

## 10. 必须验证的路径

- 正常新档：点挑战→选怪→实际首战提示出现，单主角可以完整操作。首回合交给敌人后，第二回合治疗→护甲→护甲状态→自动在同一场普通战斗接完。
- 先逛商店/事件再战斗；首个战斗类型不同，仍能启动基础教学。
- 自定义合法卡组移除示例牌：本场补齐且永久卡组不变；无目标、自我目标、敌方目标分别正确。
- 起手无攻击牌、费用不足、零费用、强制选择，不产生死锁。
- 首回合秒杀、反应结束战斗、正常敌方回合、失败与主动退出。
- 多敌、目标死亡/变化、目标控件延迟建立、窗口缩放和重新定位。
- 自动出牌、关闭提示、读档中途恢复、F10重置。
- 小战奖励正常、Boss凭据正常，未完成教学不阻断1-2解锁。
- 伙伴与月白仅教新增差异；正式挑战身份不被学院/旧教学战替换。
