# 14种宝石运行时规则

用户已通过14种方案并同意接入：攻击、防御、生命，攻击百分比、防御百分比、生命百分比，直接伤害、护甲获得量、治疗效果、反击伤害、火焰伤害、持续伤害、冰霜伤害、雷击伤害。速度和内力恢复不加入。每类仅1张图标，品质沿用装备的名称、道具底、tooltip Shader；镶嵌文本按每颗宝石自己的品质显示。

属性百分比分别以攻击、防御、生命为池，对“裸身＋装备＋固定宝石”的装备投影应用，之后再算永久天赋。固定值宝石正常相加。装备通用属性词缀现有规则保留；本轮不把它们改成新的宝石公式。

## 机制边界

- 直接伤害：本人主动牌及其正常重放/重箭的直接攻击伤害；不把反击、地势监听、固定套装衍生或持续伤害重复纳入。伤害加成不提高攻击面板。
- 产甲：本人原本生成的护甲。复制/已经结算过的护甲继续不重复放大。随机产甲词缀的名义值仍为原始值×0.5，与宝石名义产甲在同一池折算；玄甲2件等固定来源独立。
- 治疗：本人主动治疗及同一牌正常重放的治疗量，不增加药效、抽牌、气力。固定套装回血、复活、路线恢复和按已造成伤害返还的吸血不套本增幅。
- 反击：本人已有反击和玄甲格挡追击的伤害，不制造反击事件或增加次数。
- 火焰：规则标记为火系的直接伤害，以及本人施加的灼烧自然伤害；主动引燃时按引爆者的火焰/持续加成。
- 持续：流血、中毒、灼烧的自然伤害与对应的主动毒爆/引燃伤害；不增加状态层数、持续时间和触发次数，不放大蚀伤这一独立固定伤害。
- 冰霜：冰系直接伤害，包含冰爆及冰系阵赏伤害，不改变耗甲、返甲、回复内力等资源。
- 雷击：雷系直接攻击/实际落雷伤害，不增加标记、雷击次数或出牌次数。

每一次伤害把当次实际适用的通用和专精宝石名义值相加，再做一次75%边际，不各自折算后连乘。永久天赋与既有状态仍按原结算顺序处理。伤害增幅采用最终取整；产甲沿用向上取整，治疗沿用原有整数结算。

## 持续伤害归属与旧档

状态贡献记录施加者及其仍保留的层数。自然跳伤按各施加者贡献计算一次；施加者倒地不把尚存的状态改认别人。主动毒爆/引燃按原引爆者结算，只以原始状态层数为基础，不把已经放大的跳伤当作新的基础再次放大。多来源状态仍保持原来的伤害包数量和触发次数。

旧档没有来源的状态保留其原始层数和基础伤害，归入未知来源，不凭空赋予某名角色的宝石加成。新施加和消耗统一维护贡献记录。已有三种宝石的枚举值与道具ID保留；新增类型只追加。保存/读取必须覆盖新类型和战斗中的来源记录。

## 获取与展示

现有产出宝石的入口扩大到14类，同一入口中各类型等权，品质概率、售价、合成数量和孔位不改。合成保留类型只升级品质。每类图标位于固定类型路径，不因品质变化切换PNG；保留旧30张资源作兼容和回退。

单件提示写明名义增幅和边际规则，详细属性显示实际有效值。条件伤害分别显示其适用范围，不把火焰直伤与灼烧强行显示成一个不明确的数值。装备中混合品质的镶嵌文本逐颗按宝石品质调用装备品质表现，不能继承宿主装备品质。

本规则在代码接入前记录。运行时完成与验证状态见生产进度，不能以本规格文本代替测试通过。
