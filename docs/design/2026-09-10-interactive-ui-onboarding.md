## 操作式入门

主入口“界面入门 / UI Basics”，有进度时显示继续；完成后可以重学，重学不清除已有引导与战斗教学奖励记录。课程只显示当前一步，使用全屏半透明黑色遮罩，当前目标镂空、一个高亮目标、简短指令和进度。

- 操作步骤由玩家完成真实按钮操作后推进，点击错误按钮或在页面不存在时不能跳步。
- 阅读步骤才提供“明白了 / Got it”；操作步骤不靠连续点击“下一步”冒充完成。
- 背包：属性、详细属性、装备、卡组、放大选牌、悬停卡牌、返回。
- 管理：打开仓库并理解放取、编队与个人卡组、天赋详情和合计。
- 工具：打开工具、展开方形选择器、选择强化并识别输入与确认区域；不强制消费装备、金币或材料。
- 历练：难度与章节、关卡选择、挑战与历练区别、挂机栏折叠与设置入口。
- 结束后引导到现有战斗教程；不强制进入真实挑战或消耗讨伐令。

教程进度使用现有GuideProgress.CompletedGuideStepIds里的独立UI版本化ID；不改存档结构，不覆盖ActiveGuideId，不影响Academy完成与奖励账本。开始/继续时仅准备当前步骤需要的界面，准备操作不计作用户完成；退出保留进度和未应用的卡组草稿。

## 呈现约束

每步一个短标题、一句指令、进度和关闭；仅阅读步有确认按钮。尽量中文22字内、英文65字符内，细节放原有Tooltip。移除350高大段滚动说明。提示卡在背包纸面内选择不遮住目标的位置，按实际绘制比例保持可读；控件命中区域与显示区域一致。50/75/100以及中英都需要真实点击和截图。

## 退出提示

标题“退出游戏？ / Quit?”。未解锁离线天赋：仅“天赋解锁离线奖励 / Unlock offline rewards in Talents.”。

已解锁：分别三行显示宝箱、金币、经验上限，直接读取FGameXXKTalentProjection三个GetOffline*CapSeconds，和离线结算使用同一来源。默认8小时/24小时/24小时，受各自天赋影响；带分钟/秒时不擅自取整。确认、取消与保存行为不变。
