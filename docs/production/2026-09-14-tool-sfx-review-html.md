## 行为

视频提供原效果、新音效试配、无声三个模式。原效果使用游戏混音器实录。新音效试配静音原视频，将导入WAV放在F0120/F0420/F1020三个工具完成落点；F0720/F1320的洗炼生成和保留流程无工具完成音，按钮声可单独保留或关闭。音量设置只影响网页，不修改WAV字节。

时间轴条目和帧号可以点击定位结果，旁边按钮播放5秒片段。支持暂停、逐帧前后查看、拖动进度、循环所选片段、全屏。音频文件名和试听按钮均可点击播放；下载的参考音频、成品保持原始字节。

支持点击选文件及拖入单条WAV。解析RIFF头与浏览器解码结果，显示原文件采样率、声道、位深、时长和波形。单次最大20MB，支持单/双声道PCM与浮点WAV。非法文件不会覆盖已导入的有效候选。

导出使用内嵌JSON保存成品及用户文字，转义HTML结束标签，清除临时Blob视频地址；重新打开后恢复素材和设置。刷新、关闭前需要导出，未声称浏览器会自动写回用户文件或上传服务器。

## 技术与验证

页面无外部脚本、字体或素材依赖，内嵌9个资源。默认CSP禁止网络连接，媒体使用本地Blob；仅作者来源链接由用户主动打开时访问网站。

Web Audio使用按固定落点构造的整段音轨，暂停、跳转和循环时停止/重建播放源，支持从音效尾音中间继续播放；视频始终作为时间基准。网页试听用于对照，不能代替游戏内最终混音或主观听审。

Chrome完整流程15项通过：离线媒体、时间定位与逐帧、原音播放暂停、文件名试听、原WAV下载、24-bit导入、三个工具落点、跳转停止旧音、片段循环、错误导入保留原候选、拖入文件、导出并重新打开、再次导出/原成品下载、桌面与390px布局、无未捕获错误和外网请求。

导出测试包含多行备注与`</script>`文本，重新打开后按普通文本保留，没有执行注入内容。成品下载和导出包中Base64还原的字节哈希一致；试听模式、音量、按钮声开关、版本和备注均恢复。
