# 六类追加音效需求包

状态：完成。用户要求在现有 15 类 HTML 音效需求包基础上追加六类；本次交付为制作/调整用需求，不修改游戏 C++ 或导入运行时音效。

## 目标与顺序

1. 核对护甲/增益、操作受阻、开箱、暴击、换页/模式切换、升级的真实触发及可见反馈。明确与既有格挡、奖励、重击、按钮音的关系。
2. 复用适用的已有实录；缺少画面时在纯 2D 默认地图和隔离 Dev 会话中补录。编辑器启动前完整复制玩家存档与相关设置，完成后核验还原。
3. 从有完整来源记录的 CC0 素材制作六条参考 WAV。每包含原始素材、授权、参考配音视频、同画面无声视频、秒/帧时间轴、表格、独立 HTML。
4. 更新目录生成脚本、总表、21 类总览与完整 ZIP；已有包保持有效。
5. 核验音频格式、视频帧数、配音落点、同画面视频流、全部文件哈希、网页离线播放、WAV 导入/导出回读和 ZIP 完整性。

## 范围

- 16 Buff：护甲／增益生效。同一动作群体生效合并，实际增加才响。
- 17 Reject：操作受阻提示。只在玩家尝试被拒绝时响；悬停、置灰按钮及反复状态刷新不响。
- 18 ChestOpen：宝箱开箱。成功开箱的动作/结果揭示，与奖励入账语义分别说明，避免同一瞬间机械叠音。
- 19 Critical：暴击。按真实暴击标志，不能仅因伤害大就触发；替代该次普通物理命中音。
- 20 PageSwitch：换页／切换模式。共用一条，切换成功才响；重复点击当前页不响。
- 21 LevelUp：升级。等级实际增加一次结算一声，连续跨级合并。

## 取证与边界

- 五类补录使用 Windows.Graphics.Capture 和项目 MCP；开箱复用此前实录。均在默认纯2D地图与隔离Dev会话中完成，没有装载3D场景或改变C++。
- 暴击使用合法20%天赋率、50%暴伤加成及确定性随机种子273。两个随机数为8、19，第二次19<20触发真实暴击；同参数非暴击对照为120→97。未将普通高伤害误认成暴击。
- 护甲、开箱、暴击、模式切换、升级均检查原始落点相邻帧。受阻原本没有独立可见错误动画，按操作返回时刻映射到视频帧，额外需求字幕清楚标注尝试，未伪称它是游戏现有提示。
- 当前开箱没有独立掀盖动画，以新物品首次揭示为配音落点；与原第12类奖励使用同段画面，开箱成功同一瞬间不机械叠加奖励声。
- 普通收菜UI包装的刷新会把属性页切回装备页，并可能覆盖升级通知。升级最终录屏通过同一 `CollectTrainingTravelRewards` 经验事务触发，保持属性页显示新等级；未直接设为18级。此边界已写入本包，不在音效需求任务里修改游戏UI。
- 模式切换演示两个工具模式；其他换页共用同一制作要求，未逐一补录全部页签。
