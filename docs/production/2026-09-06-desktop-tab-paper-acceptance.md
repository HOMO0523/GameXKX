# 桌面Tab纸底、节点文字与天赋分区

按用户要求，沿用根目录 `codex/ui-visual-optimization`，统一背包、仓库、编队、天赋、工具、历练和选人页的纸底，并将本轮UI优化整理为Git版本。运行依据均为当前UE 5.8的真实桌面PIE截图。

## 最终实现

- `GameXXKDesktopPaperStyle`集中定义纸底贴图、0.065九宫格切片、背包参考尺寸/偏移和四边留量。背包与其他Tab共用画刷；面板通过背景层缩放匹配背包的角尺寸，边和中间填充，不改正文、按钮、装备格和立绘坐标。
- 各Tab的完整纸边采用背包留量，切换中央页时纸面上下边对齐；外纸边不裁剪，内部物品、卡组和天赋滚动区域继续裁剪。
- 天赋节点区域保留功能分区：16%淡墨底和细边界透出纸纹，右侧说明保留原纸色。节点名、级数和说明改用深墨色；没有把节点区与说明区混成一块。
- 天赋“升级”关闭自动换行，单行居中；50/75/100%实拍均为横排并位于按钮框内。
- 历练节点的编号与状态移到图标右侧，间隔14逻辑单位；图标、选中圈和连接线位置不变。三档缩放的实际UMG位置检查及截图都确认文字与图标分离。
- 工具未解锁时，说明直接放在共同纸面上，原操作控件收起；购买解锁天赋后原位恢复控件，保留原可见性与现有天赋图，不叠平色遮罩或第二张纸来遮按钮。
- 纳入江湖体Font及FontFace、思源回退和独立正文Font依赖，并保留原附字体说明；没有重导入或改写用户字体资产。
