# 1-1 的装备门槛与战败引导

状态：已实现；两组游历对照、战败后的实际按钮穿戴链和旧档兼容验证通过。未更新 Shipping 包。

## 验收目标

- 教学期间按原节奏在 1-1 游历，不由开箱、提示或穿戴动作暂停/重启。
- 不穿装备可通过四波普通敌人，在精英波次战败。
- 穿齐六件基础装备后可击败精英和 Boss，完成一整轮 1-1。
- 首次游历战败时优先引导穿戴。每件最多两步，玩家亲自拿起并放入对应槽位；穿齐后引导重新出发。

## 实现

- 移除教学初始化关闭游历和穿第一件武器重新开启游历的逻辑。
- 固定掉落箱仍是普通箱。单开和批开都优先处理待开的固定掉落箱，即使普通随机箱更早入库；批开不消耗过程中刚发的新箱。
- `Starter` 六种装备的基础属性在正式装备属性计算中乘 2，先按原曲线取整再翻倍；强化和词缀规则保持。实际装备提示、角色属性与战斗均使用同一计算结果。
- 单纯翻倍仍会在精英处失败，因此普通 1-1 的敌人生命比例校准为 50%；保留该关的四波普通、两波精英和一波 Boss 配置。
- 首次失败后的穿戴提示优先于开箱提示：必要时先打开已有普通箱取得武器，再逐件定位未穿的装备，最后指向历练与游历。已穿戴的槽位跳过，玩家可关闭提示并从教程入口恢复。
- 首次裸装/缺装备战败会暂停这次尝试，让玩家穿齐再手动出发；不修改原有自动重试偏好。正常教学和开箱期间继续游历。
- 完成记录复用现有引导存档，不自动代穿、不增发装备，不自动完成局内关卡。挑战暂停游历的规则继续适用。
- 存档版本升至 v46，为已穿基础装备的旧档重算属性缓存；新版本仍严格拒绝不一致的属性缓存，不复制装备、不改金币。
