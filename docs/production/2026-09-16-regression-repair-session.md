## 关键判断（与一开始的怀疑不同）

### 1. 学院"点击不了"不是 UI 问题

`GameXXKAcademyStateBuilder::BuildLoadout` 借用**全新档**状态，而新档
`bProgressivePartySlots == true` 且槽位天赋 rank 为 0 → `SetQuestNpc` 拒绝 →
13 门课（每门都带 NPC）**全部构建失败**。`CurrentMapId` 那 29 条断言失败只是**级联**。

### 2. 动画不是"测试过期"，而是实现偏离设计稿

一开始我判断为测试陈旧，核对设计稿后**反了**。但随后用户裁定**以游戏内为准**，
设计稿第 6 节作废——于是改为把测试对齐游戏内：**0.30 秒/包、命中点 0.10 秒**。

测试不是靠删断言变绿：断言数 **233 → 239**。真正的根因是
**测试用 `ResolveClip()` 取图集、面板实际用 `ResolveAttackClipForEvent()`**，
以及所有采样点编码了旧的 0.82 秒节奏。

### 3. 一个我自己的错误更正

初版说明页把「1.59×/4.33×」解释成帧率表造成的。**错**：
`FitClipToDuration` 里播放倍速与素材帧率互相抵消，屏幕上快慢**只取决于时长**
（`每秒张数 = 60 ÷ 时长`）。已更正。
