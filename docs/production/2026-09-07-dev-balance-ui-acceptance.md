## 实施

- Dev 首页“一键推荐配装”：所有已拥有角色统一等级，至宝/+10、中位词缀、同品质4攻4防4生命；用户指定职业套装；主角可选，NPC按第一关联职业。重复整备复用装备，蚀骨六件放物理背包，事务失败不提交。大纸底采用背包背景单独缩放，下拉改ItemSlot，操作按钮固定在首页底部。
- 增加 `benchmark.prepare`、`simulate.run`：独立标准场景、可换NPC卡组、强化/宝石对照；完整实时状态与逐次伤害包、资源和状态快照导出。修正敌我伤害混计、产甲/治疗净差混用和首回合阵亡统计混入敌人。
- 修复意图预演复制玩家手牌费用绑定及临时牌；回合结束DoT、反应和选择后自动连段转阶段，都会刷新正确阶段意图。旧阶段游标不覆盖新阶段；已行动的敌人不重复行动。
- 按用户最新确认，所有伙伴等级/星级与NPC等级都不增加内力。主角30，刀客22、守卫18、药师30、弓手24、法师34、阵师30；NPC使用自身一级基础值。装备内力仍为0，本局明确效果保留。
- tooltip正文实际应用字号，目标与伤害/护甲消耗条件保留，取消三行截断；“可选目标数”不再写成“需选择多个目标”。江湖体标题、加深正文、调整行距和纸面宽度。
- 战斗角色信息移离立绘，压缩资源条为数字与条叠排；意图卡标题独立放大、按钮江湖体及内边距；伤害数字86号江湖体与描边。气力放在结束回合正上方。
- 挂机怪物使用1K优先/2K回退；灰狼攻击、受击、死亡复用Idle进行程序表现。加载期间隐藏空画刷，同帧重生和控件重建恢复100%不透明度。旧波次解除图集固定驻留，保留原256MB缓存上限。蛤蟆按矮宽体型收小，不改素材。
