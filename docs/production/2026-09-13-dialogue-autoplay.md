# 剧情自动播放

用户要求：剧情文本自动前进，短文本显示后至少 5 秒，长文本按字数留足阅读时间。

## 交互

- 对白纸框增加“自动：关 / 开”开关，默认关闭；普通对白和主线紧凑对白共用。
- 当前对白完整显示后计时：`max(5 秒，中文等字符数 / 5 + 英文单词数 / 3 + 标点停顿)`。
- 句末标点停顿 0.3 秒，逗号等 0.15 秒，换行 0.35 秒；英文不逐字母计时。
- 新文本、说话人或节点重新计时。同一行界面刷新不重置；手动翻页取消旧行的自动请求。
- 遇到选项、进入战斗等按钮显示“自动：暂停”，必须手动操作；关闭对白不在后台推进。
- 当前文本一次性显示，因此不包含打字机动画时长。自动开关保留于当前控件，不写入玩家存档。
