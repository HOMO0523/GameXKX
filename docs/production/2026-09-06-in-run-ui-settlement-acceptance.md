# 局内重点界面与 Boss 整关结算验收

本轮在根项目分支 `codex/ui-visual-optimization` 实施。完成用户优先指定的商店、环境事件、宝匣、篝火、Boss 整关结算，以及相关卡面文字和遗物栏；没有创建 worktree、合并、推送或提交用户已有改动。

## 最终视觉决定

- 保留项目纸面水墨与江湖体。根据用户实拍反馈，商店卡取消方形卡名色底，使用局外同类竖卡纸框、顶部卡名、左侧费用和原有角色立绘。
- 卡名和费用放大；战斗手牌立绘恢复到原有 190×228 内容范围，避免为文字腾空而把人物缩成小图。主角、伙伴、六个永久 NPC 使用已有卡图，补齐商店遗漏的 NPC 图像分支。
- 商店仍为四个携带卡强化、四件遗物，使用普通金币，原有价格、刷新、已售和购买规则不变。两个货架与操作区分开，重复“持有者”前缀精简为角色名。
- 山泉与宝匣采用左侧叙述、右侧三项选择；去掉可选收益上的锁头和重复说明。卡片先选择、后确认；长说明限制换行宽度。
- 篝火保留全队恢复最大气血30%或100行旅钱，按钮单行白字，未增加药品或重新引入护符选择。
- 遗物栏六列排列，显示在战斗工具栏下方；两行以内不显示滚动条，更多遗物可滚动查看。
- 新结算页使用独立的已发奖凭据，显示实际金币、成员经验、宝箱、首通/解锁及明确标注的本场 Boss 战统计。没有将普通战后三选一当作 Boss 结算。

## 运行时修复

1. 移除普通/精英等实际战后奖励收尾中的 `Item.HealingPowder` 发放；领取和跳过均已覆盖。
2. 补齐桌面惰性启动流程中的遗物栏创建和刷新，结束路线后隐藏。
3. 新增 Training 结算凭据、伤害/治疗/护甲/主动出牌统计、确认 API 与独立结算 Widget。使用当前实际下一个存档版本 v37。
4. 最终 Boss 的奖励和未确认凭据先保存到 `GameXXK_DesktopTraining_Checkpoint`，成功后提交运行状态。确认保存成功才返回挂机。写入失败保留可重试状态；重复确认不再发奖。
5. v36 迁移不依据历史通关补奖；旧战斗统计标记为不完整；未领取的旧 Training Boss 三选一恢复到终点结算路径。
6. 实跑发现并修复：移除局内气血/内力上限加成时，将当前资源收回永久上限，避免 Boss 结算保存失败。
7. 实跑发现并修复：单关 Training 使用 chapter=1 记录节点收据，但不启用旧三章进度；存档校验现在接受这一合法状态，局中存档可以保存和恢复。
