# 1-1 挑战、商店返回与 Boss 结算修复

## 现场

用户停在正常存档的1-1 Boss胜利状态：`Screen=Battle`、`Phase=Victory`、`bChallengeActive=true`，没有结算凭据，`PartyProgressionStep=0`。不是F10临时会话。现场快照保存在 `Saved/ChallengeFlow-20260916/observed-user.json`。

## 原因与修复

1. **单主角无法结算**：结算生成强制寻找伙伴和NPC，校验又要求固定3人成长记录。改为遍历实际编队，支持主角、主角+伙伴、主角+NPC、三人；凭据允许1–3人且必须含主角，统计存活人数不能超过本次人数。
2. **结算界面残留三人假设**：未出战成长栏隐藏，复用页面从三人切到单人也不会留下旧姓名和进度条；存活分母取实际人数。
3. **1-2不能继续**：正常规则要求实际挑战通关提交后才开放1-2；上述结算失败使整个事务回滚，进度仍为0。修复结算后正常推进到1，不绕过解锁条件。1-1的历史初始可用标记不再误判为已首次挑战通关。
4. **下个节点灰着但能点击**：点击读实时路线，图标透明度只在完整刷新时更新。通过核心商店返回接口复现下一帧Alpha仍为0.44。帧更新现在检查交互状态、颜色和访问状态，仅有变化时同步节点、连线和选中圈；保留弃局确认弹窗的输入锁。
5. **商店返回的路线标识错误**：实际返回时逻辑地图变成旧 `HuangshanRoute`。路线节点完成时根据挑战标志保留 `DesktopTrainingHUD`；非挑战旧路线继续使用原标识，不加载3D地图。
