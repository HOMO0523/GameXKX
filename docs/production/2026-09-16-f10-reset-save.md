# F10 一键重置存档

## 入口与行为

- F10 → 一键整备 → 顶部「一键重置存档」。点击一次执行，成功后收起 F10。
- 按钮旁说明会覆盖当前存档；F10 按键本身仍只开关开发面板。
- 复用完整的新游戏初始化：等级、资源、物品、天赋、任务、关卡、队伍、教程和教学箱全部恢复新档状态。
- 初始为单主角、1-1 游历、一个尚未打开的普通教学箱；后续教学箱按原流程逐个发放。
- 重置当前活动存档槽及其用户编号。沿用现有原子写盘和备份策略，不批量删除其他存档槽、开发快照或本地设置。
- 成功前先构建并保存新档；写入失败保留旧运行时和 Dev 恢复点。
- 成功后清除临时试验、战前/战斗恢复点和进行中的批量模拟，解除开发写入抑制，之后正常保存新进度。
- 如正处于独立学院教程，成功写盘后才退出借用阵容，避免旧教程状态稍后覆盖新档。
- 重建桌面开局表现，清空旧通知和引导窗口；旧引导不会把新档记成「已关闭」。

## 实现

- `save.reset`：F10 与开发命令共享入口。
- `UGameXXKMVPSubsystem::InitializeNewGame`：普通新游戏与显式重置共用初始化，重置强制写入新 profile commit。
- `ResetPresentationForNewGame` / `DiscardForNewGame`：移除旧界面缓存与输入锁，重新允许第一只箱子的引导。
- 无存档字段变化，不增加 SaveVersion。
