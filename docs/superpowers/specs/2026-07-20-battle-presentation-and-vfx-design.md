# 战斗演出、技能特效与 VFX 资源迁移设计

**日期：** 2026-07-20  
**状态：** 已确认，待实施  
**范围：** `L_BattleTown` 的敌方回合演出、回合末补手牌、自身 Buff、怪物受击、状态/HUD 微反馈，以及适配的 Niagara 素材迁移。

## 目标

让战斗每一步都能被玩家看懂，并且所有画面反馈都来自真实卡牌结算：

1. 敌方整轮全部行动结束后，玩家只补满一次手牌，并有逐张抽牌动效。
2. 每张敌方意图都表现为“顶部意图牌 → 当前执行牌 → 攻击者 → 命中/状态 → 收束”的因果链。
3. 自身增益、治疗、内力、护甲、怪物受击、护甲吸收、闪避和异常状态都有不同但统一的低饱和水墨表现。
4. 所有特效、状态图标、血条、内力与共享气力都与真实规则数据同步，不能由最终 UI 数值差值猜测。
5. 引入能复用的特效资源，不迁移演示地图、无关蓝图或风格冲突的资产。

## 已锁定的战斗时序

### 玩家结束回合

规则立即将未使用手牌移入弃牌堆，并进入敌方阶段；视觉可以滞后，但不得延迟规则。

```text
玩家点击结束回合
  → 立即锁定手牌与结束回合
  → 现有手牌从左到右收向弃牌位置（0.18–0.24 秒）
  → 敌方意图依次执行
```

弃牌动作只是表达“未使用手牌被弃置”，不显示为抽牌或洗牌。

### 每张敌方意图

顶部意图轨道始终横排显示所有存活敌人的意图牌；中央只使用当前意图的不可交互副本。

| 阶段 | 时长 | 表现 |
| --- | ---: | --- |
| 聚焦 | 0.12 秒 | 顶部当前意图牌从 `1.00` 放大至 `1.10`，下移 8–14 px，攻击者 P 位标签加深。 |
| 执行牌 | 0.16 秒 | 当前意图牌的展示副本滑入中上方执行区；顶部原牌仍保留。 |
| 锁定 | 0.08–0.12 秒 | 低饱和墨迹箭头指向实际目标，目标轮廓短亮。 |
| 攻击/施法 | 0.14–0.18 秒 | 攻击者朝目标方向轻微探身或施法，不让多个敌人同时运动。 |
| 命中 | 0.12–0.18 秒 | 按真实结算播放 Impact、护甲、闪避、状态和 HUD 微反馈。 |
| 收束 | 0.08 秒 | 执行牌淡墨消散，顶部下一张意图接替焦点。 |

现有敌方意图状态机的 `Reveal → Resolve → Settle` 仍是规则调用边界；表现队列只细化每个阶段，不改变数值何时落地。

### 敌方整轮结束后的补手牌

只有最后一个敌方意图完成、规则成功切回 `Player` 且 `Deck.Hand` 已真实补到上限后，才可播放一次抽牌。

```text
最后一个敌方意图命中与状态结算完成
  → 轮末 DOT、护甲过期和状态过期结算
  → 全队共享气力显示真实新值并轻脉冲
  → 新实例牌按真实 Deck.Hand 顺序逐张飞入手牌槽
  → 最后一张落位 0.08 秒后开放交互
```

- 单张飞入 0.20–0.24 秒，相邻间隔 0.07 秒；五张牌总时长约 0.55–0.70 秒。
- 初始状态：`Scale 0.78`、低透明度、从抽牌锚点向对应槽位移动；落位时轻微 `1.03 → 1.00` 回弹。
- 当前没有合格的牌背资源；首版用半透明纸墨卡框/卡面飞入，不伪造牌背翻面。
- 没有新增手牌时不播放假抽牌；弃牌堆洗回抽牌堆时先播放一次 0.18 秒的淡墨收束，再按真实新牌顺序抽取。
- 抽牌期间手牌、结束回合和目标选择保持锁定；顶部意图牌仍允许悬停查看 Tooltip。
- 抽牌动画由明确的敌方阶段完成事件启动，绝不通过 `RefreshHandCards()` 的手牌变化推断，避免出牌、读档、重进战斗或普通刷新重复播放。

## 表现架构与权威边界

### 规则层

战斗规则保持即时、纯数据、可存档和可测试。规则层不引用 UMG、Niagara、Paper2D、Actor 或素材路径。

现有 `FGameXXKCardDamageResult` 已可可靠描述：

- `HealthDamage`：真实掉血；
- `ArmorAbsorbed`：护甲吸收；
- `bAvoidedByAgility`：闪避；
- `bRedirected`：转移/守护目标。

但 `FGameXXKCardPlayResult` 当前没有记录治疗、加护甲、回内力、加/移除状态、DOT 来源或实际施加层数；因此不能通过刷新后的最终 HP/状态反推特效。

### 语义表现事件

新增非持久、非权威的表现事件批次。每个真正生效的原子结算写出一个事件，表现层消费后即丢弃。

```text
FGameXXKBattlePresentationEvent
  SequenceId
  Type: CardCast | DirectImpact | ArmorAbsorb | Avoid | Heal | ArmorGain
        | ManaGain | StatusAdded | StatusRemoved | DotTick | EnergyChanged
        | Draw | Redirect | Defeat
  SourceUnitId
  TargetUnitId
  SourceCardInstanceId
  SourceCardId
  DamageKind
  Status
  RequestedAmount
  AppliedAmount
  OldValue
  NewValue
  HitIndex
  bRedirected
  bAvoided
```

事件必须记录实际应用后的数值和状态层数。`OnHitStatuses`、DOT、护甲清除、状态移除都必须产生对应事件，不能被直接伤害事件吞没。

`FGameXXKCardPlayResult` 承载玩家卡牌的事件批次；敌方意图、玩家回合末、敌方回合末也以同样的事件批次传递到表现层。事件不保存进 `FGameXXKCardBattleRuntime`，也不影响随机、规则或存档兼容。

### 本地演出队列

`UGameXXKBattleBoardWidget` 持有不持久化的战斗表现队列，负责排序、输入门控和时序。

```text
弃牌表现
→ 敌方意图聚焦
→ 执行牌
→ 攻击者动作
→ Impact / Buff / 状态事件
→ HUD 微反馈
→ 下一敌方意图
→ 共享气力脉冲
→ 补手牌
→ 玩家可操作
```

- 中断、读档、胜利、失败、意图恢复失败时清空队列并直接以真实运行时状态重建 UI。
- 同一 `SequenceId` 只消费一次；普通 `RefreshFromState()` 不得重放。
- 现有手牌 Hover/选中变换与发牌变换必须分层：外层 Motion Wrapper 专管飞入/弃置，内层 Button 保留 Hover 的放大/抬升。两者不能写同一个 `RenderTransform`。
- 中央执行牌、抽牌副本和状态辅助图层一律 `HitTestInvisible`，不拦截手牌、目标箭头或 Tooltip。

## 技能特效语言

### 分层

| 层 | 负责内容 | 不负责内容 |
| --- | --- | --- |
| Actor / 世界层 | 攻击探身、自身符印/光环、受击墨爆、闪避残影、死亡消散 | 手牌、Tooltip、全局数值面板 |
| 角色脚下 HUD | 气血/内力条缓动、护甲数值、状态图标弹入与层数闪亮 | 大型角色特效、卡牌飞行 |
| Board / 屏幕层 | 执行态牌、敌方锁定箭头、伤害/治疗浮字、共享气力、手牌演出 | 角色身体大特效 |

Actor 的 Buff/Impact 使用独立 `BuffFxAnchor` 与 `ImpactFxAnchor`，分别位于角色身体中部/受击落点。不得复用脚下 HUD Anchor；Actor 刷新 idle Flipbook 时也不得清空仍在播放的效果队列。

### 结果到表现的映射

| 真实事件 | 角色本体表现 | HUD 微反馈 | 色彩 |
| --- | --- | --- | --- |
| CardCast | 施放者短促聚气或笔触起势 | 无 | 职业签名色，低饱和 |
| DirectImpact + HealthDamage | 目标中部斩痕墨爆、轻微后仰 | HP 条在 0.18 秒内下降；伤害浮字 | 墨黑/赭灰 |
| ArmorAbsorb 且无掉血 | 灰蓝盾印短展开，不抖角色 | 护甲图标/层数 `1.00 → 1.18 → 1.00` | 灰蓝 |
| Avoid | 目标侧后闪 6–10 px，残墨留影 | “闪避”浮字 | 墨灰 |
| Heal | 小型纸墨光晕向上收束 | HP 条上升、数值轻亮 | 青灰绿 |
| ManaGain | 笔触向胸口收束 | 内力条上升 | 靛青 |
| ArmorGain / Guard | 环身符印或墨盾 | 护甲图标弹亮 | 灰蓝 |
| StatusAdded | 低透明符纸/小型环印 | 新图标 `0.75 → 1.00`，层数短亮 | 使用状态既有低饱和色 |
| StatusRemoved / Cleanse | 淡墨从图标向外散开 | 对应图标退场 | 中性纸灰 |
| DotTick | 小型状态墨点，不播放攻击受击 | HP 小幅变化、状态层数更新 | 对应状态色 |
| Defeat | 人物/怪物淡墨消散 | 三行脚下 HUD 同时隐藏 | 墨灰 |

主角只有在真实 `HealthDamage > 0` 时保留现有短震屏；护甲吸收、闪避、治疗、Buff、DOT 不触发全屏震动。

### 复用策略

不为 174 张牌分别制作特效。使用“施放风格 × 结果风格”组合：

```text
施放风格：主角、Blade、Guard、Healer、Hunter、Sorcerer、Formation、任务 NPC、敌人
结果风格：Impact、ArmorAbsorb、Avoid、Heal、Mana、BuffSeal、DebuffApply、Cleanse、Dot、Defeat
```

职业差异由笔触方向、符印形状、施放姿态和低饱和色相体现；效果语义始终由真实结算事件决定。

## VFX 资源迁移策略

### 资源审计结论

源目录：`D:\UE5 demo\zzz\我的项目\Content`  
源项目：UE 5.4；目标项目：UE 5.8。  
四包合计约 236 MiB，核心均为 Niagara 系统。

| 包 | 推荐候选 | 用途 | 处理 |
| --- | --- | --- | --- |
| `StylizedSlashesV2` | `NS_Slash_Ink`、`NS_SlashImpact_Ink` | 斩击、怪物受击墨爆 | 核心迁移；建立低饱和材质实例 |
| `sA_PickupSet_1` | `NS_Shield`、`NS_Energy_1` | 护甲、守护、能量 | 核心迁移；降低材质发光与饱和度 |
| `Basic_Healing_VFX` | `NS_Healing_NEW`、`NS_Mana_NEW` | 治疗、内力 | 核心迁移；验证旧引用后使用 |
| `Basic_VFX` | 毒、环形、噪声材质的可运行变体 | 后续状态扩充 | 不纳入首批核心效果，需先验证画风和旧引用 |

### 迁移规则

1. 使用 Unreal 的 Asset Migrate/AssetTools 迁移选择的 Niagara System 及依赖，禁止直接复制 `.uasset`。
2. 首批不迁移演示地图、`*_BuiltData`、演示 Blueprint、FBX/PNG 源文件或明显霓虹/赛博效果。
3. GameXXK 显式启用 Niagara；C++ 直接使用 `UNiagaraSystem` 或 `UNiagaraFunctionLibrary` 时才添加 `Niagara` 模块依赖。
4. 迁入后每个系统必须在 UE 5.8 成功加载、完成 Shader 编译、无缺失依赖，才可注册到效果库。
5. 不改原迁入材质；为 GameXXK 建立新的材质实例，统一为：
   - 斩击/受击：墨黑、赭灰；
   - 护甲：灰蓝；
   - 治疗：青灰绿；
   - 内力：靛青；
   - 毒/流血等：沿既有状态图标低饱和色。
6. 任何效果单色、低饱和、0.18–0.45 秒，不使用全屏闪白、高亮霓虹或连续大粒子。

## 交互、Tooltip 与可访问性

- 所有 Tooltip 继续只由悬停触发，且 Tooltip 与临时动画副本均不截获鼠标。
- 敌方回合：手牌与结束回合禁用；顶部意图牌可查看 Tooltip；正在执行的中央副本不显示重复 Tooltip。
- 玩家目标选择保留现有“选中牌抬起 → 合法目标描边 → 箭头跟随鼠标”。
- 无气力、无内力或无合法目标只播放轻微否定抖动和原因 Tooltip，不播放完整出牌/受击。
- 支持“动画减弱”设置：角色位移、震屏、飞牌压缩为 0–0.08 秒；数值、状态和真实手牌顺序仍完整显示。
- Space 长按加速敌方演出；普通左键不用于跳过，避免与目标选择冲突。

## 验收与测试

### 自动化

1. 敌方每张意图只触发一次聚焦、执行、Impact 和收束。
2. 只有敌方全部完成且 `Phase == Player` 时触发一次补手牌；读档、普通刷新、出牌不触发。
3. 抽牌事件与真实新增 `CardInstanceId` 顺序一致；动画完成前手牌/结束回合不可点击。
4. 语义事件覆盖：真实伤害、护甲全吸收、闪避、重定向、治疗、加甲、回内力、加/移除状态、多目标、多段、DOT 和死亡。
5. 护甲吸收不触发角色受击或主角震屏；主角真实掉血才触发震屏。
6. Actor 效果队列可观察当前类型、目标、Anchor、生命周期和完成复位。
7. 状态与资源 Widget 测试增量动画；状态图标 Hover/Tooltip 仍正常。
8. Reduced Motion 下规则结果、事件顺序、手牌顺序和状态数值与标准模式一致。
9. VFX 资产加载测试保证每个首批 Niagara System 可加载且无缺失引用。

### 真实 PIE

在 1288×770 的 `L_BattleTown` PIE 中保存阶段截图/短序列，必须清晰看到：

- 顶部所有存活敌人的意图牌，以及当前执行牌；
- 敌人攻击后真实命中、护甲吸收和闪避的不同反馈；
- 自身 Buff、护甲、治疗、内力和状态新增的不同表现；
- 角色脚下 HP/内力/状态 HUD 不被特效遮挡；
- 最后敌方结算后共享气力刷新并逐张补手牌；
- 手牌、敌方意图牌、状态图标的 Tooltip 在相关时段仍可用；
- 首批 Niagara 效果的低饱和材质与 PSD 水墨 UI 一致。

## 非目标

- 不改变任何卡牌数值、敌方意图顺序、手牌随机顺序、卡牌规则或存档格式。
- 不为每张卡制作独立特效。
- 不迁移演示地图/无关资产或直接复制源项目 `.uasset`。
- 不引入全屏高亮、霓虹赛博画风或持续大粒子效果。
