# 序章地图、月白同行与 0-1 专用教程设计

**日期：** 2026-08-31
**状态：** 用户逐段确认，待实施
**前置规格：** `2026-08-31-qingshan-carriage-preview-design.md`
**默认入口：** `/Game/GameXXK/Maps/L_DesktopTrainingHUD` → `剧情`
**序章城镇：** `/Game/GameXXK/Maps/Prototype/L_Qingshan_AsianVillage_Demo`
**专用教程地图：** `/Game/GameXXK/Maps/Tutorial/L_Tutorial_0_1`

## 1. 目标与本轮终点

本轮从现有马车预览的完成事件继续，交付以下完整闭环：

```text
马车驶离
→ 主角发现地图
→ 地图缩略图与可选检视
→ 月白登场
→ 干粮恩情与同行对白
→ 月白悬浮跟随
→ 月白头顶非阻塞提示前往巨大雕像
→ 雕像旁按 F
→ 进入隔离的 0-1 纯 2D 战斗教程地图
→ 胜利返回，或失败后重试/返回
```

本轮终点是 0-1 胜负返回闭环。0-1 之后的剧情、商店、事件、休息、宝箱、首领和结算后续另行讨论，不在本规格预装。

## 2. 已确认的玩家流程

### 2.1 马车后接主角台词

新增独立的“马车后续剧情控制器”，只订阅 `Tutorial.CarriagePreview.Completed`。马车 Rig 不扩展地图、对白、月白、背包或教程职责。

马车完成后立即进入底部 HUD 纸质对话框：

> **主角：** 再往前就是天台山了……这是什么？

本段没有世界卷轴 Actor、靠近检测、碰撞、拾取提示或鼠标点击。玩家按一次空格后直接进入地图缩略图卡片。

### 2.2 地图缩略图与可选检视

缩略图卡片位于屏幕中央，背景轻度压暗，卡片本身不显示物品名称，只包含：

- 用户提供的徐霞客路线图缩略图；
- `检视`按钮；
- `空格继续`提示。

`检视`完全可选。点击后打开完整地图纸框：

- 原图按约 3:4 纵横比等比完整显示，不裁切；
- 1920×1080 参考尺寸约为 645×860，其他窗口按可用高度响应缩放；
- 关闭按钮位于统一的纸框右上角外沿，不遮挡标题、路线或海岸；
- 检视期间空格不推进剧情；
- 点击关闭返回缩略图卡片。

缩略图卡片按空格后关闭卡片并进入月白登场。

### 2.3 月白登场

剧情复用当前青山镇唯一的固定月白 NPC，不生成第二个月白，也不执行 NPC 解锁。

控制器在运行时记录月白原始 Transform、显隐、碰撞和交互状态，然后把她移动到用户在真实 PIE 中指定的登场锚点：

```text
YueBaiReveal = (16929.215, 5936.139, 1075.711)
```

镜头保持原位，不平移、不推近、不切镜。月白使用现有蓝雾登场图集，完整动画播放期间不接受推进输入。动画结束后才显示底部对白纸框。

### 2.4 干粮恩情对白

对白文本冻结为：

> **月白：** 你……可有吃的？本座已经好几日没吃东西了。<br>
> **主角：** 你从地图里钻出来，第一件事就是讨饭？<br>
> **月白：** ……有便给些，没有便罢。<br>
> **主角：** 行了，拿去吧。就剩这点干粮，省着吃。<br>
> **【演出】** 主角递出干粮，月白接过。<br>
> **月白：** 多谢恩公。救命赠食之恩，本座定会报答。

干粮是剧情演出道具，不读取、扣除或要求玩家背包存在食物。

### 2.5 同行对白

随后继续：

> **月白：** 恩公欲往何处？<br>
> **主角：** 天台山。听说前面有活干，运气好还能混口饭吃。<br>
> **月白：** 天台山……此图上正有一条路通往那里。<br>
> **主角：** 你看得懂这玩意？<br>
> **月白：** 自然。<br>
> **主角：** 那正好，我不识字。你替我认路，就算报恩了。<br>
> **月白：** ……也罢。本座随你同行，替你指路。<br>
> **主角：** 那说好了，我在前面走，你在后面指。<br>
> **月白：** ……恩公倒是安排得明白。

最后一句按空格后关闭正式对白、释放主角操作并进入月白跟随状态。

## 3. 地图任务道具

### 3.1 身份与取得

新增唯一任务道具：

```text
ItemId: Item.Tutorial.RiverMap
DisplayName: 徐霞客游历路线
Kind: Task
MaxOwned: 1
```

地图缩略图第一次出现时立即取得该道具。它是玩家在剧情中直接拿到的关键物，不是任务菜单中的金币、经验或普通物品奖励，因此允许即时进入背包。

首次取得优先放入第一个空背包格。背包已满时放入第一个空仓库格并明确提示；背包和仓库都满时记录待投递状态，剧情继续且道具不得丢失，待出现空格后自动投递。

重播剧情时取得操作幂等：

- 已拥有时不增加第二份；
- 已被玩家拖入仓库时保持原位置；
- 不强制移回背包；
- 不重复弹出取得奖励或改变数量。

### 3.2 背包交互

- 左键沿用现有携带/拖拽事务，可在背包格与仓库格之间移动；
- 任务地图不得放入装备槽或工具槽；非法落点沿用原子回滚；
- 无论位于背包还是仓库，右键均优先打开完整地图检视；
- 右键不得触发快速装备、工具栏放置、右键转仓或使用；
- 不可出售、消耗、分解、强化或装备；
- 右键检视复用剧情中的完整地图纸框与右上角关闭规则，不改变剧情状态。

### 3.3 美术真源

背包图标使用用户附图，其 RGBA 像素与现有源图完全一致，因此直接复用：

```text
Source: SourceArt/UI/Relics/final/T_Relic_OldMap.png
UE: /Game/GameXXK/UI/Relics/Icons/T_Relic_OldMap
Size: 512×512 RGBA
```

该图标只用于背包格，不重新成为世界卷轴。

完整检视图必须从用户提供原图复制进项目稳定源目录后导入，禁止运行时依赖微信临时路径：

```text
Original size: 1279×1706 JPEG
SHA256: 195CB969EBE91691D585934F1265D81B3E285A36B81EFAA723E14B2CF52D36BC
Source: SourceArt/Narrative/Tutorial/XuXiakeTravelRoute.jpg
UE: /Game/GameXXK/Narrative/Items/T_Tutorial_XuXiakeTravelRouteInspect
```

## 4. 解耦状态机

后续剧情控制器使用有界状态机：

```text
Dormant
→ HeroNotice
→ MapThumbnail
↔ MapInspection
→ YueBaiIntro
→ FoodDialogue
→ GuideDialogue
→ YueBaiFollowing
→ StatuePrompt
→ TutorialTravelPending
→ Finished | Cancelled
```

职责边界：

- Dialogue JSON 只保存正式台词和节点顺序；
- 地图卡片、检视窗、月白移动、登场动画、跟随和地图切换由后续剧情控制器负责；
- 马车 Rig 只广播既有完成事件；
- 挂机条、任务抽屉、普通城镇按钮和固定 NPC 编队不参与；
- 不恢复已删除的桌面 Narrative Layer、旧任务抽屉或旧 QuestDialog。

主角发现台词和月白首次对话固定拆成两个小型 Dialogue JSON，由控制器在地图展示前后分别启动，避免把 UI/Actor 命令塞入 Dialogue 节点：

```text
Dialogue.Tutorial.CarriageNotice
Dialogue.Tutorial.YueBaiFirstMeeting
```

## 5. 月白剧情跟随

### 5.1 跟随语义

玩家控制主角走在前面；月白位于后方并通过提示负责指路，符合“你在前走，本座在后引”。月白的剧情跟随不占阵容槽、不改变 `OrderedFormation`、不改变固定 NPC 选择，也不创建新的 NPC 实例。

### 5.2 距离与表现

- 月白保持现有悬浮待机动画，平滑飘动；
- 允许距离为 220–300 UU，目标距离约 260 UU；
- 超过 300 UU 开始追赶，回到约 260 UU 停止；
- 小于 220 UU 时缓慢退回安全距离；
- 使用滞回，不允许在阈值处来回抖动；
- 月白无物理阻挡，不得卡住主角或 NPC；
- 极端卡住或距离过远时，只在画面外安全追上；
- 普通进城不激活该模式；离开当前剧情会话后不永久改写地图中的月白位置。

## 6. 巨大雕像导航与 F 交互

月白进入跟随后，头顶持续显示：

> 前往巨大雕像旁按F交互

该提示禁止使用正式 DialogueCoordinator。现有 DialogueCoordinator 的气泡会设置 `bBlockingPresentation=true` 并触发 Controller 的移动/视角忽略；长期导航若复用它会导致玩家无法移动。

本提示使用独立的被动世界引导气泡：

- 锚定月白头顶；
- 不创建 DialogueSession；
- 不申请 Narrative 或 Guide 输入 token；
- `HitTestInvisible`，不拦截鼠标；
- 主角移动、镜头和普通城镇操作保持可用；
- 进入教程、暂停、返回桌面、地图退出或月白失效时立即清除。

不修改巨大雕像资产。青山镇增加一个受管、无物理阻挡的教程交互标记，放在雕像基座可达区域，复用现有 InteractionComponent/InteractableComponent 的 F 输入。只有玩家进入标记范围后 F 才有效；范围外 F 不触发地图切换。

## 7. 0-1 专用纯 2D 教程地图

### 7.1 地图隔离

项目当前只有 0-1 数据定义，没有专用地图。本轮新增：

```text
/Game/GameXXK/Maps/Tutorial/L_Tutorial_0_1
```

它是纯 2D 战斗宿主：加载后立即显示现有全屏 BattleBoard，不生成可移动 3D 场景、青山镇、路线图、挂机条或普通挑战工作台。

只有巨大雕像的教程 F 交互能带着显式 tutorial option 进入。普通挑战、游历、路线节点、主菜单、启动和读档均不得解析到此地图。

### 7.2 遭遇与战斗引导

专用地图复用现有教程语义数据：

```text
Encounter.Main.XuXiake.0-1
BattleProfile.Tutorial.0-1
Guide.Battle.Basic
Enemy: Enemy.Ch1.Rooster ×1
```

`Guide.Battle.Basic` 在此地图中启用既有三步强制教学：

1. 选择当前可打出的指向型卡牌；
2. 选择合法敌人并打出卡牌；
3. 没有合适牌时结束回合。

Guide 使用教程地图自己的临时 Guide 会话和 Action Gate，不复用 Workbench 所拥有的 Guide presenter，不改变其他战斗的输入策略。普通战斗即使发出 `Event.Battle.Opened`，也不得因此自动套用 0-1 教学。

### 7.3 普通状态隔离

进入前建立瞬态教程返回上下文，并隔离所有普通系统：

- 不推进普通挑战或路线节点；
- 不推进挂机/游历计时；
- 不改变普通 Battle/RouteMap 的恢复点；
- 不发普通金币、经验、物品、宝箱或卡牌奖励；
- 不改变普通敌人编制、关卡解锁或 1-1 规则；
- 教程失败和重试不消耗普通资源；
- 教程结束后恢复进入前的非教程 Runtime 状态。

地图关键道具在进入教程前已经持久取得，恢复普通 Runtime 时必须保留该唯一物品。

### 7.4 胜负与返回

胜利：

- 不显示普通奖励；
- 返回青山镇巨大雕像旁；
- 月白恢复 220–300 UU 悬浮跟随；
- 本次运行期 0-1 标记完成；
- 不再显示“前往巨大雕像”气泡；
- 后续剧情本轮不启动。

失败：

- 在专用教程地图显示`重新挑战 / 返回城镇`；
- 重新挑战重建干净的 0-1 教程会话；
- 返回城镇后主角回到雕像旁，月白恢复跟随；
- 月白重新显示“前往巨大雕像旁按F交互”，允许再次进入。

游戏在教程中关闭或异常退出时不保存瞬态战斗会话；下次正常启动仍进入默认 2D 桌面，不自动进入教程地图。

## 8. 暂停、取消与故障安全

### 8.1 正式剧情阶段

HeroNotice、地图卡片、月白登场和正式对白期间持有一个有范围的输入锁。Esc 必须始终打开可继续/返回桌面的安全暂停层；继续从相同状态恢复，返回桌面走同一幂等清理路径。

地图检视的右上角关闭只关闭检视，不推进剧情。检视状态下空格被消费但不切换状态。

### 8.2 跟随与导航阶段

月白被动气泡不持有输入锁。此时 Esc 使用普通暂停，主角移动保持正常。雕像 F 触发必须有地图切换 pending 防重入，重复 F 不允许启动两次教程旅行。

### 8.3 失败放行

地图纹理、Dialogue 资产、月白 NPC、登场图集、雕像标记、专用教程地图、BattleBoard 或返回上下文任一缺失时：

1. 移除地图卡片、检视窗、正式对白与被动气泡；
2. 恢复主角输入、碰撞和 ViewTarget；
3. 恢复或安全显示唯一月白；
4. 释放所有输入 token 和地图切换 pending；
5. 不写普通奖励、挑战、路线或挂机状态；
6. 输出明确错误日志；
7. 保留已经成功取得的唯一地图任务道具。

取消、地图退出、EndPlay 和迟到回调必须幂等。

## 9. 持久化边界

本轮唯一必须持久化的新增结果是 `Item.Tutorial.RiverMap ×1` 及其背包/仓库物理位置。以下状态保持瞬态：

- 马车后续状态机当前节点；
- 地图缩略图或检视是否打开；
- 月白运行时位置与跟随状态；
- 雕像提示状态；
- 0-1 战斗、重试和返回上下文；
- 本次运行期的 0-1 完成标记。

本轮不自动完成任务、不解锁 NPC、不改 `bFollowerJoined`，也不定义 0-1 后续任务或奖励。是否把序章/0-1 完成写入正式主线进度，留到后续剧情规格裁决。

## 10. 验证与验收

### 10.1 自动化门禁

必须覆盖：

- 马车 Rig 只广播完成事件，不拥有新增剧情职责；
- 后续状态机顺序、地图检视可选循环和空格规则；
- 检视打开时空格不推进，关闭返回缩略图；
- 地图任务道具首次取得、唯一性、满格待投递和重播幂等；
- 地图左右键规则、背包/仓库拖拽、工具/装备非法落点回滚；
- 右键检视不会触发快速装备、工具、出售或使用；
- 复用唯一月白，不生成第二实例；
- 月白登场坐标、镜头不动、动画完成后才开始对白；
- 干粮不读取或扣除库存；
- 跟随的 220/260/300 滞回、无碰撞和远距追上；
- 被动月白气泡显示时 Controller 移动与视角输入不被忽略；
- 正式 Dialogue 气泡仍保持原有阻塞语义，二者互不混用；
- 雕像范围外 F 无效，范围内一次 F 只发出一次教程旅行；
- 专用地图只从教程入口解析，普通入口不可达；
- 0-1 使用一只公鸡、现有 BattleProfile 与三步 Guide；
- 0-1 胜败/重试/返回不改变普通挑战、路线、挂机、奖励和编队；
- 失败、暂停、返回、地图退出和资源缺失均释放输入并恢复角色。

C++ 必须通过冷 UBT `GameXXKEditor Win64 Development -NoHotReload`；禁止 Live Coding、Hot Reload 和自动鼠标输入。

### 10.2 地图与资源校验

通过 UE MCP 的守卫脚本验证：

- 青山镇恰有一个受管后续剧情控制器与一个雕像教程交互标记；
- 不移动巨大雕像、NPC authored transform、建筑、相机、PaperZD 或 HD2D 资产；
- YueBaiReveal 精确等于批准坐标；
- 专用教程地图存在且没有 3D 城镇/路线/挂机 Actor；
- 背包图标为 512×512 真 Alpha；
- 完整地图源尺寸、SHA256 和 UE 纹理路径一致；
- 保存只触及明确批准的包。

### 10.3 玩家可见验收

不运行自动点击，由玩家亲自验证：

```text
点击剧情
→ 马车完整播放
→ 主角台词
→ 空格显示无名称地图卡片
→ 可选检视并关闭
→ 空格后月白原镜头蓝雾登场
→ 完整食物/同行对白
→ 月白在 220–300 UU 后方悬浮跟随
→ 月白头顶提示存在但主角仍可移动
→ 到巨大雕像旁按 F
→ 进入独立纯 2D 0-1
→ 三步战斗教学
→ 胜利返回且无普通奖励
```

另验失败后的`重新挑战 / 返回城镇`、返回后提示恢复、右键背包/仓库地图检视、剧情重播不重复发图、暂停/返回/重启不留下输入锁。

地图卡片、完整地图、月白登场位置、被动头顶气泡、跟随距离和专用 BattleBoard 由 Luna Max 进行截图复核；用户手工未执行的步骤必须记录为未验收，不得从自动化推断。

## 11. 明确非目标

本轮不实现：

- 世界卷轴、靠近拾取、鼠标点击卷轴或拾取提示；
- 主角取名；
- 月白 NPC 解锁或编队自动变更；
- 徐霞客宝藏、“吃不完的米”和月白真实动机的后续对白；
- 0-1 之后的商店、事件、休息、宝箱、首领和结算；
- 普通挑战、普通 1-1、挂机、路线图或双窗口策略修改；
- 自动点击、全局鼠标钩子、窗口隐藏或自动最小化；
- 正式序章/0-1 完成存档语义和后续奖励领取。
