## 1. 目标与本轮终点

本轮从现有马车预览的完成事件继续，交付以下完整闭环：

```text
马车驶离
→ 主角发现地图
→ 地图缩略图与可选检视
→ 月白登场
→ 干粮恩情与同行对白
→ 月白悬浮跟随
→ 月白头顶非阻塞提示前往巨大雕像
→ 雕像旁按 F
→ 进入隔离的 0-1 纯 2D 固定路线地图
→ 点击固定的 0-1 公鸡战斗节点
→ 临时以月白替换土司首领进入 BattleBoard
→ 新手完成九步引导；老玩家直接战斗
→ 胜利关闭战斗、返回路线地图并解锁终点
→ 玩家点击终点返回青山镇；失败可重试或返回
```

本轮终点是 0-1 胜负返回闭环。0-1 之后的剧情、商店、事件、休息、宝箱、首领和结算后续另行讨论，不在本规格预装。

## 2. 已确认的玩家流程

### 2.1 马车后接主角台词

新增独立的“马车后续剧情控制器”，只订阅 `Tutorial.CarriagePreview.Completed`。马车 Rig 不扩展地图、对白、月白、背包或教程职责。

马车完成后立即进入底部 HUD 纸质对话框：

> **主角：** 再往前就是天台山了……这是什么？

本段没有世界卷轴 Actor、靠近检测、碰撞、拾取提示或鼠标点击。玩家按一次空格后直接进入地图缩略图卡片。

### 2.2 地图缩略图与可选检视

缩略图卡片位于屏幕中央，背景轻度压暗，卡片本身不显示物品名称，只包含：

- 用户提供的徐霞客路线图缩略图；
- `检视`按钮；
- `空格继续`提示。

`检视`完全可选。点击后打开完整地图纸框：

- 原图按约 3:4 纵横比等比完整显示，不裁切；
- 1920×1080 参考尺寸约为 645×860，其他窗口按可用高度响应缩放；
- 关闭按钮位于统一的纸框右上角外沿，不遮挡标题、路线或海岸；
- 检视期间空格不推进剧情；
- 点击关闭返回缩略图卡片。

缩略图卡片按空格后关闭卡片并进入月白登场。

### 2.3 月白登场

剧情复用当前青山镇唯一的固定月白 NPC，不生成第二个月白，也不执行 NPC 解锁。

控制器在运行时记录月白原始 Transform、显隐、碰撞和交互状态，然后把她移动到用户在真实 PIE 中指定的登场锚点：

```text
YueBaiReveal = (16929.215, 5936.139, 1075.711)
```

镜头保持原位，不平移、不推近、不切镜。月白使用现有蓝雾登场图集，完整动画播放期间不接受推进输入。动画结束后才显示底部对白纸框。

### 2.4 干粮恩情对白

对白文本冻结为：

> **月白：** 你……可有吃的？本座已经好几日没吃东西了。<br>
> **主角：** 你从地图里钻出来，第一件事就是讨饭？<br>
> **月白：** ……有便给些，没有便罢。<br>
> **主角：** 行了，拿去吧。就剩这点干粮，省着吃。<br>
> **【演出】** 主角递出干粮，月白接过。<br>
> **月白：** 多谢恩公。救命赠食之恩，本座定会报答。

干粮是剧情演出道具，不读取、扣除或要求玩家背包存在食物。

### 2.5 同行对白

随后继续：

> **月白：** 恩公欲往何处？<br>
> **主角：** 天台山。听说前面有活干，运气好还能混口饭吃。<br>
> **月白：** 天台山……此图上正有一条路通往那里。<br>
> **主角：** 你看得懂这玩意？<br>
> **月白：** 自然。<br>
> **主角：** 那正好，我不识字。你替我认路，就算报恩了。<br>
> **月白：** ……也罢。本座随你同行，替你指路。<br>
> **主角：** 那说好了，我在前面走，你在后面指。<br>
> **月白：** ……恩公倒是安排得明白。

最后一句按空格后关闭正式对白、释放主角操作并进入月白跟随状态。

## 4. 解耦状态机

旧 `TutorialQuest → Story.Main.XuXiakeTreasure → Task.Main.XuXiake.Prologue` 玩家任务链退役，不再作为新序章的接取、解锁、追踪或迁移权威。旧 `AcceptTownQuest` 只保留为现有路线/战斗兼容数据，不允许从城镇 NPC 或新序章 UI 触发。

土司首领与宋金宝在新流程接线完成前不提供旧交互：角色目录不再配置两者的默认 NarrativeSequence，旧任务/商店 Dialogue、Sequence、`openTaskOffer`/`openShop` 命令执行器和生成 DataAsset 全部删除。其他固定 NPC、路线商店和 MetaShop 本体不因此删除。

后续剧情控制器使用有界状态机：

```text
Dormant
→ HeroNotice
→ MapThumbnail
↔ MapInspection
→ YueBaiIntro
→ FoodDialogue
→ GuideDialogue
→ YueBaiFollowing
→ StatuePrompt
→ TutorialTravelPending
→ Finished | Cancelled
```

`TutorialTravelPending` 之后的固定路线、战斗覆盖层、胜利回图和终点返回由瞬态 0-1 教程会话接管。后续剧情控制器不得在切图后直接创建 BattleBoard，也不得让普通战斗结算接管教程胜利。

职责边界：

- Dialogue JSON 只保存正式台词和节点顺序；
- 地图卡片、检视窗、月白移动、登场动画、跟随和地图切换由后续剧情控制器负责；
- 马车 Rig 只广播既有完成事件；
- 挂机条、任务抽屉、普通城镇按钮和固定 NPC 编队不参与；
- 不恢复已删除的桌面 Narrative Layer、旧任务抽屉或旧 QuestDialog。

主角发现台词和月白首次对话固定拆成两个小型 Dialogue JSON，由控制器在地图展示前后分别启动，避免把 UI/Actor 命令塞入 Dialogue 节点：

```text
Dialogue.Tutorial.CarriageNotice
Dialogue.Tutorial.YueBaiFirstMeeting
```

## 5. 月白剧情跟随

### 5.1 跟随语义

玩家控制主角走在前面；月白位于后方并通过提示负责指路，符合“你在前走，本座在后引”。月白的剧情跟随不占阵容槽、不改变 `OrderedFormation`、不改变固定 NPC 选择，也不创建新的 NPC 实例。

### 5.2 距离与表现

- 月白保持现有悬浮待机动画，平滑飘动；
- 允许距离为 220–300 UU，目标距离约 260 UU；
- 超过 300 UU 开始追赶，回到约 260 UU 停止；
- 小于 220 UU 时缓慢退回安全距离；
- 使用滞回，不允许在阈值处来回抖动；
- 月白无物理阻挡，不得卡住主角或 NPC；
- 无阻挡不等于锁定高度：跟随目标位置必须向下采样当前可见地面，并以角色根部高度平滑贴合台阶、坡面和楼梯；地面采样失败才保持上一帧 Z；
- 跟随移动和停驻都显式保持现有月白悬浮 Idle Flipbook 循环播放，不切换行走动画，也不允许停在单帧；
- 月白剧情跟随固定使用生产 `FB_character_09_yue_bai_2k_idle` 多帧 Idle，不允许 1K 回退；PartyDeck 单帧南向图只保留给原有静态卡组/场景用途；
- 该 2K Flipbook 仅在剧情跟随期间对现有视觉组件应用 `2.5×` 相对 Scale，使月白可见高度接近主角；退出跟随精确恢复 authored Scale，不改源资产；
- 极端卡住或距离过远时，只在画面外安全追上；
- 普通进城不激活该模式；离开当前剧情会话后不永久改写地图中的月白位置。

## 6. 巨大雕像导航与 F 交互

月白进入跟随后，头顶持续显示：

> 前往巨大雕像旁按F交互

该提示禁止使用正式 DialogueCoordinator。现有 DialogueCoordinator 的气泡会设置 `bBlockingPresentation=true` 并触发 Controller 的移动/视角忽略；长期导航若复用它会导致玩家无法移动。

本提示使用独立的被动世界引导气泡：

- 锚定月白 PaperFlipbook 实际渲染 Bounds 的顶部，而不是碰撞球或 Actor 根点；
- 投影使用 viewport-client / DPI 修正后的 UMG 局部坐标，禁止依赖浮动窗口桌面原点或截图硬编码偏移；
- 不创建 DialogueSession；
- 不申请 Narrative 或 Guide 输入 token；
- `HitTestInvisible`，不拦截鼠标；
- 主角移动、镜头和普通城镇操作保持可用；
- 进入教程、暂停、返回桌面、地图退出或月白失效时立即清除。

不修改巨大雕像资产。青山镇增加一个受管、无物理阻挡的教程交互标记，放在雕像基座可达区域，复用现有 InteractionComponent/InteractableComponent 的 F 输入。该标记只属于本序章控制器，只在 `StatuePrompt` 状态启用；普通进城、重启、旧任务状态和其他 NPC 交互都不能激活它。只有玩家进入标记范围后 F 才有效；范围外 F 不触发地图切换。

雕像 F 不直接切图，而是先显示“是否开启战斗引导？”选择窗。该窗默认永久折叠，禁止因 `GuideProgress.Preference == Unset`、进入城镇、打开 Workbench 或开始序章而自动出现；只有本序章雕像 F 可显式打开。窗口使用批准的 `T_MasterV2_PanelLarge` 纸张九宫格底，保留“我是老玩家，跳过 / 我是新手，继续”两个按钮。选择结果由后续 0-1 临时会话接管，不通过旧任务解锁链触发。

## 7. 0-1 专用纯 2D 固定路线地图

### 7.1 地图隔离

项目当前只有 0-1 数据定义，没有专用地图。本轮新增：

```text
/Game/GameXXK/Maps/Tutorial/L_Tutorial_0_1
```

它是纯 2D 教程路线宿主：加载后首先显示教程专用固定路线，不得立即显示 BattleBoard；不生成可移动 3D 场景、青山镇、挂机条或普通挑战工作台。

只有巨大雕像的教程 F 交互能带着显式 tutorial option 进入。普通挑战、游历、路线节点、主菜单、启动和读档均不得解析到此地图。

### 7.2 固定三节点路线

教程路线不调用普通随机路线生成器，不读取普通 `RouteSeed`，节点固定为：

```text
Tutorial01.Start（起点，进入时已完成）
→ Tutorial01.Battle（0-1 公鸡战斗，进入时唯一可点击）
→ Tutorial01.ReturnTown（终点，胜利后解锁）
```

- 起点只表达玩家已抵达，不响应重复点击；
- 玩家点击战斗节点后，路线图保持为底层所有者，现有 BattleBoard 作为全屏覆盖层进入；
- 战斗期间路线图折叠但不销毁，滚动位置和节点状态由教程会话保留；
- 胜利后战斗节点显示已完成，连接线更新，终点变为可点击，并给出明确的“0-1 完成”反馈；
- 玩家点击终点后才恢复进入教程前的普通 Runtime，并返回青山镇巨大雕像旁；
- 教程路线节点不写入普通 `VisitedRouteNodeIds`、`ReachableRouteNodeIds`、挑战进度或主线存档。

教程固定路线复用现有 `UGameXXKOneGameRouteMapWidget` 的节点绘制与点击语义，但节点数据和点击解析由教程瞬态会话提供。禁止为教程复制第二套普通路线系统。

### 7.3 遭遇、战斗覆盖层与引导

专用地图复用现有教程语义数据：

```text
Encounter.Main.XuXiake.0-1
BattleProfile.Tutorial.0-1
Guide.Battle.Tutorial01.NewPlayer
Enemy: Enemy.Ch1.Rooster ×1
```

点击 `Tutorial01.Battle` 后启动上述 Encounter，并必须通过现有 `UGameXXKBattleOverlayCoordinator` 进入 BattleBoard。该入口负责创建非零视觉会话 Token、加载角色图集、显示主角/伙伴/NPC/公鸡战场动画，并在退出战斗时恢复同一张路线地图；禁止再次从 PlayerController `BeginPlay` 直接显示 BattleBoard。

进入战斗前，教程会话对当前 `OrderedFormation` 建立只读快照，然后只在本场构造临时阵容：保留主角与原固定伙伴，用月白替换土司首领所在的第三个战斗槽。该覆盖对“老玩家”和“新手”两个分支都生效，以保证两者进入同一场 0-1；它不得改写伙伴/NPC 解锁、候选列表、编队存档或普通挂机条阵容。胜利、失败返回、主动退出、地图退出和异常清理均从快照精确恢复进入前编队。

两个分支也使用同一套确定性开局牌堆。开局手牌必须包含：

```text
Hero.Generic.HengJianShouShi（横剑守势，固定为最左第一张）
Hero.Generic.SuiYanJi（碎岩击）
Hero.Generic.FengShenBu（风身步）
```

固定的是本场教程开局，不改玩家永久卡组。后续引导按 CardId 查找牌，不依赖出牌后变化的槽位序号。

“我是新手，继续”只在本场启用独立的 `Guide.Battle.Tutorial01.NewPlayer`；不得覆盖或扩写普通 `Guide.Battle.Basic`。新手引导顺序固定为：

1. **气力值说明**：只聚光气力值显示。月白气泡显示“气力值：每回合出牌时消耗的点数。”玩家按空格继续。
2. **主角状态说明**：同时聚光主角气血条与内力条。月白气泡显示“气血：主角生命值，归零时死亡。内力值：出牌时消耗的角色能量条，每回合恢复 2 点内力。”玩家按空格继续。
3. **怪物意图说明**：只聚光公鸡意图卡，并保留真实悬停提示。月白气泡显示“怪物意图卡：玩家悬停可以看到下回合怪物的动向和攻击数值，提前布局。”玩家按空格继续。
4. **横剑守势**：同时聚光最左侧 `横剑守势` 与主角。只允许玩家先点击该牌、再点击主角；牌实际结算并为主角增加属性与护甲后推进。
5. **碎岩击**：同时聚光 `碎岩击` 与公鸡。只允许玩家先点击该牌、再点击敌人；伤害实际结算后推进。
6. **风身步**：同时聚光 `风身步` 与主角。只允许玩家先点击该牌、再点击主角；实际进入强制弃牌状态后推进。
7. **选择弃牌**：聚光完整弃牌选择框，允许玩家在框内选择一张合法手牌；弃牌事务成功提交后推进。
8. **结束回合**：只聚光结束回合按钮。月白气泡显示“结束回合：本回合气力消耗和出牌结束后，点击这个按钮结束回合。”点击并成功提交结束回合后推进。敌方回合期间引导进入等待态，不显示遮罩、不拦截输入。
9. **自动战斗**：下一次轮到我方时只聚光自动战斗按钮。月白气泡说明点击后可由系统自动出牌战斗；玩家成功开启自动战斗后，立即销毁本场 Guide 与 Action Gate，由现有自动战斗系统完成余下战斗。

信息步骤只由空格推进；点击或悬停被聚光控件不会跳过说明。操作步骤只由对应的战斗语义事件推进，不得把一次原始点击当作完成。`牌 + 目标`步骤虽然同时露出两个目标，但 Action Gate 必须维持“先牌、后目标”的子状态，两个动作与最终结算全部成功后才进入下一步。

#### 7.3.1 多目标聚光与月白气泡

BattleBoard 为引导登记稳定的语义目标，包括气力值、主角气血/内力、公鸡意图、三张指定 CardId、主角、公鸡、弃牌选择框、结束回合和自动战斗。Guide 数据只引用语义目标，不保存分辨率相关坐标。

现有 Guide Overlay 扩展为多目标“遮罩挖孔”模式：

- 半透明底覆盖战斗区域，但为本步骤的一个或多个真实控件绘制透明孔，使它们视觉上被抬高；
- 遮罩与引导装饰固定为 `HitTestInvisible`，不吞掉鼠标；
- 不移动、重挂、复制或截图真实控件，所有点击仍由原控件处理；
- 聚光矩形只使用 BattleBoard viewport-client / SafeStage 本地坐标，禁止通过桌面绝对坐标往返；
- 每帧从目标登记表重新取本地矩形，以适应卡牌移动、窗口缩放和 DPI 变化；
- 月白说明气泡锚定本场月白 UnitVisual 的实际可见边界，并显示在半透明底之上；空间不足时在同一 BattleBoard 安全区内换侧，不使用世界投影；
- 点错目标时不推进，并由月白气泡重复当前动作提示；暂停、退出和失败返回动作始终列入允许集合。

Action Gate 只属于 `Guide.Battle.Tutorial01.NewPlayer` 的当前战斗会话。半透明底不承担输入过滤；规则层只放行当前步骤的正确语义动作以及暂停/退出。普通战斗、老玩家分支、路线图、城镇、挂机条和 Workbench 均不得收到该 Gate。

“我是老玩家，跳过”仍进入相同固定路线、临时阵容、确定性开局与 0-1 战斗，但不创建 Guide、聚光层或 Action Gate。普通战斗即使发出 `Event.Battle.Opened`，也不得因此自动套用 0-1 教学。

### 7.4 普通状态隔离

进入前建立瞬态教程返回上下文，并隔离所有普通系统：

- 不推进普通挑战或路线节点；
- 不推进挂机/游历计时；
- 不改变普通 Battle/RouteMap 的恢复点；
- 不发普通金币、经验、物品、宝箱或卡牌奖励；
- 不改变普通敌人编制、关卡解锁或 1-1 规则；
- 教程失败和重试不消耗普通资源；
- 教程临时阵容和确定性牌堆不写入存档；
- 教程结束后恢复进入前的编队及非教程 Runtime 状态。

地图关键道具在进入教程前已经持久取得，恢复普通 Runtime 时必须保留该唯一物品。

### 7.5 胜负与返回

胜利：

- 必须在普通金币、经验、物品、卡牌和路线奖励生效前截获教程胜利；
- 关闭 BattleBoard 覆盖层并回到同一张固定教程路线地图；
- 战斗节点显示完成、终点解锁，并显示一次清晰的完成反馈；
- 不显示普通奖励，也不改变进入教程前的金币、经验或其他普通状态；
- 玩家点击终点后返回青山镇巨大雕像旁；
- 精确恢复进入教程前的原编队；
- 月白恢复 220–300 UU 悬浮跟随；
- 本次运行期 0-1 标记完成；
- 不再显示“前往巨大雕像”气泡；
- 后续剧情本轮不启动。

失败：

- 在战斗覆盖层上显示`重新挑战 / 返回城镇`；
- 重新挑战重建干净的 0-1 教程会话；新手分支从“气力值说明”重新开始，不恢复半截 Guide；
- 返回城镇后精确恢复进入教程前的原编队，主角回到雕像旁，月白恢复跟随；
- 月白重新显示“前往巨大雕像旁按F交互”，允许再次进入。

游戏在教程中关闭、主动退出或异常退出时不保存瞬态战斗/Guide 步骤；下次正常启动仍进入默认 2D 桌面，不自动进入教程地图、剧情或战斗。再次主动进入 0-1 时从对应分支开头开始。

## 8. 暂停、取消与故障安全

### 8.1 正式剧情阶段

HeroNotice、地图卡片、月白登场和正式对白期间持有一个有范围的输入锁。Esc 必须始终打开可继续/返回桌面的安全暂停层；继续从相同状态恢复，返回桌面走同一幂等清理路径。

地图检视的右上角关闭只关闭检视，不推进剧情。检视状态下空格被消费但不切换状态。

### 8.2 跟随与导航阶段

月白被动气泡不持有输入锁。此时 Esc 使用普通暂停，主角移动保持正常。雕像 F 触发必须有地图切换 pending 防重入，重复 F 不允许启动两次教程旅行。

### 8.3 失败放行

地图纹理、Dialogue 资产、月白 NPC、登场图集、雕像标记、专用教程地图、BattleBoard、返回上下文、教程指定牌、语义目标控件、月白战场视觉或预期结算事件任一缺失时：

1. 移除地图卡片、检视窗、正式对白与被动气泡；
2. 移除战斗聚光、月白战斗气泡和 Action Gate，绝不把玩家留在不可操作遮罩中；
3. 恢复主角输入、碰撞和 ViewTarget；
4. 恢复进入教程前的编队，并恢复或安全显示唯一月白；
5. 释放所有输入 token 和地图切换 pending；
6. 在教程战斗中显示可操作的`重新挑战 / 返回城镇`，其他阶段安全返回默认 2D 桌面；
7. 不写普通奖励、挑战、路线或挂机状态；
8. 输出明确错误日志；
9. 保留已经成功取得的唯一地图任务道具。

操作处理明确返回失败，或战斗不再处于 Busy/Pause 状态但预期结算事件 15 秒内仍未到达时，按同一失败放行路径处理。暂停时间、敌方正常行动和自动战斗阶段不计入该看门狗。

取消、地图退出、EndPlay 和迟到回调必须幂等。

## 9. 持久化边界

本轮唯一必须持久化的新增结果是 `Item.Tutorial.RiverMap ×1` 及其背包/仓库物理位置。以下状态保持瞬态：

- 马车后续状态机当前节点；
- 地图缩略图或检视是否打开；
- 月白运行时位置与跟随状态；
- 雕像提示状态；
- 0-1 战斗、重试和返回上下文；
- 教程临时编队、确定性牌堆与新手 Guide 当前步骤；
- 本次运行期的 0-1 完成标记。

本轮不自动完成任务、不解锁 NPC、不改 `bFollowerJoined`，也不永久改变月白、土司首领或任何伙伴/NPC 的编队状态；不定义 0-1 后续任务或奖励。是否把序章/0-1 完成写入正式主线进度，留到后续剧情规格裁决。

## 10. 验证与验收

### 10.1 自动化门禁

必须覆盖：

- 马车 Rig 只广播完成事件，不拥有新增剧情职责；
- 后续状态机顺序、地图检视可选循环和空格规则；
- 检视打开时空格不推进，关闭返回缩略图；
- 地图任务道具首次取得、唯一性、满格待投递和重播幂等；
- 地图左右键规则、背包/仓库拖拽、工具/装备非法落点回滚；
- 右键检视不会触发快速装备、工具、出售或使用；
- 复用唯一月白，不生成第二实例；
- 月白登场坐标、镜头不动、动画完成后才开始对白；
- 干粮不读取或扣除库存；
- 跟随的 220/260/300 滞回、无碰撞、地面高度采样、楼梯升降和远距追上；
- 跟随/停驻阶段月白悬浮 Idle 始终循环播放；
- 被动气泡以月白实际视觉顶部为锚，浮动 PIE 中不得与月白明显脱离；
- 被动月白气泡显示时 Controller 移动与视角输入不被忽略；
- 正式 Dialogue 气泡仍保持原有阻塞语义，二者互不混用；
- 雕像范围外 F 无效，范围内一次 F 只发出一次教程旅行；
- 专用地图只从教程入口解析，普通入口不可达；
- 进入专用地图先显示固定三节点路线，不得直接开战；
- 固定路线只有起点、0-1 战斗、返回青山镇三个节点，不调用随机生成；
- 点击战斗节点必须通过 BattleOverlayCoordinator 建立非零视觉会话并显示四个战场角色；
- 0-1 使用一只公鸡、现有 BattleProfile、临时“主角 + 原固定伙伴 + 月白”阵容与确定性开局牌；退出后原编队精确恢复；
- 老玩家与新手进入同一节点/战斗；老玩家没有 Guide/Gate，新手只启用 `Guide.Battle.Tutorial01.NewPlayer`；
- 新手 Guide 严格执行气力、主角气血/内力、怪物意图、横剑守势、碎岩击、风身步、弃牌、结束回合和自动战斗九步顺序；
- 横剑守势固定在开局手牌最左侧；三张指定牌按 CardId 定位，且不改永久卡组；
- 信息步骤只由空格推进，操作步骤只由正确语义动作及成功结算推进；错误点击不推进；
- `牌 + 角色/敌人`可同时聚光，但必须依次完成选牌、选目标和结算；
- 多目标聚光不重挂或复制真实控件，遮罩不拦截鼠标，并在浮动 PIE、窗口缩放和 DPI 变化后保持本地坐标对齐；
- 月白战斗气泡锚定月白 UnitVisual；暂停、退出和失败返回始终可用；
- Guide 资源或结算异常时释放全部限制并显示`重新挑战 / 返回城镇`，不得软锁；
- 胜利必须先回到教程路线图、表现节点完成并解锁终点，点击终点后才回城；
- 0-1 胜败/重试/返回不改变普通挑战、路线、挂机或奖励，离开教程后不得留下任何临时编队改动；
- 失败、暂停、返回、地图退出和资源缺失均释放输入并恢复角色。

C++ 必须通过冷 UBT `GameXXKEditor Win64 Development -NoHotReload`；禁止 Live Coding、Hot Reload 和自动鼠标输入。自动化只能由开发者显式运行，并通过游戏内部语义接口驱动；不得在双击 `.uproject`、打开编辑器或启动 PIE 后自动执行测试脚本、模拟鼠标、控制窗口、隐藏窗口或最小化窗口。

### 10.2 地图与资源校验
