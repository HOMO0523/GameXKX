# GameXXK 天赋网格、扁平图标与仓库批量转移重设计

日期：2026-08-25  
状态：设计已在对话中逐节确认，等待书面规格复核

## 1. 目标

本次重设计解决三个已经在 PIE 中确认的问题：

1. 当前天赋图标细节过多、带有自己的纸张背景，与项目现有背包套件不一致。
2. 当前节点把名称和 `0/5` 压在图片内部，图片被压缩；自由角度连线与节点位置会产生歪斜和重叠。
3. 仓库仍使用“上一页 / 下一页 / +”控制，不符合已经确认的页签与批量转移操作。

本次不修改已经确认的永久天赋数值上限、价格倍率、战斗公式、挂机公式、工具公式或存档中的已购等级。

## 2. 视觉资源复用原则

### 2.1 节点底板

所有天赋节点统一复用背包正在使用的项目资产：

`/Game/GameXXK/UI/MasterV2/Approved/T_MasterV2_ItemSlot`

要求：

- Item Slot 始终保持 1:1 比例。
- 不为天赋另画一套节点框。
- 不在底板图片内部烘焙名称、等级、锁、光效或其他状态。
- Item Slot 在未点亮、可升级、已升级三种状态下保持同一张底板。

### 2.2 根基图标

根节点不重新生成图标，直接复用当前底部“天赋”入口使用的凯尔特三角结：

`/Game/GameXXK/UI/ImageTruth/Training/T_TrainingNavTalents`

### 2.3 其他图标

其余图标优先复用同一套现有导航资产：

- 仓库相关优先使用 `T_TrainingNavWarehouse`。
- 工具相关优先使用 `T_TrainingNavTools`。
- 只有项目内没有合适单主体图标时才生成新图。

需要生成的新图必须以当前天赋入口图标为风格锚点：

- 独立透明 PNG；不带纸张、方框或场景背景。
- 单一主体、深墨轮廓、最多两个主色。
- 不画光芒、速度线、金币堆、复杂纹理或组合插画。
- 统一正方形画布和主体占比，主体约占画布 70%。
- 每个节点只绑定一张干净的正方形图片。
- 同一效果类别永远复用同一图标。

效果与图标类别如下：

| 类别 | 图形 | 复用范围 |
|---|---|---|
| 根基 | 现有凯尔特三角结 | 永久根节点 |
| 攻击 | 简化刀剑 | 固定攻击、攻击百分比、最终伤害 |
| 生命 | 简化心形 | 固定生命、生命百分比 |
| 防御 | 简化盾牌 | 固定防御、防御百分比 |
| 暴击 | 简化四角星 | 暴击率、暴击伤害 |
| 移速 | 简化布鞋 | 挂机走路时间 |
| 背包 | 简化布包 | 背包容量 |
| 仓库 | 现有仓库入口图标 | 仓库页 |
| 金币 | 单枚铜钱 | 在线/离线金币 |
| 经验 | 单张卷轴 | 在线/离线经验 |
| 离线 | 简化月亮 | 离线入口与离线分区根基 |
| 时间 | 简化沙漏 | 离线金币/经验积累时间 |
| 宝箱 | 单个宝箱 | 普通、高级、离线宝箱相关 |
| 工具 | 现有工具入口图标 | 工具入口、工具经验、工具金币 |

未点亮状态由运行时降低图标亮度和饱和度实现，不生成第二套灰色图片。

## 3. 节点组件

### 3.1 几何

- Item Slot 显示尺寸：`90 × 90`。
- 图标使用 `ScaleToFit`，四边保留约 8 像素视觉内边距。
- 图标不得拉伸、裁切或铺满变形。
- 单个节点完整布局占位：约 `130 × 132`。
- 网格步长：`180 × 180`，节点包围盒之间至少保留约 50 像素间隔。

### 3.2 文本

节点结构固定为：

```text
[ 90×90 Item Slot + 正方形图标 ]
天赋名称
0/5
```

- 名称和等级必须位于 Item Slot 下方。
- 名称单行居中；长名称缩小字号，不换行侵占相邻网格。
- 普通节点显示 `0/5` 至 `5/5`。
- 根节点、四个入口、仓库页节点显示 `0/1` 或 `1/1`。
- 不显示 `MAX`。

### 3.3 状态

- 未点亮：图标置灰、降低亮度；相关连线置灰。
- 可升级或已升级：图标恢复原色；已经成立的连线点亮。
- 当前选中：叠加项目现有的方形选中边框，不替换 Item Slot。
- 详情栏操作按钮始终显示“升级”，复用其他界面正在使用的同款纸板按钮。

## 4. 四角网格布局

### 4.1 分区

根节点固定在画布中心，四个分区严格镜像并且不得跨越中心轴：

| 象限 | 分区 | 主干方向 | 水平支线 | 垂直支线 |
|---|---|---|---|---|
| 左上 | 战斗属性 | 左上 45° | 向左 | 向上 |
| 左下 | 背包、仓库、宝箱 | 左下 45° | 向左 | 向下 |
| 右上 | 在线挂机、离线奖励 | 右上 45° | 向右 | 向上 |
| 右下 | 工具 | 右下 45° | 向右 | 向下 |

根节点达到 `1/1` 后同时开放四个分区入口；这是唯一允许一次开放四个节点的特殊情况。

### 4.2 允许的连线

连线只能使用：

- 水平 `0°`；
- 垂直 `90°`；
- 对角 `+45°` 或 `-45°`。

禁止任意角度、曲线、穿过节点、共享节点包围盒或依赖运行时自由旋转所得的近似角度。连线必须按照离散网格坐标生成。

### 4.3 单元循环

每个45°主干节点是一个有实际奖励的节点，不允许使用无奖励门槛节点。

一个循环单元的几何关系为：

```text
垂直同类天赋链
        ↑
     主干节点 ───→ 水平同类天赋链
          ╲
           ╲ 45°
            下一主干节点
```

解锁顺序严格为 `1 → 2 → 1`：

1. 上一单元满足条件后，只开放一个新的45°主干节点。
2. 主干节点达到至少 `1/5` 后，开放水平、垂直两个支线首节点。
3. 水平、垂直首节点都达到至少 `1/5` 后，开放下一个45°主干节点，并点亮对应45°连线。
4. 支线后续节点只要求同一支线的前一节点达到至少 `1/5`。
5. 已经开放后，任意旧节点仍可随时继续升级至 `5/5`。
6. 最后一组允许只有一条支线，不补无奖励占位节点。

水平和垂直支线只向所在象限的外侧生长。每个主干网格点拥有独立的水平行和垂直列，因此不同循环的支线不会交叉或重叠。

## 5. 线路分组与现有节点映射

每条水平或垂直支线只承载一种名称前缀、一个实际效果类别和一个图标。45°主干使用统一的分区根基名称前缀与图标；主干各节点可以保留不同的实际奖励，详情栏必须明确显示真实效果。布局必须复用现有节点 ID，保证存档等级不丢失。

### 5.1 战斗区：五组

| 组 | 水平支线 | 垂直支线 |
|---|---|---|
| 1 | 固定攻击 | 固定生命 |
| 2 | 固定防御 | 挂机移速 |
| 3 | 攻击百分比 | 最终伤害 |
| 4 | 防御百分比 | 生命百分比 |
| 5 | 暴击率 | 暴击伤害 |

45°主干使用现有节点：

1. `Talent.Entry.Combat`
2. `Talent.Combat.FlatAttack.08`
3. `Talent.Combat.FlatHealth.08`
4. `Talent.Combat.FlatDefense.08`
5. `Talent.Combat.CriticalDamage.05`

对应支线使用剩余同类节点；例如固定攻击支线使用 `.01` 至 `.07`。挂机移速节点保持单节点支线。主干统一使用“战斗根基”名称前缀和战斗分区图标，但详情栏继续显示该节点的真实数值效果。

### 5.2 背包宝箱区：三组

| 组 | 水平支线 | 垂直支线 |
|---|---|---|
| 1 | 背包容量 | 仓库页 |
| 2 | 普通宝箱 | 高级宝箱 |
| 3 | 离线宝箱时间 | 无 |

45°主干使用现有节点：

1. `Talent.Entry.CapacityChest`
2. `Talent.Capacity.Backpack.34`
3. `Talent.Capacity.Backpack.35`

背包直线使用 `.01` 至 `.33`，仓库页直线使用现有四个仓库页节点。所有容量奖励总和保持不变，最终背包容量仍为 200。

### 5.3 挂机离线区：三组

| 组 | 水平支线 | 垂直支线 |
|---|---|---|
| 1 | 在线金币 | 在线经验 |
| 2 | 离线金币 | 离线经验 |
| 3 | 离线金币时间 | 离线经验时间 |

45°主干使用现有节点：

1. `Talent.Entry.IdleOffline`
2. `Talent.Idle.OnlineGold.35`
3. `Talent.Idle.OnlineExperience.35`

在线金币、在线经验支线使用 `.01` 至 `.34`；主干节点继续保留原节点真实奖励，因此每条效果的最终累计值仍保持原上限。

### 5.4 工具区：一组

| 组 | 水平支线 | 垂直支线 |
|---|---|---|
| 1 | 工具经验 | 工具金币 |

45°主干使用 `Talent.Entry.Tools`。两条支线继续使用现有十层节点。

## 6. 数值与存档兼容

- 不清空 `FGameXXKTalentProgress::NodeRanks`。
- 不改变现有节点的实际效果值、单节点最大等级或全局累计上限。
- 主干只重排现有节点，不新增会突破奖励预算的节点。
- 旧存档中的现有节点 ID 和等级原样保留。
- 前置判断由“前置节点满级”改成“前置节点等级至少 1”。
- 下一主干使用两个支线首节点的 AND 前置条件。
- 根节点与四个入口仍使用 `1/1`。
- 由于不改变持久化字段结构，不要求仅为布局升级存档版本；恢复后重新从目录定义计算可见状态即可。

## 7. 天赋界面交互

- 图谱使用大画布滚动查看，首次打开定位中心根节点。
- 购买后原位刷新图标、等级、连线和新开放节点，不重建整个工作台。
- 不重置水平或垂直滚动位置。
- 详情栏显示名称、当前等级、真实效果、下一等级价格和状态原因。
- 按钮始终叫“升级”；满级时按钮禁用，通过详情状态文字显示“已满级”，节点下方等级保持 `5/5` 或 `1/1`。
- 金币、仓库页、背包锁格和工具解锁状态在购买后同步原位更新。

## 8. 仓库界面

### 8.1 页签

- 仓库顶部只保留页签 `1–6`。
- 未解锁页签置灰且不可点击。
- 删除“上一页”“下一页”和“+”按钮。
- 仓库底部不再保留“排序”按钮；底部只显示两个批量转移按钮。

### 8.2 批量按钮

仓库底部使用项目现有同款纸板按钮：

- 左侧：`仓库 → 背包`
- 右侧：`背包 → 仓库`

### 8.3 批量移动规则

- 只操作当前仓库页；批量操作不会改变当前页。
- 包括装备、宝石、材料和普通道具。
- 锁定物品允许转移，转移后保持锁定。
- 已装备物品、工具格预留物品、鼠标当前拿起的物品不参与批量移动。
- 按来源物理格顺序处理，不自动排序。
- 可堆叠道具优先并入目标容器已有堆叠，再占用空格。
- 目标空间不足时能移动多少移动多少；剩余物品留在原处，不回滚已成功项目。
- 操作完成后保持当前仓库页不变。
- 成功提示：`已移动 X 件`。
- 部分完成提示：`已移动 X 件，目标空间不足`。
- 没有可移动内容或目标容器没有任何可用空间时，对应按钮禁用。

提示中的 `X` 按来源条目计数：一件装备或一整组堆叠道具都计为一件。若目标容器已经存在相同道具堆叠，则允许跨仓库页合并到该唯一权威堆叠；“当前页”限制仓库来源范围和新仓库格的分配范围。

批量规则由独立的权威规则函数执行。UI不得直接修改物品数组；返回结果至少包含移动数量、是否部分完成和停止原因。

## 9. 错误处理

- 单个来源格在执行时失效：跳过该格并继续处理后续格。
- 目标容器容量耗尽：正常结束并标记部分完成。
- 状态整体无法通过桌面库存校验：整个调用失败，不提交候选状态。
- 锁定仅限制自动合成/自动选择，不限制本次明确授权的仓库批量转移。
- 转移前存在鼠标携带或工具预留时，这些条目保持原权威位置且不进入批量候选。

## 10. 验收标准

### 10.1 视觉

- 节点内部只有一张正方形图标，无名称、等级或状态文字。
- Item Slot 和图标均保持 1:1，不拉伸。
- 根节点使用现有天赋入口图标。
- 新图标与入口图标保持一致的简化墨迹风格。
- 名称和等级位于图片下方。
- 任意两个完整节点包围盒不得重叠。
- 四个分区不得越过中心轴。
- 所有连线角度只能是 `0°`、`90°`、`+45°`、`-45°`。

### 10.2 解锁

- 根节点 `1/1` 后开放四入口。
- 主干 `1/5` 后开放两个支线首节点。
- 两个支线首节点都 `1/5` 后只开放一个下一主干。
- 支线节点 `1/5` 后开放同方向下一个节点。
- 开放后旧节点仍能继续升至 `5/5`。

### 10.3 数值与存档

- 现有节点等级在保存/读取后不变化。
- 攻击、生命、防御、百分比、暴击、挂机、宝箱、容量、离线和工具上限保持现有确认值。
- 重排后不存在满级无收益节点。

### 10.4 仓库

- 只通过 `1–6` 页签换页。
- 两个批量方向均严格限制当前仓库页。
- 验证装备、堆叠道具、锁定物品、工具预留、鼠标携带、容量不足与部分成功。
- 验证锁定状态跨容器保留。
- 验证移动后格子、页数、占用数字和提示实时刷新。

### 10.5 回归

- 天赋购买、战斗投影、挂机奖励、工具解锁和保存恢复测试保持通过。
- 背包左键移动、右键快捷操作、工具自动放置和仓库单格操作保持通过。
- PIE 在 `/Game/GameXXK/Maps/L_DesktopTrainingHUD` 上完成根节点、四角分支、滚动、升级和仓库批量转移实测。
