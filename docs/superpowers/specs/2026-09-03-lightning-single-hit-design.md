## 1. 确认范围

保留卡名雷走八方、CardId `Profession.Sorcerer.RanLingHuanYuan`、普通原生品质及对敌全体自动结算；最新已确认费用为1气／4内，见[法师气力费用](2026-09-03-sorcerer-energy-cost-design.md)。

雷走改为每个存活敌人一次直接攻击。沿用普通直接攻击的标记增伤与消耗流程，有标记时正常使用一层，保留其余标记；零标记也有一次基础攻击。取消按当前全部标记安排多次落雷的基础效果。没有“标记完全免耗”或“一次群攻只允许总共消耗一层”的特殊规则。

连霆穿云继续按每个敌人的标记快照安排多段落雷，基础55%、第4～5位70%，品质另乘一次；首牌阵赏保持先加标记5、固定五次70%落雷。由此区分单段重击与多段爆发。

## 2. 本轮用于计算的候选牌文

以下百分比为普通品质底值，尚未冻结；升级后乘对应品质倍率一次。

| 时机 | 候选效果 |
|---|---|
| 基础，目标无标记 | 对该目标进行一次120%攻击。 |
| 基础，目标有标记 | 改为一次180%攻击。 |
| 编序第3～4位，目标有标记 | 有标记档改为一次220%攻击。第5位仍为180%；零标记仍为120%。 |
| 雷走为任务首牌的阵赏 | 所有存活敌人标记＋3，然后各受到一次240%攻击；按普通命中规则消耗一层标记。 |

“有标记”的判断在每个目标受到这次攻击前读取其当时状态，不锁定首次主动出牌时是否有标记。一次攻击只进行一次对应目标的防御结算。

标记0／1／4的三个目标，在没有死亡、转阶段或其他状态变化时，结算后分别为0／0／3；只有后两个目标使用有标记倍率。一次攻击正常触发一份标记增伤，不随剩余层数叠加15%。

候选首牌阵赏从0标记开始，先加3再攻击，结束为2；从3开始则结束为5。若攻击触发转阶段，按既有规则清空负面状态，不能承诺保留上一阶段的标记。

## 3. 五牌任务与额外重放

- 雷走仍是含直接伤害的牌，不会因此满足六合“前一张不含直接伤害”的条件。
- 首次主动记录锁定品质、序位和编序资格。任务免费重放沿用这些记录，重新读取当前标记；不支付气力或内力。
- 重复主动打出已经记录的牌，沿用现有任务规则：执行基础效果，不重复推进任务或获得编序强化。
- 只在雷走为任务首牌时执行雷走阵赏。基础重放不会额外加3标记，也不自动使用阵赏的240%。
- 斗转雷阵赏继续按“标记＋2 → 额外重放最后一张雷牌 → 按剩余标记逐层落雷”结算。额外重放保留被重放牌的原品质与原序位。
- 例如最后一张雷牌是第5位普通雷走，从0标记开始的斗转阵赏先变2；雷走按180%打一段后剩1；斗转再结算一次自身史诗56%落雷。不能将雷走升级成史诗、误用第3～4位220%，或在中间插入雷走首牌阵赏。
- 击杀后停止该目标后续效果；转阶段后读取新阶段状态。保存／恢复不得重复命中、重复加标记或重复发放阵赏。

## 4. 与其他雷牌的关系

引雷定标与雷符索敌本轮保留既有基础、编序和阵赏。此前建议将引雷阵赏改为“标记5＋易伤2”是独立提案，用户本轮只选择雷走的攻击形态，故不混入本次数值对照。

推荐顺序之一为：引雷定标 → 雷符索敌 → 周天归元 → 雷走八方 → 连霆穿云。

在百级法师495攻击、目标146防御、等级差伤害倍率0.65、最低合法品质、检索失败的固定示例中，索敌结算后有4标记；第4位雷走造成705伤害并留下3标记，第5位连霆再造成3×150＝450伤害。免费重放同样按这一记录顺序运行。
