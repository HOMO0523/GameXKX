# 破军套：刀客冲锋与收招套装重做

日期：2026-08-11
状态：用户已确认设计，待 TDD 实施与 198 张全卡复审

## 1. 目标与替代关系

破军是刀客机制套装。它不再提供旧版“直接伤害 +5% / 首次多段破甲 / 首次攻击破甲目标追击”，而是奖励一回合内完成“刀客牌开场产生冲锋 → 下一张任意主动牌消费冲锋 → 刀客牌收招”的首尾编排。

保留套装名称、`Set.PoJun.2`、`Set.PoJun.4`、`Set.PoJun.6` 和已有装备实例归属；替换三档描述符类型、卡文和战斗监听。旧枚举只保留存档兼容映射，不得继续产生旧战斗收益。

## 2. 作用域

- 每名穿戴者独立生效，不是全队唯一。
- 只有来源角色为该穿戴者的刀客牌能够产生本套装的冲锋、收招与首尾完成记录。
- 冲锋原本仍可强化紧接着主动打出的下一张任意角色牌；消费牌不要求属于穿戴者。
- 同一团队若有多名穿戴者，各自维护独立来源与次数，但一个来源不能消费另一个来源的套装记录。

## 3. 三档效果

### 2 件·催锋

短文本：`每回合首次由穿戴者产生的冲锋被消费后，抽1张牌。`

精确规则：

1. 穿戴者以本回合第一张主动牌打出刀客牌，登记该卡冲锋。
2. 紧接着的下一张主动牌成功结算并实际消费该冲锋后，抽 1 张牌。
3. 每名穿戴者每个玩家回合最多触发一次。
4. 冲锋未被消费、消费牌支付或结算失败、只发生自动重放时均不触发。
5. 抽牌使用共享牌堆规则；牌堆不足时按既有弃牌堆洗牌规则处理，不凭空生成卡。

### 4 件·归势

短文本：`穿戴者收招后，将该牌的冲锋保存为下回合藏式。`

精确规则：

1. 点击结束回合时，最后一张主动牌是穿戴者的刀客牌且其收招成功结算，复制该牌的冲锋定义到一个“破军藏式”快照。
2. 破军藏式在下个玩家回合由第一张符合条件的主动牌消费；目标牌仍可属于任意角色。
3. 破军藏式与卡牌自身藏式分别记录、允许同时存在，并按稳定顺序“卡牌原生藏式 → 破军藏式”结算。
4. 同一穿戴者最多持有一个破军藏式；新记录替换尚未消费的旧破军藏式。
5. 若到下个玩家回合结束仍未消费，则失效。跨战斗不保留。
6. 自动重放、任务回放、协战、反击、格挡和 DoT 不产生或消费破军藏式。

### 6 件·首尾相生

短文本：`同回合消费冲锋并触发收招：下回合首张主动牌重放基础效果。`

精确规则：

1. 同一穿戴者在同一个玩家回合内必须同时满足：其冲锋被下一张主动牌成功消费；其刀客牌成为收招并成功结算。
2. 两项都成立后，为下个玩家回合登记一次“首尾相生”。顺序必须来自同一回合，但开场牌和收招牌可以是同一张或不同张；若同一张是本回合唯一主动牌，其冲锋没有被消费，因此不成立。
3. 下个玩家回合第一张成功结算的主动牌完成正常结算后，自动重放该牌的基础效果一次。
4. 重放使用首次结算锁定的卡牌定义、来源和合法目标快照；目标已经死亡或失效时，按既有自动重放合法目标规则处理，不能改为任意新目标。
5. 自动重放不支付气力或内力，不计主动出牌，不触发冲锋、收招、藏式、任务、药方、套装、重箭或其他“每打出一张牌”监听。
6. 每名穿戴者每个玩家回合最多登记一次；下个玩家回合结束仍未消费则失效；跨战斗不保留。

## 4. 结算顺序

一个完整循环采用以下顺序：

1. 第一张主动刀客牌支付并结算基础效果。
2. 登记该牌冲锋；自动产生的基础重放不再登记。
3. 下一张主动牌支付并结算，消费冲锋。
4. 若穿戴者有破军 2 件且本回合未触发催锋，完成抽牌。
5. 后续主动牌正常结算；自动行为不改写收招候选。
6. 玩家点击结束回合，最后一张主动刀客牌先结算其原生收招。
7. 原生收招成功后，破军 4 件保存该牌冲锋为破军藏式。
8. 若本回合已经消费该穿戴者冲锋，破军 6 件登记下回合首尾相生。
9. 下回合第一张主动牌依次消费原生藏式和破军藏式，完成正常基础与附加结算；随后首尾相生只重放该牌基础效果。

## 5. 失败与原子性

- 主动牌支付失败、目标非法或结算原子回滚时，不得消费冲锋、触发催锋或推进首尾相生。
- 收招结算失败时，不保存破军藏式，也不满足首尾相生的收招条件。
- 抽牌、藏式快照与首尾记录都必须写入战斗候选状态，整次动作成功后再提交。
- 战斗胜负已锁定后不再创建新的藏式或下回合重放；已进入同一结算队列的基础效果按全局胜负队列规则收尾。
- 任意自动重放最多带一个既有自动操作 ID；检测到同操作再次派生重放时直接拒绝，避免递归。

## 6. UI 与文本

- 不改变装备页、背包页或战斗 HUD 布局。
- 套装面板只替换三档短文本；公共 Tooltip 解释“冲锋”“收招”“藏式”和“基础效果重放”。
- 局内图标 Tooltip 使用本文件的短文本，不展开完整时序；详细规则进入卡牌关键词帮助页。
- 旧破军效果不得继续出现在装备 Tooltip、战斗日志或导出文档中。

## 7. TDD 验收矩阵

实现前必须先新增 RED 测试，至少覆盖：

1. 三个稳定套装 ID 仍存在，但旧枚举、旧文本和旧数值不再生效。
2. 2 件只在冲锋被真实主动牌消费后抽 1；未消费、失败结算、自动重放均不触发；同回合第二次不触发。
3. 4 件只在原生收招成功后保存；原生与破军藏式稳定共存，各消费一次；过期、替换和跨战斗清除正确。
4. 6 件要求同回合两项条件；只冲锋、只收招、单卡未消费冲锋均不成立。
5. 下回合首张主动牌基础效果恰好执行两遍，而冲锋、收招、任务、药方、套装和出牌计数都只按主动牌执行一次。
6. 多名穿戴者来源隔离；来源 A 的冲锋不能推进来源 B 的套装记录。
7. 目标死亡、群体目标、治疗/护甲/状态牌和无目标牌都遵守既有自动重放目标规则，不出现卡死或原子回滚。
8. 与刀客 18 张逐卡矩阵组合测试，确认每一种冲锋与收招都能进入套装循环且不存在无限链。
9. 198 张全卡复审、冷 UBT、精确 Automation、平衡观测和真实 PIE 全部通过后才允许提交套装实现。

## 8. 明确不做

- 不保留旧直接伤害、破甲或 120% 追击收益。
- 不把破军改成全队唯一。
- 不让自动行为产生主动牌计数或再次触发套装。
- 不新增 UI 页签、控件位置或布局尺寸。
- 不在本套装中额外加入固定伤害倍率、气力返还或内力返还。
