## 构图

- 画布为 `1920×1080`。
- 全屏水墨轻水彩场景，不使用中央纸张窗口。
- 虎王占据中央与右侧，是画面主视觉；姿势采用压低身体、近距离迫近的巨大尺度。
- 主角以小比例站在右下区域，面向虎王，形成明显尺度反差。
- 左侧为稳定的文字安全区，不让虎王头部、爪部或高对比背景干扰按钮。
- 场景可使用浅色纸张、水岸、竹木和青绿色植被，但不得加入未确认角色、Logo、水印或可读文字。

## 生成与校正方式

采用身份锁定的混合重绘：以虎王和主角素材作为强参考生成统一场景；若主角外观出现偏差，使用当前 512×512 主角立绘作为独立 PSD 校正层，不接受换装、换发型或去除竹篓。

生成插画本身不得含标题、按钮、Logo、水印或伪文字。所有 UI 内容在 Photoshop 中使用现有组件完成。
