# 路线临时卡退出与首领卡槽重设计(2026-08-14)

## 需求来源

用户实测验收后指示:
1. 路线临时卡全部删除——该体系整体退出,不再向任何卡池发卡;
2. 玩家卡组新增"首领卡槽 3 个",只有首领卡可以进入;
3. 击杀首领后,玩家可选择一张首领牌加入手牌(并占用一个首领卡槽);
4. 战后奖励只剩:首领牌(例外)、角色携带牌品质升级、遗物、气力点、抽牌数。

## 确认决策

| 项 | 决策 |
|---|---|
| 路线临时卡体系 | **彻底删除**:`FGameXXKRouteCardEntry` / 路线卡容量 12 / 18 张基础配方 / 事件与宝箱发卡 / 商人卡牌货架 / Boss 卡入路线牌库+替换流程,全部移除 |
| 首领卡 | 玩家卡组新增 `BossCardSlots`(上限 3);击杀 Boss 后三选一中"首领牌"选项选中后:写入空闲槽位,并立即加入当前手牌;槽满则候选剔除 |
| 首领卡池 | 沿用现有 Boss 专属池(虎/熊,`EGameXXKCardOwner::Route` 中的 Boss 子集);不进路线牌库 |
| 普通战奖励 | 遗物×2 + 卡组牌品质升级×1(角色携带牌,已落地语义不变) |
| 精英战奖励 | 属性奖(气力+1 或 抽牌+1)×1 + 卡组牌升级×1 + 遗物×1(不变) |
| Boss 战奖励 | 首领牌×1 + 卡组牌升级×1 + 遗物×1(首领牌去向改为 BossCardSlots+手牌) |
| 事件/宝箱 | 卡牌奖励 → 改为遗物/气力点/抽牌数;不再出任何卡 |
| 商人 | 货架只卖遗物(扩充格数),删除卡牌货架与刷新费卡牌逻辑(仅遗物) |
| 存档迁移 | v16 → **v17**:丢弃 RouteCardIds/RouteCardEntries,新增 BossCardSlots(默认空);迁移测试钉死行为 |

## 假设(实现默认,如与预期不符请指正)

- 首领卡槽属于英雄卡组(与 HeroSelectedCardIds 并列持久化于 CardRun)。
- "加入手牌":Boss 战胜利结算时,选中的首领牌立刻进入当前战斗手牌(当次战斗若已结束则进入下一战起始手牌逻辑=正常抽牌规则处理)。
- 路线图/旅行币/路线节点/精英/Boss 流程保留,只是不再承载卡牌掉落。
- 路线商人仍使用旅行币购买遗物。

## 范围边界

- 不动:198 张卡规则、品质升级规则、遗物、气力/抽牌加成、战斗模拟、地形、城镇。
- 删除涉及的公共入口:`FGameXXKRunDeckRules`、`FGameXXKRouteCardRecipe`、`RouteCardEntries` 相关门面与 UI(路线商人卡牌货架、路线遭遇发卡、Boss 替换流程)。

## 验证

- 冷 UBT + 全量 Automation(0 failed)+ 真机 PIE:普通/精英/Boss 三选一构成、Boss 牌入槽+入手牌、槽满剔除、迁移 v17 清空旧路线卡、事件/宝箱/商人不再出卡。
