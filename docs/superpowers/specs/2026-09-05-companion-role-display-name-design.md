# GameXXK 永久伙伴职业统称设计

## 1. 目标

永久伙伴不再显示由 `Role + NameSeed` 生成的随机中文姓名。所有玩家界面统一使用简短职业统称，降低记忆负担，并与卡组、装备和配队分析中的职业名称一致。

## 2. 正式名称

| 角色职业 | 正式显示名 |
|---|---|
| `Blade` | 刀客 |
| `Guard` | 守卫 |
| `Healer` | 药师 |
| `Hunter` | 弓手 |
| `Sorcerer` | 法师 |
| `FormationMaster` | 阵师 |

`Invalid`、Hero、QuestNpc、Route 等非永久伙伴角色不产生伙伴职业名。

## 3. 同职业伙伴区分

同职业伙伴允许拥有相同正式名称，不追加随机姓名、甲乙编号或会随名册顺序变化的后缀。内部和操作目标继续使用稳定 `InstanceId`。

需要区分同职业伙伴的名册位置显示：

`职业名 · Lv.等级 · ★星级`

详细资料继续显示出战状态、卡组、装备和属性。战斗HUD、卡牌所有者、路线商店和配队报告只显示职业统称，因为当时只有一名该职业伙伴实例处于相关上下文。

## 4. 兼容边界

- `NameSeed` 字段继续保存在旧档和运行时结构中，只作兼容墓碑，不参与显示。
- 不重写伙伴 `InstanceId`、招募模板、头像变体、卡牌种子、完整牌池、等级、星级或装备。
- 旧存档载入后立即显示职业统称，不需要新增存档版本。
- 删除运行时姓/名数组和混合算法；不得在其他UI复制一份新的职业名称映射。

## 5. UI 文本

- 招募成功：`获得伙伴：刀客`。
- 重复招募：`招募重复：刀客转化为1枚升星印。`
- 伙伴资料标题：`刀客` 或 `刀客 · 已出战`。
- 名册悬停：`刀客 · Lv.15 · ★2`。
- 挂机条/队伍：`刀客 Lv.15`。
- 卡牌所有者、路线商店：`刀客`。

职业词不得继续出现“护卫、医师、猎手、术士”等同义版本。

## 6. 验收

- 六个永久伙伴职业对任意 `NameSeed` 返回第2节固定名称；
- 不同种子不再改变显示名；
- 无效角色返回空字符串；
- 同职业多实例仍以稳定实例ID完成选择、替换、装备和卡组编辑；
- 名册用等级、星级和出战状态提供必要区分；
- 商店结果不出现“刀客（刀客）”等重复职业文本；
- 全项目玩家可见职业词统一为刀客、守卫、药师、弓手、法师、阵师；
- 旧档往返不修改 `NameSeed` 或任何伙伴玩法数据。
