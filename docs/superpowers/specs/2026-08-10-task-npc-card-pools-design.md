# GameXXK 六名任务 NPC 卡池设计

日期：2026-08-10

状态：24 张候选牌已逐张口头确认，等待书面规格复核

范围：土司首领、金贵、琼么儿、周光祖、月白、宋金宝的职业定位、4 选 3 牌池、NPC 法术小任务、NPC 重箭、协战、反击来源与地势收益

本规格取代旧设计中上述六名任务 NPC 的卡牌费用、目标和效果。角色身份、立绘、属性、任务路线、被动能力及已确认的局内 UI 布局保持不变。

## 1. 目标

六名任务 NPC 的牌必须同时满足以下目标：

1. 每名 NPC 适配两种职业机制，并让六种职业各获得两名可配合的任务 NPC。
2. 每名 NPC 保留 4 张候选牌，加入任务路线时只携带其中 3 张。
3. NPC 牌整体强于普通职业牌，气力消耗以 0–1 为主，但不能依靠未携带的第四张牌才能运转。
4. 卡面基础效果保持一行；冲锋、收招、任务奖励各使用一条短句，公共规则进入关键词 Tooltip。
5. 每张非任务牌能在单牌内建立并利用其主要机制；法师型 NPC 则由所带 3 张牌共同完成一个短任务闭环。
6. 不新增战斗页面、页签或改动现有布局。

## 2. 非目标

- 不修改六名 NPC 的美术、被动、基础属性或路线身份。
- 不把任务 NPC 牌加入永久伙伴职业卡池、商店奖励池或升级解锁池。
- 不修改永久伙伴“出生 6 张、终身不解锁新牌”的规则。
- 不在本规格中重新设计六个永久职业的 18 张牌。
- 不改变已确认的流血、中毒、灼烧、蚀伤、气势、标记、灵动、护甲衰减和双方同时死亡规则。
- 不在本规格中决定新的任务进度 HUD；如现有反馈不足，必须另行讨论表现方案。

## 4. 4 选 3 生成规则

1. 任务 NPC 加入本次路线时，从其 4 张候选牌中等概率、无重复地取得 3 张。
2. 四种“缺少其中一张”的组合概率相同，均为 25%。
3. 结果由路线随机种子确定并写入存档；读档、重放和战斗重试不得重新抽取。
4. 未携带的第四张牌不进入抽牌堆、弃牌堆、消耗区或法术任务。
5. “检索未完成任务牌”只能访问本场已经携带的另外两张牌，不能生成未携带的第四张牌。
6. 现有固定列出前三张牌的默认配置必须迁移为 4 选 3，不能继续让第四张永远不出现。

## 5. 公共结算规则

### 5.1 主动出牌与自动基础效果

“主动打出”只指玩家从手牌中确认并支付费用打出的牌。协战、反击、重箭追加段、任务重放和冲锋重放都只结算基础效果，不视为主动出牌，并且：

- 不改变本回合第一张主动牌；
- 不替换收招候选；
- 不推进法术任务；
- 不再次触发冲锋、收招或任务奖励；
- 不消耗“一诺千金”等仅作用于主动牌的次数；
- 不计入依赖主动出牌张数的套装和回合计数。

### 5.2 协战

- “协战 X%”不是生成或打出一张牌，而是指定友方立即对敌人造成一次 X% 攻击伤害。
- 卡面写“协战者”时，协战者为当前攻击最高的存活友方；并列时按稳定单位 ID 决定。
- 卡面直接写“一名友方……并协战”时，玩家选择的友方就是协战者。
- 卡牌选择了敌人时，协战攻击该目标。
- 卡牌只选择友方时，协战攻击标记层数最高的存活敌人；并列时选择生命比例最低者，再按稳定单位 ID 决定。
- 协战属于直接攻击，正常读取并消耗标记，正常触发流血。

### 5.3 NPC 重箭

NPC 牌写出“重箭”时按以下顺序处理：

1. 先结算基础效果并让协战者获得牌面蓄力。
2. 立即锁定协战者当前全部蓄力层数。
3. 消耗锁定的全部蓄力。
4. 按每层规则依次结算重箭攻击、抽牌或内力收益。

重箭追加攻击均为协战者的直接攻击。攻击次数在消耗时锁定，不会因中途获得新蓄力而增加。

### 5.4 反击来源

- 反击在敌方一张符合条件的单体攻击牌完整结算后触发。
- 同一反击来源面对一张多段敌方牌只触发一次；多个来源分别触发。
- 闪避不会取消已经登记的反击。
- 守卫型卡牌授予的反击造成“100% 攻击力＋触发时当前护甲”的伤害。
- 刀客型卡牌以及其他来源的反击造成 100% 攻击力伤害。
- 除非牌面明确写出，否则反击不消耗护甲。

土司首领和金贵表中的反击为守卫型来源；宋金宝“贵客令”的反击为刀客型来源。

### 5.5 药效与治疗反转

- 药效由打出卡牌的角色持有。
- 治疗或治疗反转开始时，先锁定并消费该角色当时的全部药效；每层使本次行动的每个目标增加 1 点结算值。
- 对敌方使用可反转治疗的牌时，敌人直接失去“基础治疗＋药效快照”的生命；该生命损失不经过防御和护甲，也不视为直接攻击。
- 群体治疗只锁定并消费一次药效快照，但每名目标都获得完整加值。
- 本次治疗、生命损失或其他监听器随后新产生的药效属于下一次行动，不纳入已经锁定的快照，也不会被本次消费清除。
- 一次获得 6 层药效同时按已确认的药师规则获得 1 层气势。
- 牌面造成的我方生命消耗最低只能降至 1 点生命，不能杀死友方。

### 5.6 持续伤害与毒爆

本规格沿用全局规则：

- 流血在受到直接攻击时按当前层数造成伤害并减少 1 层，回合结束不减层。
- 中毒和灼烧按各自触发点结算，并在触发后减少 1 层。
- 毒爆使目标的流血、中毒、灼烧各结算一次并各减少 1 层。
- 蚀伤不被毒爆引爆。

### 5.7 NPC 地势收益

周光祖和月白的“触发当前地势收益”使用同一短关键词。相关牌固定选择一名敌人，避免因地势改变玩家选取模式：

| 当前地势 | 每次收益 |
| --- | --- |
| 平原 | 所选敌人获得 2 层灼烧 |
| 山崖 | 所选敌人获得 2 层破绽和 1 层标记 |
| 森林 | 我方全体回复 4 点生命 |
| 水岸/渡口 | 我方全体回复 3 点内力 |
| 村寨 | 抽 1 张牌，我方全体获得 4 点护甲 |
| 洞穴 | 我方全体获得 8 点护甲和 1 次守卫型反击 |

触发两次或三次时按表格顺序完整结算多次。NPC 地势牌不切换场地，因此不会突破永久阵师出生时固定两张换场牌的限制。

### 5.8 NPC 法术小任务

月白和宋金宝使用相同的三牌小任务：

1. 本场携带的 3 张牌就是任务所需的 3 个不同 CardId。
2. 没有任务时，第一张主动打出的本 NPC 牌开启任务，记录其任务奖励、原目标和第一顺位。
3. 在任务完成前不会产生新任务。
4. 其余两张携带牌各主动打出一次后完成任务；重复同一张不能代替缺少的 CardId。
5. 完成时按三张牌首次主动打出的顺序，免费重放各自基础效果。
6. 三次基础重放结束后，只执行第一张牌的任务奖励。
7. 自动重放不推进任务，也不触发卡牌自身的冲锋、收招或任务奖励。
8. 原目标仍合法时重用原目标；原目标失效时，敌方效果改选生命比例最低的合法敌人，友方效果改选生命比例最低的合法友方，并以稳定 ID 解决并列。
9. 完成后清空任务记录；之后下一张主动打出的本 NPC 牌可以开启新任务。

“检索 1 张未完成任务的宋金宝牌”复用现有选牌交互，从本场携带且任务尚未登记的牌中选择，并从抽牌堆或弃牌堆移入手牌。若所有符合条件的牌都已在手牌或正在结算，则不生成复制牌。

## 12. 卡面、Tooltip 与交互

### 12.1 卡面文本

- 基础效果最多一行。
- 只有带刀客机制的牌显示“冲锋”和“收招”两条短句。
- 月白和宋金宝显示一条“任务奖励”短句。
- 协战、重箭、地势收益和三牌任务的公共流程不重复写在每张牌上。
- 任务 NPC 继续使用现有任务 NPC 卡框，不因职业配对切换为职业卡框。

### 12.2 短 Tooltip

| 关键词 | 局内短文本 |
| --- | --- |
| 协战 X% | 一名友方立即攻击一次，倍率为 X% |
| 重箭 | 消耗协战者全部蓄力，逐层触发本牌重箭效果 |
| NPC 小任务 | 所带 3 张各主动打出一次，依序重放基础效果，再结算首牌奖励 |
| 地势收益 | 按当前场地触发对应的固定收益 |
| 守卫型反击 | 敌方单体攻击牌结算后，造成 100% 攻击＋当前护甲 |
| 刀客型反击 | 敌方单体攻击牌结算后，造成 100% 攻击 |

### 12.3 UI 边界

- 不移动血条、状态图标、手牌、气力、内力或敌方意图区域。
- 不新增战斗页面或页签。
- 异草辨识只扩展现有单位合法目标高亮，不创建新的目标选择界面。
- 宋金宝的检索复用现有选牌交互。
- NPC 小任务的进度表现需要在实施前单独确认；本规格只确定行为，不授权新增独立面板。

## 13. 数据与运行时边界

实现时应保持下列职责分离：

1. 卡牌目录只保存 CardId、费用、固定目标模式、基础效果、冲锋、收招和任务奖励数据。
2. 任务 NPC 牌池生成器负责 4 选 3、确定性随机和存档，不把随机逻辑写进 UI。
3. 协战与 NPC 重箭使用共享攻击解析器，不能复制一套绕过标记、流血和防御的伤害公式。
4. 反击来源记录来源类型、剩余次数和授予者，不能只保存一个无法区分公式的总层数。
5. NPC 法术任务以独立运行时状态记录三个 CardId、首次顺序、原目标和首牌奖励。
6. 地势收益由共享表驱动，周光祖和月白不得各自硬编码六份不同规则。
7. 药效、持续伤害和标记继续走全局状态解析器。

24 张牌继续使用现有规范 CardId，因此不需要 CardId 迁移；旧费用和旧效果由新定义直接取代。

## 14. 验收与测试要求

### 14.1 牌池生成

- 每名 NPC 恰有 4 张候选牌，任意一次结果恰有 3 张且无重复。
- 四种缺牌组合在固定大样本种子下近似等概率。
- 相同种子、存档和重试得到相同三张牌。
- 未携带第四张不进入任何战斗区域，也不能被检索。

### 14.2 协战、重箭与标记

- 协战者选择、默认敌方目标和并列规则确定。
- 重箭先锁定并清空全部蓄力，再按锁定层数结算正确次数。
- 多段重箭逐段读取标记和流血，命中次数不会被中途新蓄力改变。
- 盟寨誓约和耳目密报任务奖励的多名友方攻击分别结算。

### 14.3 反击

- 守卫型反击使用 100% 攻击＋当前护甲，刀客型反击只使用 100% 攻击。
- 一张多段敌方单体牌对每个来源只触发一次。
- 多个反击来源分别触发，闪避不取消反击。
- 土司军令的免消耗只保护我方下一次实际反击。

### 14.4 药效与持续伤害

- 单体基础治疗不超过 12，群体基础治疗不超过 6；药效作为主要增幅来源。
- 友方生命消耗不能降至 0。
- 异草辨识的友方治疗与敌方生命扣除使用同一药效快照。
- 群体治疗对每名目标获得完整药效加值，但药效只消费一次。
- 蛊雾迷踪和岩粉封脉的毒爆结算流血、中毒、灼烧并各减 1，不结算蚀伤。

### 14.5 地势收益

- 六种地势分别得到表中效果。
- 两次和三次触发按顺序完整执行。
- 所有相关卡在六种地势下保持同一手动目标模式，不出现预览可打、结算回滚或卡牌卡手。
- NPC 地势牌不修改当前场地。

### 14.6 法术小任务

- 四种 4 选 3 组合都能完成任务。
- 三个不同 CardId 各主动打出一次才完成，重复牌不顶替缺牌。
- 完成时按首次顺序重放三次基础效果，只执行首牌奖励。
- 自动重放不推进任务、不触发奖励、不触发冲锋/收招、不计入主动出牌套装。
- 原目标死亡后的确定性改选正确。
- 完成后可以由下一张 NPC 牌开启新任务。
- 宋金宝检索只访问本场携带且尚未完成的牌。

### 14.7 刀客顺序

- 土司首领与宋金宝的冲锋只在其为本回合第一张主动牌时建立。
- 冲锋可以作用于任意角色的下一张主动牌。
- 收招只由结束回合前最后一张主动刀客牌触发，自动重放不替换候选。
- 石门守势重定向、土司军令群体改写和一诺千金费用预览在确认前即显示正确结果。

### 14.8 回归

- 气势仍按每层为本次直接攻击增加固定伤害，不自然消耗、不设上限。
- 标记仍使每次直接命中增加 15% 伤害并逐段消耗。
- 灵动仍按 25% 完美闪避消耗 1 层，失败后有至少 2 层则消耗 2 层普通闪避。
- 护甲仍在常规回合衰减点减半，只有明确效果可以阻止。
- 双方同时死亡仍按玩家胜利。
- 现有局内 UI 布局不发生变化。

## 15. 完成标准

本规格进入实施计划前必须满足：

- 六名 NPC 的职业配对、4 选 3结构和 24 张候选牌均无未决数值；
- 每种 4 选 3 组合都保留双方职业体验；
- 卡面文本短，公共流程集中在 Tooltip；
- 法术任务、冲锋/收招、协战、重箭、反击、药效与地势收益之间不存在递归或重复计数歧义；
- 不包含占位项或未确认的新页面；
- 用户完成本书面规格复核。
