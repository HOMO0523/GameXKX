# GameXXK 玄甲与山河套装完整设计

## 1. 目标与边界

本规格冻结玄甲、山河 2/4/6 件套的玩家文本、运行时语义、触发顺序、数值、作用域和模拟口径。它替换 `GameXXKEquipmentSetCatalog` 中尚无消费者的旧描述意图，以及旧项目文档中“待单独评审”的状态。

保留现有稳定 ID：

- `Set.XuanJia.2`、`Set.XuanJia.4`、`Set.XuanJia.6`；
- `Set.ShanHe.2`、`Set.ShanHe.4`、`Set.ShanHe.6`。

2/4/6 件效果累积生效。套装品质不改变阈值效果；装备基础属性、强化、宝石和词缀仍按各自既有规则结算。

## 2. 正式玩家文本

### 2.1 玄甲

| 件数 | 玩家文本 |
|---:|---|
| 2 | 穿戴者产生的护甲提高10%。 |
| 4 | 我方回合开始时保留50%护甲；每个敌方回合首次格挡后，追加80%攻击伤害。 |
| 6 | 全队唯一。敌方回合首次有友方因攻击损失气血后，全体获得穿戴者40%防御的护甲；穿戴者援护其他友方各1次。 |

### 2.2 山河

| 件数 | 玩家文本 |
|---:|---|
| 2 | 每回合首次打出地势牌后，抽1张。 |
| 4 | 每回合首张地势牌少耗1气；结算后，其他友方各回复2内力。 |
| 6 | 全队唯一。每个我方回合开始时，由穿戴者触发1次当前地势。 |

### 2.3 共用 Pill

- `地势牌`：会改变或触发地势的主动牌。
- `全队唯一`：同名团队套装只生效1份。

玩家文本不展开取整、失败事务、重复来源选择、伤害管线、自动结算来源和非递归规则。以下章节是实现、预览、战斗日志和模拟器的唯一后台口径。

## 3. 玄甲完整语义

### 3.1 二件：护甲产生增幅

玄甲二件只增强**以穿戴者为来源新产生的护甲包**。来源包括穿戴者的主动牌、自动效果、装备效果和由穿戴者触发的护甲地势。群体护甲仍向每个合法目标分别授予完整数值。

先按卡牌或地势规则算出该护甲包的整数基础值，再把玄甲二件的 `+1000` 基点与同类“护甲产生”词缀相加，统一向上取整一次：

`最终护甲 = ceil(基础护甲 × (10000 + 护甲产生总基点) / 10000)`

以下操作不是新的护甲产生，不再次获得玄甲二件增幅：

- 保留已有护甲；
- 翻倍、复制或移动一个已经结算的护甲数值；
- 按已消耗护甲固定返还；
- 读取护甲用于攻击；
- 其他角色产生、但授予穿戴者的护甲。

### 3.2 四件：保留与格挡追加伤害

在我方回合开始的常规友方护甲清除边界，玄甲四件穿戴者改为保留：

`保留护甲 = floor(边界前剩余护甲 × 50%)`

保留不属于护甲产生，不接受二件或护甲产生词缀的再次增幅。

若一个明确卡牌效果为该边界提供完整护甲保留，则完整保留优先，玄甲四件不再把结果减半。不同来源不得连续执行“完整保留后再保留50%”。

每个敌方回合，穿戴者第一次在一张敌方单体直接攻击牌的反应边界成功结算至少一个普通格挡来源后，对同一攻击者追加一个80%当前攻击的单体反应伤害包：

- 同一敌方牌触发多个格挡来源时，玄甲只追加一次；
- 没有成功格挡、群体攻击、DOT、固定生命损失和非攻击事件不触发；
- 追加包使用隐含品质1.0，经过敌方防御、标记、破绽和等级差；
- 追加包不触发格挡、反击、玄甲或其他攻击反应；
- 穿戴者或攻击者在追加包前已经倒下时不执行；
- 次数在每个敌方回合开始时重置。

普通格挡全部结算后再执行玄甲追加包，避免它改变当前敌方牌已经锁定的格挡护甲快照。

### 3.3 六件：团队救援

玄甲六件是全队唯一效果。每个敌方回合第一次有至少一名存活友方因同一张敌方直接攻击牌实际损失气血时，记录一次待结算救援。

在该敌方牌全部伤害包、原有援护重定向及普通格挡/反击结束后，若六件套来源仍存活，则按以下顺序结算一次：

1. 以六件套穿戴者为来源，计算 `ceil(穿戴者当前防御 × 40%)` 的基础护甲；
2. 应用玄甲二件和穿戴者合法护甲产生词缀；
3. 每名存活友方各获得一份完整护甲；
4. 穿戴者向每名其他存活友方分别增加1次援护。

救援不保护已经完成的触发牌，只影响后续敌方攻击。已有相同援护关系增加1次，不覆盖旧次数；穿戴者不能援护自己。

下列生命变化不触发玄甲六件：

- 流血、中毒、灼烧、蚀伤；
- 玩家牌或装备造成的非致死自损；
- 出牌生命费用、治疗反转和友方固定生命变化；
- 阶段切换、存档迁移或调试修正；
- 伤害全部被护甲吸收、没有实际气血损失的攻击。

群体或多段敌方攻击只在整张牌结束后触发一次。触发来源在该牌或普通反应中倒下时，本次救援失效且不会转交另一名玄甲穿戴者。

### 3.4 玄甲百级基准

百级守卫防御358、无额外护甲产生词缀时：

| 场景 | 基础值 | 玄甲二件后 |
|---|---:|---:|
| 80%防御护甲 | 287 | 316 |
| 140%防御护甲 | 502 | 553 |
| 200%防御护甲 | 716 | 788 |
| 六件40%团队救援，每名友方 | 144 | 159 |

边界前剩余300护甲时，玄甲四件保留150。边界前剩余301护甲时保留150。

## 4. 山河完整语义

### 4.1 地势牌分类

“地势牌”是有效卡牌定义中含有以下任一基础效果的主动牌：

- `ChangeTerrain`；
- `TriggerTerrainBenefit`。

分类由卡牌定义决定，预览、费用和结算使用同一结果。主动打出的临时复制仍是地势牌；任务重放、装备重放、地势监听和其他自动来源不算“打出地势牌”。

### 4.2 二件：首张地势牌抽牌

每个玩家回合，穿戴者第一次成功主动打出地势牌并完成该主动事务后抽1张牌。

- 自动重放不触发，也不占用本回合次数；
- 施放失败、费用不足、目标无效或事务回滚不占用次数；
- 强制弃牌、检索等牌内待选择事项先完成，再结算套装抽牌；
- 抽牌使用普通手牌容量、重洗和挂起规则；
- 多名二件穿戴者分别记录自己的次数。

### 4.3 四件：减费与队友回内

每个玩家回合，穿戴者第一张地势牌的实际气力费用减少1，最低为0。该减费与其他合法减费相加后统一限制到0，预览与支付必须一致。

只有成功支付并完成主动事务才消耗本回合四件次数。结算后，所有其他存活友方各回复2点当前内力，不超过各自固定上限；穿戴者不获得这2点内力。

同一张首牌同时满足二件和四件时，顺序为：

1. 费用预览并应用四件减费；
2. 主动牌及其待选择事项完整结算；
3. 二件抽1张；
4. 四件为其他友方各回复2内力。

套装抽牌和回内不计入地势触发次数，不开启任务或药方，也不再次触发山河。

### 4.4 六件：阵眼地势

山河六件是全队唯一效果。每个玩家回合开始时，先完成友方护甲清除/玄甲保留、气力与内力恢复以及普通手牌补充；在玩家获得操作权之前：

1. 先结算存活永久阵师伙伴提供的普通自动地势；
2. 再由山河六件穿戴者额外触发当前地势1次。

没有永久阵师伙伴时，第二步仍照常发生。六件套穿戴者在该时点已经倒下时不触发。

山河阵眼触发属于装备自动来源：

- 不算主动牌，不触发二件、四件、追风、任务、药方或卡牌出牌计数；
- 不接受“下一张地势牌”“下一次主动地势”等只服务主动牌的次数覆盖；
- 不改变当前地势，也不把本回合标记为“已换地势”；
- 护甲地势使用六件套穿戴者当前防御；
- 地势载荷使用隐含品质1.0，按批准地势规则结算；
- 村镇抽牌发生在普通手牌补充之后，因此可以把手牌增加到常规5张补充目标以上；
- 多名六件穿戴者只使用一个稳定团队来源。

### 4.5 山河百级基准

百级阵师防御301、队伍最高等级100时，六件阵眼每回合额外一次地势收益为：

| 地势 | 额外收益 |
|---|---|
| 平原 | 全体敌人各获得10点灼烧 |
| 断崖 | 全体敌人各获得2层破绽、1层标记 |
| 山林 | 全体友方各治疗50 |
| 水岸/渡口 | 全体友方各回复3内力 |
| 村镇 | 抽1张；全体友方各获得61护甲 |
| 洞窟 | 全体友方各获得121护甲和1次格挡 |

若山河六件穿戴者同时拥有玄甲二件，且护甲地势由该穿戴者触发，玄甲二件可以作为合法的跨套装护甲产生增幅。山河本身不再提供旧5%或12%地势百分比，不存在离散层数的百分比换算。

## 5. 全队唯一来源

玄甲六件和山河六件分别选择一个稳定团队来源，不叠加同名六件效果。来源选择沿用装备系统规则：

1. 有效同套件数更高；
2. 装备品质与强化综合评分更高；
3. 仍相同时使用稳定角色 ID。

来源在战斗开始时快照。来源倒下后，本场不转交另一名穿戴者，避免回合中改变计算者、防御和次数状态。玄甲2/4和山河2/4仍为穿戴者个人效果，可以由不同角色分别生效。

## 6. 预览、日志与显示

- 装备 Tooltip 使用第2节精简玩家文本。
- “地势牌”和“全队唯一”使用第2.3节 Pill，不把后台边界塞回短文本。
- 当前穿戴者上下文存在时，玄甲六件和护甲地势预览显示本角色可产生的实际护甲数字；详细信息可显示40%防御等系数。
- 玄甲格挡追加伤害显示为独立装备来源；不能并入普通格挡数字后失去归因。
- 山河二件抽牌、四件减费/回内和六件地势各自记录稳定来源 ID。
- 战斗日志说明触发套装、穿戴者、目标、基础值、增幅、实际护甲/伤害、次数是否已经使用。

## 7. 存档与迁移

稳定套装 ID、装备实例和穿戴关系不变。旧存档中的玄甲、山河实例不重掷、不改品质、不改强化和词缀。

旧运行时只有描述符而没有对应消费者，因此启用新规则不会丢失既有已生效收益。载入进行中的战斗时：

- 从已经保存的装备战斗快照识别现有套装来源；
- 新增的每回合次数字段使用“本回合未触发”安全默认值；
- 不补发过去回合的护甲、抽牌、内力、援护、格挡伤害或地势；
- 从载入后的下一个合法触发点开始生效；
- 不因迁移额外执行一次回合开始地势或护甲保留。

## 8. 验收矩阵

玄甲至少覆盖：

- 2件单体、群体、地势护甲及非来源护甲；
- 复制、翻倍、固定返还和保留不二次增幅；
- 4件奇偶护甲取整、完整保留优先和普通清除对照；
- 多个格挡来源只追加一次80%伤害；
- 群攻、DOT、固定损血不触发4件；
- 6件单体、多段、群攻、全护甲吸收、来源倒下和已有援护叠加；
- 青囊、自损、毒伤不会提前触发团队救援；
- 同名六件来源唯一且存档往返稳定。

山河至少覆盖：

- 所有改变/触发地势牌的分类与非地势牌排除；
- 2件每穿戴者每回合一次、失败不占次数、自动重放不触发；
- 4件预览/支付一致、最低0气、其他友方回内且不含穿戴者；
- 2/4同牌固定顺序和挂起选择；
- 6件有/无永久阵师伙伴、来源倒下、首回合和后续回合；
- 六种概念地势的批准数值、Armor来源防御与DOT等级增幅；
- 六件自动地势不消费主动牌地势修饰、不触发任务或追风；
- 同名六件来源唯一、跨玄甲二件护甲增幅和存档往返稳定。

共同要求预览、实际结算、战斗日志、Tooltip和模拟遥测一致；任何套装自动伤害或地势不得递归触发自身。

## 9. 实施顺序

先把基础地势运行时迁移到批准的新载荷，再实现玄甲和山河消费者。山河不得建立在旧的森林治疗4、村镇护甲4、洞窟护甲8之上。

建议依赖顺序：

1. 批准地势载荷及来源防御；
2. 玄甲二件护甲产生增幅；
3. 玄甲四件保留与格挡追加；
4. 玄甲六件团队救援；
5. 地势牌稳定分类；
6. 山河二/四件主动牌监听；
7. 山河六件阵眼；
8. 存档、预览、Tooltip、日志和模拟遥测；
9. 加入配队与装备联动模拟排名。
