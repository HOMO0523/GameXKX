# 工具交互与九合一改造

状态：已完成。最终结果见[工具验收](../../production/2026-09-10-tools-redesign-acceptance.md)。用户已明确允许本任务在根项目 `codex/ui-visual-optimization` 分支实施和测试；不创建工作树。后文构建过程段落保留作历史。

## 已确认行为

- 五种工具默认可用，天赋只继续提供工具收益加成分支。
- 保留九宫格。分解和两类合成可用九格；强化、洗炼只用首格；镶嵌首格放装备，后续格显示该装备的真实宝石孔，剩余格停用并提示“本模式不使用”。切换时释放不兼容预留，保留兼容目标。
- 宝石九格各预留一个，同品质可混类型。点击合成才消耗九个，产出一种随机宝石；品质遵循既有九合一概率表。数量不足、混品质、宇宙品质和过期来源不得消耗。
- 装备和宝石共用 `docs/superpowers/specs/2026-08-28-generic-dialogue-tutorial-shop-design.md` 第14节概率表。当前代码误为固定升一阶；本次补齐规则，并让满格预览读取相同数据。高阶可能保持原品质，仍消耗九个；不把“下一等级”误写成必定升级。
- 分解、合成均有自动放置。空工具时，优先选择最低可凑足九件的同品质未锁定物品；较低品质不足九件则继续向上找。用户2026-09-10追加：所有品质均不足九件时，选数量最多、最接近九件的一档；数量相同选较低品质，自动填入现有数量。已有物品时保持原格和品质，按该品质尽可能补到九格，允许不足九格，不改选其他品质。宝石按每格一颗累计堆叠；后续手动放入也必须同品质、同类别。仓库参与开关沿用；自动放置只预留，不自动提交。
- 洗炼可选词缀；付费生成后显示“原属性”和“新属性”两块可点击选项，每块内含对应值，点击哪块就选哪版，取消独立的底部“采用/保留”按钮。结果待决期间不能重复付费，也不得修改目标；关闭后仍可恢复处理。
- 镶嵌拖入指定孔即执行，替换和拆卸返还宝石至背包；满包失败须整体回滚。点击已镶宝石后点击“拆卸”。保留装备以便连续操作。
- 强化成功后保留目标。按钮使用具体动作名；合成等级仅在装备合成显示；沿用纸面、字体及当前HUD缩放。
- 强化石、洗炼砂显示背包持有量与本次消耗；零材料或不足本次消耗时按钮禁用。
- 保留地图任务正在接入的行旅钱分解（2500金币/个且不吃天赋加成）、数量快照，以及商店、宝箱、路线等其他改动。
