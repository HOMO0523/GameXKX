## 交互与命令约定

- 首次改变游戏状态前建立临时测试会话；关闭面板后可继续试玩；“返回原进度”恢复进入前状态。
- 独立快照/预设存于`Saved/DevTools`。默认临时会话抑制正常存档和训练恢复点写入，显式保存Dev快照可供重开导入。
- 中文名用于界面，稳定ID用于命令；目录以当前启用的数据定义为准，历史废弃药品不作为普通发放候选。
- 命令入口接受版本化JSON，所有入口调用同一处理器；未知参数、无效ID、超界数量和不适用状态返回明确失败。
- 批测使用状态副本，保留种子、策略、版本、胜败/僵局/超限分类与实际战斗记录，不影响正在游玩的状态。
- 第一版不宣称搜索得到最优配装；深度策略搜索、自动调参和完整动画编辑不属于本轮闭环。

## 验收要点

- F10在桌面HUD和全屏战斗中开关同一Dev面板，Esc优先关闭Dev；游戏失焦时不抢占其他应用按键。
- 真实鼠标完成“检索物品→发放→指定角色穿装→查看属性→进入指定战斗→恢复快照”。
- 主角、伙伴、NPC配装归属一致；装备/宝石/强化生成经过现有规则校验。
- 无效命令及失败事务不留下部分装备、资源或状态变化。
- 相同场景/种子得到一致模拟输出；模拟前后原状态及存档字节不变。
- 会话期间涉及购买/奖励/退出的保存路径均不写玩家原档，返回原进度同时恢复挂机快照。
- 开发包的面板和本机命令入口独立于Editor专属MCP/Python插件。
