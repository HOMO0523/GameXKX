# 17种宝石与抗性接入

用户已确认三抗性图标、物理/法术分流与34项基础抗性方案。本计划续接十四宝石任务，复用当前分支授权；不建worktree、不擅自提交、不操作3D场景。

## 已确认的结算

- 物理：固定防御减伤→临时护甲→生命。法术：对应火/冰/雷抗性→临时护甲→生命。灼烧自然及引燃吃火抗，沿用持续伤害直扣生命；血/毒/蚀伤维持原通道。
- 三抗分别配置，基础值不随等级/难度普涨。正向名义增益S按R0+(75-R0)S/(75-R0+S)递减，最后减抗并夹到-25～75%。
- 抗性宝石沿用机制宝石品质曲线：0.5/1/2/4/8/16/29/47.5/68.5/86名义百分点；最终贡献取决于佩戴者基础抗性。基础三属性百分比仍为该曲线的一半。
- 直接伤害宝石对外更名物理伤害，稳定ID DirectDamage保留。物理/元素互斥；物理反击或元素反击的真正适用加成只合池一次。固定独立伤害和未接通的29条随机词缀不借机扩展。
- 万法归一继承其前一张法师牌的火/冰/雷元素，快照重放保留相同来源；倍率和出牌/落雷次数不变。
- 所有类型共用各自一张图标；宝石名称、槽底、tooltip与每颗镶嵌文字按自身品质显示。
