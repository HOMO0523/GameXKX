# 编队与共用卡组交互

状态：完成，最终证据见 `docs/production/2026-09-07-formation-deck-ui-acceptance.md`。

继续当前UI优化任务、根工作区 `codex/ui-visual-optimization`；不创建worktree、不改玩家存档。最新用户要求同时覆盖编队和背包卡组。

## 设计与实施顺序

1. 先截取当前编队与卡组。编队保留三名出战者的大卡、等级与简短身份，删除重复长说明；换伙伴/NPC打开与背包相同的单层半透明六卡横排。候选预览和确认编入分开，取消不换人。
2. 每位出战角色提供“编辑卡组”，在编队内打开共用卡组编辑器，并提供返回编队；角色选卡规则与背包一致。适合保留的功能是查看阵容、换人、配卡及简短状态，避免把完整属性长文堆进编队。
3. 共用卡组顶部加入2列/4列缩放和“展开选牌”。展开用整块纸面范围上的单层半透明遮罩，隐藏/阻挡背后的交互，卡牌铺满可用面积；按卡池数量适配密度。保留卡名、气/内、选中标记与tooltip，右下返回，确认与计数固定。
4. 切换密度、展开/收起、角色及入口时保留当前角色草稿；未满额禁用应用，打开/返回不修改正式卡组。修复清空草稿被自动重新填回的边界。
5. 行为测试覆盖草稿、两种布局/展开返回、编队入口与取消选人。冷UBT、针对性回归、50/75/100%实机截图与鼠标交互；恢复原会话和设置。

数值报告与动画修复单元已完成，证据见 `docs/production/2026-09-07-dev-balance-ui-acceptance.md`；新界面变化不需要重跑2,040场数值矩阵。
