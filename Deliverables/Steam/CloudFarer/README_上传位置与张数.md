## 使用方法

先看 `00_素材总览_不要上传商店.png`。总览上的标签用于识别素材，不能作为游戏截图或宣传图上传。
上传各子目录中单独的图片；文件名包含对应的 Steam 字段名和像素尺寸。

## 截图拍摄顺序

1. 桌面挂机：展示桌面工作台、正在进行的游历和成长。
2. 卡牌战斗：展示敌我双方、手牌和战斗目标。
3. 编队搭配：展示角色与卡组配置。
4. 装备整理：展示背包、仓库及装备信息。
5. 装备工具：展示强化/镶嵌等实际功能。
6. 天赋成长或历练选择：展示可用成长路径与关卡入口。

必须来自实际运行画面，不以封面插画、UI概念图、自动生成图冒充。不得为了凑1920×1080把旧低分辨率诊断图拉伸后当成新实拍。用于展示桌面浮窗时需检查背景不含个人信息；最终截图内不叠加用途标签。

## 尚需发布前确认

- 用户审阅最终构图；库 Logo 叠加在 Hero 的位置需要在 Steam 后台预览。
- 3840×1240 Hero 为既有主视觉的裁切放大，并非原生4K细节；本包保留生成原图，后续可替换更高分辨率母版。
- 原始图标的来源、游戏内字体的商用/嵌入授权需在完整素材授权清单里核实。当前 font-manifest 中江湖体的软件嵌入授权标为需确认；不要因宣传图完成就视为全项目授权已验收。
- 宣传片属于独立视频素材，本包提供脚本建议，尚无成品视频；不能将静态图幻灯片称为游戏实录。
- 无捆绑包、DLC、活动或额外语言图片需求时，不必制作其专属素材；后续增加时单独补充。
