# 四档向水墨渐进的画风尝试

用户希望先做画风探索，每种画风独立重绘一个角色。为了方便判断画法，四档采用同一主角身份和相近的全身姿态：短髻、竹篓、竹杖、交领、短云肩，3/4朝画面左。

- A 块面勾线：保留清楚体积，轻加墨线笔意。
- B 线描设色：线条主导，颜色更平。
- C 淡彩水墨：淡墨塑形，石青与赭色点色。
- D 轻写意水墨：笔势、干湿变化和留白更明显。

每档都由内置image_gen分别生成，不是在同一张图上套滤镜。raw/保留原图，prompts/记录完整提示词与来源；characters/统一为1600×1600审阅画布，原生尺寸另记于manifest。只做画布尺寸统一与对比图排版，不对生成角色做后期风格化。

先看comparison.png，再看各张独立角色图。此批尚未选定或导入，现有讨论预览保持不变；上一轮4张增量国风候选暂存于gemstyle-discussion-20260910/refinements/guofeng-v1/，没有写回现有排版。
