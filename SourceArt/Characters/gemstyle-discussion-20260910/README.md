# GameXXK 国风新画风讨论包

本包用独立美术素材，按当前项目的局内布局合成预览，供讨论美术方向。新角色、怪物、纯场景与卡底尚未导入游戏。

## 先看哪张

- layout-preview.png：1920×1080排版预览，人物、卡牌、资源条和按钮采用当前代码的站位与尺寸。
- layout-art-only.png：同样站位，只看纯场景与六个主体。
- background-pure.png：独立纯场景，不包含角色和UI。保留大形，补充适量岩层、松竹和地面手绘层次。
- card-base.png：独立无字卡底，单层简洁墨线。尺寸452×516，Alpha边界[2,4,448,512]与原项目T_MasterV2_CardFrame完全一致，可在确认后直接替换。
- six-subjects.png：3角色与3怪物总览。单独1600×1600全身审阅图在characters/、monsters/。
- preview-cutouts/：排版使用的透明单体，按用户要求平衡主角/伙伴尺度、缩小幽白与普通怪物，并保持当前410×410视觉框和资源条位置。
- unit-layer.png、ui-overlay.png：独立排版图层。

## 设计与修订

角色为主角、弓手、幽白，朝画面左；怪物公鸡在1P、金钱鼠Boss在2P、山羊在3P，朝画面右，尽量3/4侧面。弓手披风采用追风套的大祥云与风纹，交领、云肩、布靴强调国风。保留原低位持弓姿势，只修弓弦上下梢与箭尾的连接。

宝石同系列的粗墨轮廓、饱满块面与清楚色域贯穿素材；场景不过分碎，也不只剩平整几何块。

## 排版依据与范围

布局依据Source/GameXXK/Private/UI/GameXXKBattleBoardWidget.cpp及GameXXKBattleUnitVisualWidget.cpp：1920×1080设计舞台、410×410单位视觉框、左右错层站位、206×285手牌/意图牌、1170×287手牌行、当前工具栏与结束回合按钮位置。字体为项目现用的江湖古风字体。对应坐标、原角色占幅、卡底对齐和文件哈希见layout-spec.json。

编辑器当时未运行，无法采集实时存档现场；这是确定性离线排版，不是UE实机截图。数字和手牌为样例，不改玩法或平衡。原来由图像模型整张生成的游戏截图方案已弃用，不属于本包成果。

34张全量设计暂停，先确认这批方向，再继续下一步。已确认的44张道具已在同轮实际替换进UE，并通过像素与透明通道回读验证。

美术使用内置image_gen生成，后续只做去底、尺寸归一化与确定性排版。prompts/记录本包素材提示词。重建命令：python scripts/compose_gemstyle_current_layout.py，再运行python scripts/package_gemstyle_discussion.py。
