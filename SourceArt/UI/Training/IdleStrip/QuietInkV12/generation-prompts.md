# 青玉清透设色 v12

方式：内置 imagegen。用户指定较实的固有色稿为修改目标，要求“太脏，通透点”；本次清理黄灰浑浊混色，以青玉固有色、近深远淡及顺山势推动的连续晕染修订。

## 实际提示

精确编辑第一张用户指定的挂机山水背景，第二张是此前用户给的青绿配色参考。最新要求：“太脏，通透点”。

请保留第一张的固有色覆盖、山峰/松树/道路构图、近实远虚和适当底部重量，但把设色从黄灰浑浊的苔绿色，校正为参考图那样清透的玉青绿。改善颜色的纯净度与透光感，不是简单整体漂白：
- 主山使用干净的青绿、玉绿，受光面仍有浅玉色，背光面是纯净偏青的深绿；去掉混入山体的灰褐、脏黄和粉灰。由峰顶浓青向下沿山势缓缓推淡，每层颜色的渐变干净连贯，湿墨通透，没有斑驳补丁。
- 远山轻而有颜色，近处坡脚和松树保留清楚的墨绿轮廓、稳定的重量，避免整图同一个灰蒙蒙亮度。
- 地面保持有固有色的浅玉绿/清淡暖沙色底，减少浑浊橄榄黄。地面上青绿色的宽幅晕染顺着横向地势轻轻推开；留少量清暖的亮色通道，但大面积白色不要回来。现有色带边缘柔和，色层内部有清透的浓淡。
- 增加一点明亮但有色的玉青色过渡，像薄而清澈的颜料层。不能增亮成粉白，也不能把青色加饱和成刺眼蓝绿，保持雅致。
- 复杂度来自少数有宽窄、长短和转折的流动色层。不要补充金色网线、裂纹、鳞片皴染、颗粒、纸纹、点点、散石或草点。清理现有使颜色发脏的细小碎皴与杂色。

保留原图轮廓、山与松的位置、道路落脚高度和画布比例。上下景物外部依然平整纯品红#FF00FF；不要动抠图底、不要裁剪。保持水平二方连续：左右边界的颜色、地形高度和路沿相配，不能在中间出现接缝。尽量输出1983×793。不要新增月亮、建筑、云、人物、敌人、UI、文字。
