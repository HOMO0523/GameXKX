# 云海与近黑勾线 v21

用户指定附件作为基底，要求“勾线再深点，接近黑线，后面加层云海”。基底与用户附件逐像素一致；云海由内置imagegen生成独立后层，墨线沿用已有路径，仅加深为RGB(43,44,42)。v21云层整体透明度0.80；v22取消该衰减，保留生成图本身的边缘透明度，解决深色预览背景把云混暗的问题。

## 实际云层提示

为附图制作一张可对位叠放在山体后面的“云海独立图层”，只输出云海图层，不要输出山、松树、黄土地或任何其他景物。
用途：横向循环挂机背景的远景。原山与地面会作为前景完整盖在这层云海前，所以云可以在山后连续延伸，不能遮到角色或土地上。

画布严格1983×793，与附图对位。原山体约y=256至430、土地y=430至530。请把云海放在约y=270至435的区域：上沿由舒展、缓慢起伏的云峰组成，局部最高可到y=245，大部分上沿在y=290至320；下沿延至y=435，会被前景遮住。中央山谷后方应能看见明显而安静的一层云海。左右满幅连接，没有封闭的左右端头。
形态为中国手绘武侠山水中的远处云海：两三层大而平缓的灰白云带，层层横向舒展，少量柔软卷曲和远近明暗，有云层厚度和轻微水墨渗化。整体低对比，边缘有虚有实，但不要完全模糊或雾白糊一片。云色淡蓝灰、暖灰白，代表色#C3CDD1、#DDE0DB，阴影#AEBBC0；不用刺眼纯白。远景轮廓只允许极淡灰线，不能用黑描边。
不要数十个小棉花球，不要颗粒、飞散点、碎雾、光效、月亮、太阳、天空背景或装饰。只需要安静的一层云海，用大形给山体增加远近感。
云海外所有区域保持绝对平整纯品红#FF00FF，包括顶部、底部，不能画灰白天空矩形。输出仅云形和品红抠图背景。不要原山水填色，不要参考里的松树或土地，不要人物、UI、文字。
水平二方连续要求：左右云层断面的高度、轮廓、色彩相同，拼接时无竖缝。两端云形继续贯穿画幅，不淡出、不收口。

## 保留与验证

前景不透明、未勾线区域的像素完全保留，云海位于前景后方，不延伸到地面下方。前景几何不变，左右接缝RGBA差值0，血条区域底图alpha为255。独立云层、墨线层、选定底图和参数均在本目录。用户对整体画面随后提出反馈，不能将本版本视为最终视觉确认。
