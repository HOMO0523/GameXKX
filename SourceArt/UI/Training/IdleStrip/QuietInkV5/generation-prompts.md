# 淡墨绿晕染挂机背景 v5

方式：内置 imagegen；基于 v4 简化山形继续编辑地面变化与淡墨绿晕染。用户提出的方向已实施，本文件不代表用户对结果的最终视觉确认。

## 最终提示

在这张图片上做明确可见的“淡墨绿水墨晕染”处理，山体和地面都要有。输出1981×793原尺寸。保留山形、两株松、路面位置及品红外部遮罩。
现在的地面过于均匀像平涂，山体也太灰白。请让整个景物明显具有湿墨在纸上徐徐渗开的感觉：
地面：从坡脚向下、从路沿向内，增加三四片宽阔、形状不规则的浅墨绿和灰赭湿墨色团。至少有一片在路面中部可见。每片有非常自然的深浅浓度渐变，边缘朦胧柔化，部分交叠。灰绿实际偏清淡的鼠尾草/墨绿（参考暗部#8F9F8D、中间#B9C4AF、极浅#D9DFC8），透明感强、轻薄，最浅处过渡回原有暖纸色。面积要足够让人能看见晕染，但仍是淡的背景。路面保留行走通道，有疏有密，绝不是均匀重复的矩形色块。
山体：同样增加由浅灰绿到淡墨绿的水墨浓淡渐变，山脚柔和地溶入地面晕染，主轮廓有虚有实。保留现有山石形体与松树姿态。
关键：用低频、连续、柔软的湿墨渐变形成层次；不要点状斑驳、散点、喷溅、细碎飞白、沙粒、碎石、草点、均匀纸纹。不要强硬平涂边，不要黑墨，不要浓艳绿。晕染应一眼能辨认，并且仍清淡克制。
左右两端的高度、颜色和形状相配，可以横向连续；不增加中间接缝。路面高度和上下留空原样，品红RGB255,0,255背景保持完全平整，别把水墨晕染画到品红区域。不添加人物、文字或UI。
