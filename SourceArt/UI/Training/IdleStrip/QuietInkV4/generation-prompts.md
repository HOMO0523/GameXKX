# 挂机条疏简淡墨背景

生成方式：内置 imagegen。当前稿是按用户“细碎、抢眼”“连续性不成立”“太平没有味道”“点太多”的反馈修订；尚未标记为用户最终视觉确认。

## 最终造型提示

编辑这张游戏挂机背景，输出同样 1983×793 的横向连续背景素材，外部纯品红 #FF00FF 保持。

用户要求：这张太细碎、点太多。请保留有韵味的山形和松树姿态，把画面简化成干净、连贯的大块淡墨设色。
具体只改这些：
- 保留左侧斜肩山、右侧错落山峰的总体形状，但山峰更低一些。山中只留一两笔宽而连续的结构墨线；删去全部砂点、皴擦碎笔、碎高光、飞白颗粒、裂纹。
- 全图只留左侧一株弯松和右侧一株很小的松。树冠合并成完整的三两团，删去枝叶碎点、其他灌木、小树、石块、草丛。
- 灰橄榄山体只用三层清楚而低对比的平涂色块，线条有自然粗细和转折。既有手绘性格，又干净利落。绝不能变成圆滑正弦波小丘。
- 修掉前景黑色碎石裙边，路沿改成完整、轻薄、自然起伏的灰褐轮廓，只有很少几段长笔触。
- 路面使用低饱和浅灰赭，内部只允许三条宽、长、浅的扫笔，大片安静留白，删去所有短小斑点、沙粒、碎石。不要一条刷墙般均匀的色块，笔触顺着土地走向而且有长短变化。
- IMPORTANT geometry: 当前图的地平线太低。把路面上沿提升到画布 y=430，路面下沿提升到 y=570。最高山尖 y=270 左右。顶部与底部保留大面积品红空白，不要裁画布。
- 左右边界保持山地外形、地平线和路沿高度相同，可以横向无限循环；两边都选低矮山谷衔接，不出现垂直接痕。两端不淡出、不收口。
- 整体配色是暖灰、灰绿、淡赭，背景的最深色也明显浅于游戏人物的墨色轮廓。
不要添加任何新物体。不要文字、人物、界面、噪点、纸纹、碎笔、黑边。只输出这张精简后的背景。

## 出图后的技术导出

- 原始生成图为 1981×793；左右各扩展一个边缘像素，恢复运行时 1983×793 画布，不拉伸图形。
- 提取品红遮罩并清理混色边缘，导出实际 RGBA。
- 全图上移 64 像素，使道路回到原角色脚底所在位置。
- 使用预乘透明度的 128 像素平滑边缘融合，令左右边缘 RGBA 完全一致。
- 用纯 2D `L_DesktopTrainingHUD` 的实际角色与血条复核；人物、控件和动画保持独立。
